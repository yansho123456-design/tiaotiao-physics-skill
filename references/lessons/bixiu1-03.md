# 必修1 第3讲 时间与时刻（基础课）

讲次代号：bixiu1-03

## 这一讲讲了什么

这一讲是必修1运动学的第三个基础概念，讲时间与时刻。老师先说明质点、参考系、时间与时刻都是为研究运动学做准备：质点回答谁在动，参考系回答动没动，时间与时刻回答什么时候动、动了多久。核心区别只有一句：时刻是时间轴上的一个点，描述运动的开始、结束；时间（时间间隔）是时间轴上的一段，描述运动持续的时长。日常说话里的时间有两个含义，物理上要分开。常见说法分两组：时间有第1s、第3s、前3s、第ns，时刻有0时刻、第1s初、第1s末、第ns初、第ns末。第几秒从第1秒起，没有第0秒；第ns是从 $n-1$ 到 $n$，不会推时令 $n=1$ 去推。本讲两道例题：一道判断哪个说法指时间，一道在时间轴上判断四个说法哪个对。老师给的三个目标是区分时间与时刻、掌握常见说法、会在时间轴上标时间与时刻。

### bixiu1-03-c01　〔概念〕为什么学时间与时刻：运动学的三个基本问题

讲义第 2 页 · 视频 00:37 · 关键词：运动学、运动学基本问题、质点、参考系、时间与时刻、时间、时刻 · 题型：概念

老师说：前两节课的质点、参考系和这节课的时间与时刻，都是为研究运动学做准备。运动学说白了就是研究一个物体怎么去动。研究物体怎么动，要依次解决三个问题。第一，谁在动，靠质点：现实中运动的物体五花八门、形状各异，很麻烦，所以把它抽象成点，眼里都是一个个点在动，点最简单、好算，质点的目的是简化运动的物体。第二，动没动，靠参考系：运动是绝对的，静止是相对的，世间万物都在动，但我们关注的不是它到底动没动，而是在研究的这个问题里它动没动；办法是先人为规定一个静止的物体，看研究的物体相对这个参考系动没动，参考系的意义是帮我们确定物体到底动还是没动。第三，什么时候开始动、什么时候结束、到底动了多久，靠时间与时刻这两个概念。

### bixiu1-03-c03　〔概念〕日常说的时间有两层含义：一个时间点，或一段时间

讲义第 4 页 · 视频 03:03 · 关键词：时间、时刻、时间点、一段时间、日常说法、时间的两个含义 · 题型：概念、判断

老师用一篇小学生日记《爸爸，我想对你说》来引入。讲义上标红的是早上五点、半夜三点，老师说这两个都是记录一个时间点，比如他看信的那个时刻是早上五点钟，或者他醒来的那个时间点是半夜三点。讲义上标蓝的是最近两天内、早上7:00到晚上12:00、连续十几个小时、半个小时、四十分钟，老师说这些是一段时间。老师又举例：跟女朋友约好明天下午两点半去看电影，两点半是约定的一个时间点，迟到一秒钟都算迟到。老师总结：日常生活中我们说的时间有两个含义，有时表示一个时间点，有时表示一段时间。平时已经习惯这么说，不会有歧义，比如说明天下午两点半见，不用特意强调这是时间点不是一段时间。但物理是严谨的学科，所以要给这个时间点和这一段时间分别起一个名字，这就是时刻与时间。

### bixiu1-03-c07　〔例题〕例题 1：给出几句话，判断哪个涉及的计时数据指时间

讲义第 6 页 · 视频 05:52 · 关键词：时间、时刻、判断时间还是时刻、新闻联播、天宫一号、时间轴 · 题型：例题、判断、选择题

考点是区分时间与时刻。老师说这种题在高一上学期的考试中经常出现：给你几句话，问涉及到时间的是哪个、涉及到时刻的是哪个。老师强调要练熟，给你一段描述，要知道它表示的是时间还是时刻。〔整理注：老师口述里天宫一号被转录成天空一号，这里照讲义写作天宫一号。〕

**题目**：下列几种表述中，涉及到的计时数据，指时间的是（   ）
A. 中央电视台新闻联播节目用时30分钟
B. 1997年7月1日零时中国对香港恢复行使主权
C. 北京奥运会开幕式于2008年8月8日晚8时开始
D. 2011年9月29日21时16分03秒，“天宫一号”在酒泉卫星发射中心发射升空

**解法**：

1. 先回忆：时间指的是一段，不是一个点。一个一个选项看。
2. A：新闻联播用时30分钟，30分钟是一段时间，从晚上7点钟到晚上7点半，是时间。A 对。
3. B：1997年7月1日零时中国对香港恢复行使主权，过了7月1日零时之后香港就是中国的了，这是一个时刻，不是一段时间。B 不对。
4. C：奥运会的开始是2008年8月8日晚上8时，过了晚上8时之后奥运会立马开始，这是一个时刻。C 不对。
5. D：精确到秒的发射时间，“天宫一号”就是在这一个时刻发射的，也是时刻。D 不对。所以 B、C、D 指的都是时刻，只有 A 是时间，选 A。

**答案**：A

### bixiu1-03-c08　〔易错〕精确到秒或没精确到秒都只是时刻的说法，不是看精确不精确

讲义第 6 页 · 视频 06:53 · 关键词：时刻、精确到秒、零秒、判断时间还是时刻、时刻的说法 · 题型：易错、判断、选择题

老师说：例题 1 里有同学会纠结，C 项晚上8时没有精确到秒，D 项精确到了秒。其实这只是时刻的两种说法。可以把 C 理解为晚上8时零秒，只是这个零秒写出来看着很可笑，就省略了，语文及格的同学都应该能读出来。所以判断是时间还是时刻，不能看有没有精确到分、秒，只看它是一个点还是一段。B、C、D 指的都是时刻。

### bixiu1-03-c09　〔概念〕时间的常见说法：第1s、第3s、前3s、第ns，在时间轴上都是一段

讲义第 7 页 · 视频 07:39 · 关键词：时间、第1s、第3s、前3s、第ns、第几秒、前几秒、第几秒内、时间的说法、时间轴 · 题型：概念、判断、标时间轴

老师说：时间和时刻在日常生活中用得太多，所以说法就多一些。讲义上时间的说法（红字）有：第1s，第3s，前3s，第ns，这些都是时间的说法。在时间轴上标出来：第1s 就是从 0 到 1 的这一段；既然 0 到 1 是第1s，1 到 2 是第2s，那么第3s 就是 2 到 3 这一段；前3s 指从最开始算起3秒钟这段时间，是从 0 到 3 这一整段；第ns 是从 $n-1$ 到 $n$ 这一段（推法见方法卡）。老师说，只要说到第1s、第3s、前3s、第n s、第几秒内、前几秒这些，都是时间。〔整理注：本卡把讲义的第ns 的 n 写作 $n$。〕

### bixiu1-03-c10　〔概念〕时刻的常见说法：0时刻、第1s初、第1s末、第ns初、第ns末，在时间轴上都是一个点

讲义第 7 页 · 视频 07:58 · 关键词：时刻、0时刻、零时刻、第1s初、第1s末、第ns初、第ns末、时刻的说法、时间轴 · 题型：概念、判断、标时间轴

老师说：讲义上时刻的说法（蓝字）有：0时刻，第1s初，第1s末，第ns初，第ns末。时刻是有零的，因为时间轴上零点就是零时刻。第1s初指第1秒最开始的那一个点，所以是一个时刻；第1s末指第1秒最末尾的那一个点，也是一个时刻。在时间轴上：0时刻就是 0 这个点；第1s初也是 0 这个点，所以它和0时刻一模一样；第1s末是第1秒（0 到 1）末尾的那个点，也就是 1 这个点；第ns初指第ns（$n-1$ 到 $n$）开头的那个点，也就是 $n-1$ 这个点；第ns末是第ns 结尾的那个点，也就是 $n$ 这个点。老师总结：说到零时刻、第1s初、第1s末、第ns初、第ns末这些，都是时刻。

### bixiu1-03-c11　〔易错〕没有第0s：第几秒从第1秒开始，时刻才有零

老师先标时间。第1s：已经标出来，是从 0 到 1 的这段。第3s：既然 0 到 1 是第1s，往后是第2s，再往后是第3s，所以第3s 是 2 到 3 这一段。前3s：从最开始算起3秒钟，是 0 到 3 这一整段。第ns：是 $n-1$ 到 $n$ 这一段（不会推时用下一张方法卡）。做法：从 0 开始往后一段一段数，数到第几秒就是第几段；前几秒是从 0 开始连着的几段。

### bixiu1-03-c13　〔方法〕把时刻标在时间轴上：找到那个点

### bixiu1-03-c14　〔方法〕第n秒不会推就令 $n=1$：第ns 是从 $n-1$ 到 $n$

讲义第 7 页 · 视频 09:01 · 关键词：第ns、令n=1、n-1到n、第n秒、带n搞不定就让n=1推、第几秒 · 题型：方法、标时间轴、判断

老师说：第ns 很多人犯难，到底是 $n$ 到 $n+1$，还是 $n-1$ 到 $n$？其实不需要记，有一个特别简单的方法：不知道就看第1秒。第1秒是 0 到 1，还是 1 到 2？前面说过第1秒是 0 到 1。这时候 $n=1$，0 对应的就是 $n-1$，1 对应的就是 $n$，所以第ns 就是 $n-1$ 到 $n$。老师总结：以后遇到什么第n个什么、前n个什么，不会推的时候，就让 $n=1$，立马就知道它是 $n-1$ 到 $n$ 还是 $n$ 到 $n+1$。老师把它写成了讲义上的红字笔记：带n搞不定，就让n=1推。本讲总结时老师把它列为要注意的第二个点（比较难的点）：关于第ns、第ns初、第ns末，只要知道第ns 是 $n-1$ 到 $n$，不知道就令 $n=1$ 先推一下，也很容易。

### bixiu1-03-c15　〔例题〕例题 2：在时间轴上判断四个关于时刻和时间的说法哪个正确

讲义第 8 页 · 视频 10:55 · 关键词：时间轴、时刻、时间、第2s末、第3s初、第3s内、最初2s内、第2s内、第ns内、令n=1 · 题型：例题、判断、选择题、标时间轴

考点是时间轴上时刻与时间的各种说法。老师的解法是逐项判断：先看这一项说的是点还是段，再看称呼对不对；带 $n$ 的选项用令 $n=1$ 来检验。讲义红字笔记：带n搞不定，就让n=1推。〔整理注：转录里选项 D 的讲解被写成了选项 C，这里按讲义和老师所讲内容归到选项 D。〕

**题目**：如图所示的时间轴，下列关于时刻和时间的说法中正确的是（   ）
A. $t_2$ 表示时刻，称为第2s末或第3s初，也可以称为2s内
B. $t_2 \sim t_3$ 表示时间，称为第3s内
C. $t_0 \sim t_2$ 表示时间，称为最初2s内或第2s内
D. $t_{n-1} \sim t_n$ 表示时间，称为第$(n-1)$s内

**解法**：

1. 时间轴上 $t_0$、$t_1$、$t_2$、$t_3$ 对应 0、1、2、3，$t_{n-1}$、$t_n$ 对应 $n-1$、$n$。逐项看。
2. A：$t_2$ 是一个点，表示时刻，说它称为第2s末或第3s初没问题；但后面“也可以称为2s内”说的是一段时间。一个点表示时刻，就一定不可能又是时间，两者冲突。A 不对。
3. B：$t_2$ 到 $t_3$ 是一段，表示时间没问题。称为第3s内：看不出来的话，就从零开始往后数，0 到 1 是第1s，1 到 2 是第2s，2 到 3 是第3s，所以是第3s内。B 对。
4. C：$t_0$ 到 $t_2$ 是 0 到 2 这一段，表示时间没问题，称为最初2s内也没问题；但它不是第2s内，第2s内是 1 到 2 这一段。C 不对。
5. D：带 $n$ 搞不定就让 $n=1$ 推。$n=1$ 时，$t_{n-1}$ 到 $t_n$ 是 $t_0$ 到 $t_1$，称为第$(n-1)$s内就是第0s内，而没有第0s，所以不对。如果把 $n-1$ 改成 $n$，$n=1$ 时就是 $t_0$ 到 $t_1$ 称为第1s，就没问题了。D 不对。所以选 B。

**答案**：B

老师说：选项 A 说 $t_2$ 表示时刻，称为第2s末或第3s初，这句话没问题；但后面接着说也可以称为2s内，注意后面这一段话，描述的其实是某一个时间。$t_2$ 是时间轴上的一个点，它表示时刻了，就一定不可能是时间，这两个是冲突的，所以 A 不对。判断称呼时要看前后说的是不是同一类：点只能用时刻的说法，段只能用时间的说法。

### bixiu1-03-c17　〔易错〕最初2s内是 0 到 2，第2s内只是 1 到 2：例题 2 选项 C

讲义第 8 页 · 视频 11:35 · 关键词：最初2s内、第2s内、第3s内、时间、t0~t2、第几秒内 · 题型：易错、判断、选择题

老师说：选项 C 里，$t_0$ 到 $t_2$ 是 0 到 2 这一段，表示时间毫无疑问没有问题，称为最初2s内也没问题；但它不表示第2s内。第2s内表示的是从 1 到 2 这一段，所以“或第2s内”这里是错的，C 不对。对比选项 B：$t_2$ 到 $t_3$ 才是第3s内，判断第几秒内时从零开始往后一段一段数，0 到 1 是第1s，1 到 2 是第2s，2 到 3 是第3s。

配图：bixiu1-03-q-optC、bixiu1-03-q-optB

### bixiu1-03-c18　〔易错〕带 $n$ 的说法：选项 D 的第$(n-1)$s内令 $n=1$ 变成第0s内，不对

讲义第 8 页 · 视频 11:57 · 关键词：第ns内、令n=1、没有第0s、t(n-1)~tn、带n搞不定就让n=1推、第几秒内 · 题型：易错、方法、判断、选择题

老师说：选项 D 说 $t_{n-1}$ 到 $t_n$ 表示时间，称为第$(n-1)$s内，又到了 $n$，只要带 $n$ 就让 $n=1$。$n=1$ 时，$n-1$ 是 0，$t_{n-1}$ 就是 $t_0$，所以这句话翻译过来是：$t_0$ 到 $t_1$ 表示时间，称为第0s内。不对，因为没有第0s，第几秒最早是从第1秒开始，最小是1。老师说，如果把这里的 $n-1$ 改成 $n$ 就对了：把 $n=1$ 代进去，是 $t_0$ 到 $t_1$ 表示时间，称为第1s，就没有问题。所以遇到带 $n$ 的题，把 $n$ 代成 1 进去看对不对就行。

### bixiu1-03-c19　〔口诀〕本讲打卡小结：区别、常见说法、标时间轴

讲义第 9 页 · 视频 12:49 · 关键词：时间与时刻、小结、时刻、时间、常见说法、标时间轴、打卡 · 题型：口诀、概念、方法

老师带着对照三个目标。目标一，拿捏时间与时刻的区别：时刻是一个瞬间，时间轴上的一个点；时间（间隔）是一段时间，时间轴上的一段。目标二，掌握时间与时刻的常见说法：说到第1s、第3s、前3s、第ns、第几秒内、前几秒，这些都是时间；说到零时刻、第1s初、第1s末、第ns初、第ns末，这些都是时刻。老师说，要知道这些常见说法，给你一个说法，要能区分出它到底是时间还是时刻。目标三，给你一个时间轴，会按要求标时间与时刻：讲例子和例题时已经演示过几次了，不熟练的话可以再听一听。老师建议顺利拿捏这三个目标的同学在评论区回复“已打卡”作为学习的见证。下一讲是基础课第4讲，矢量与标量，老师说这两个概念贯穿高中物理三年，非常重要，要认真听。
