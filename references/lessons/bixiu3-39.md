# 必修3 第39讲 φ-x图像（题型技巧课）

讲次代号：bixiu3-39

## 这一讲讲了什么

这一讲是电场综合问题里电场图像问题的第一类：φ-x 图像（电势随位移变化的图像）。题型特征是题目给出 x 轴上电势随 x 的分布图，让我们分析 x 轴上各点的各种物理量。老师先强调图像的含义：这条曲线只表示 x 轴这一条一维直线上各点的电势，不是电场线或等势面，x 轴以外的信息全部未知，所以题目只会问 x 轴上的量。分析只有两个核心。核心 1：先把 x 轴上的电场线画出来，电场线从高电势指向低电势，按单调区间分段，每段从高指向低。核心 2：比较场强大小，看斜率，某点斜率的大小就表示该点场强的大小，老师用 $\Delta x\to 0$ 的微元思想推了出来。随后六道例题依次是：B、C 两点的场强与电场力做功、关于纵轴对称的曲线加直线图、粒子由静止从 M 向右运动（判电性、能否过 N 点）、均匀带电圆环轴线上的电势图、等量异种电荷连线上电势的选图、2017 江苏高考的两个点电荷。老师说这六道题听明白，这个题型就可以彻底过掉。下一讲是 E-x 图像。

### bixiu3-39-c01　〔概念〕φ-x 图像题的题型特征：给 x 轴上的电势分布，分析 x 轴上各点的物理量

讲义第 3 页 · 视频 00:38 · 关键词：φ-x图像、电势位移图像、φ-x图、电势随x的分布、电场图像问题、题型特征、x轴、电势、φ · 题型：概念、判断、选择题

老师说：φ-x 图像（电势随位移变化的图像）是电场综合问题的最后一类，电场图像问题里最常考的有两种：一种是 φ-x 图，另一种是 E-x 图（场强随位移变化的图像，下一讲讲），其中 φ-x 图考得更多一些。这类题的特征很明显：告诉我们电场中的一条线，通常叫 x 轴，以及 x 轴上电势随 x 的分布图，让我们分析 x 轴上各个位置的各个物理量，例如比较 M 点和 N 点哪个点场强高、哪个点场强低，或者把一个负电荷从 M 点移到 N 点，问电场力做正功还是负功、电势能增加还是减小等等。讲义第 3 页的例题是：空间存在平行于 x 轴的静电场，A、M、O、N、B 为 x 轴上的点，$OA<OB$，$OM=ON$，AB 间的电势 $\varphi$ 随 $x$ 的分布如图所示，一个带电粒子在电场中仅在电场力作用下从 M 点由静止开始沿 x 轴向右运动，判断下列选项，这道题放在后面作为例题 3 详讲。一句话概括题型特征：已知 x 轴上电势随 x 的分布图，分析 x 轴上各种物理量。老师提醒，想真正会做这类题，首先要把这个图像的含义理解到位，很多同学对它有误解。

### bixiu3-39-c02　〔概念〕图像的含义：纵坐标是 x 轴上某一点的电势，曲线只表示 x 轴这一条线

讲义第 4 页 · 视频 01:20 · 关键词：φ-x图像、图像含义、纵坐标、电势、φ、一维空间、x轴、电势高低 · 题型：概念、判断

老师说：看 φ-x 图像一定要注意，这条曲线不是电场线，也不是等势面，它只能表示 x 轴这一条线。x 轴是一个一维空间，一条直线，图像只告诉我们这个一维空间上每一点的电势高低。纵坐标表示 x 轴上某一点的电势，要看电势高低，只看纵坐标大小就行。老师举例：在 x 轴上取点 a、b、c、d、e，从图像上读出它们的纵坐标，随手取 a 为 $-3$、b 为 $0$、c 为 $5$、d 为 $8$、e 为 $0$（这几个数是老师为了讲解随便写的）。那么这个图像表示的就是：把对应的点画到一条 x 轴上，a 点电势是 $-3$，b 点电势是 $0$，c 点电势是 $5$，d 点电势是 $8$，e 点电势是 $0$。整个图看上去是二维的，但它只表示这一条一维 x 轴上各点的电势，就这么简单。〔整理注：纵坐标为 $0$ 的点，就是电势为零的点；曲线最高处的点电势最大。〕

### bixiu3-39-c03　〔易错〕x 轴以外的信息全部未知，题目只会问 x 轴上的量

讲义第 4 页 · 视频 02:37 · 关键词：φ-x图像、x轴以外、信息未知、一维、图像含义、电场线、等势面 · 题型：易错、判断、概念

老师说：这条线以外的所有信息我们都不知道，这条线以外任何一个点的电势、场强什么的都不知道。所以对 φ-x 这类图，如果给了你一个图像，问的一定是 x 轴上各个点的各个物理量，一定不会问 x 轴以外，因为 x 轴以外什么都不知道，没法分析。讲义第 4 页红字：注意，电场中 x 轴以外的地方信息全部未知。老师还说，注意这个图只是看起来像二维图像，不要把曲线当成电场线或等势面去想。

### bixiu3-39-c04　〔方法〕核心 1：画出 x 轴上的电场线，从高电势指向低电势

讲义第 5 页 · 视频 03:29 · 关键词：核心1、画电场线、x轴上电场线、高电势指向低电势、电场线、场强方向、电势高低、φ-x图像、电场方向 · 题型：方法、判断、选择题

老师说：分析 φ-x 图像有两个核心，第一个核心是把 x 轴上的电场线画出来。根据电势高低画电场线，电场线从高电势指向低电势。怎么看电势高低：看纵坐标大小就行。例子：曲线左半部分，设 A 点在左边的零点附近，B 点在最高处，从 A 到 B 电势一直升高，B 点电势最高、A 点电势最低，所以这段电场线从 B 指向 A。老师强调，只画 x 轴上的，x 轴以外不画，因为不知道。从 B 再往右，曲线又往下落，电势降低，B 是 B 往右电势最高的地方，所以这段电场线从 B 往右指。为什么要以 B 分开：因为从 B 的左边往 B 走是升高，B 的右边是降低。老师总结：每一段增和减，都应该画出一段箭头。讲义第 5 页红字：电场线从高电势指向低电势，按单调区间分段，每段从高指向低。老师说，只要是 φ-x 图，第一步都先把 x 轴上的电场线画出来，养成习惯，这是第一个核心。〔整理注：电场线方向就是场强方向，后面例题里判断场强的方向直接看这一步画出的箭头，不看斜率的正负。〕

### bixiu3-39-c05　〔方法〕复杂图像先按单调区间分段，每段从高指向低

讲义第 5 页 · 视频 05:10 · 关键词：单调区间、分段、核心1、画电场线、单调增、单调减、高指向低、φ-x图像 · 题型：方法、判断

老师说：简单的图一眼就能看出来，复杂的图就按单调区间分段来画。第一步：先把图像按单调区间分段，弄清哪一段在增、哪一段在减。第二步：每一段按从高指向低来画箭头。核心就是先按单调区间分段。讲义第 5 页右边的图：曲线左边一直在降低，曲线右边先增加再降低，所以一共有三个单调区间，曲线左边是单调减，右边是先单调增再单调减，就分三段来画。第一段：左边这段，起点高、末端低，箭头向右。第二段：从第一条虚线（红线）到第二条虚线（黄线）这段一直在增，起点低、末端高，所以箭头从高指向低，向左。第三段：过了第二条竖线再往右又在降低，这个点是右边最高的点，箭头向右。所以它的 x 轴电场线是先向右、再向左、再向右。有几个单调区间就分几段。

### bixiu3-39-c06　〔方法〕核心 2：某点斜率的大小表示该点场强的大小（推导）

讲义第 6 页 · 视频 07:06 · 关键词：核心2、斜率、场强、场强大小、平均场强、微元法、U=Ed、φ-x图像、电场强度、E、k=E · 题型：方法、概念、推导

老师说：φ-x 图题总是问 x 轴上两个点哪个点场强大、哪个点场强小，所以第二个核心是根据 φ-x 图分析两点场强大小，办法很简单，直接看斜率。某一个点的斜率的大小就表示这一点的场强大小。讲义第 6 页红字：某点斜率大小表示该点场强大小。老师把推导也讲了，希望听明白。在曲线上某点的左边取 $x_1$，右边取 $x_2$，两点距离是 $\Delta x$，让 $\Delta x$ 趋近于 $0$，斜率 $k=\frac{\varphi_2-\varphi_1}{\Delta x}$。其中 $\varphi_2-\varphi_1$ 是这一段的电势差 $U$，$\Delta x$ 是两点间的距离，记作 $d$，所以 $k=\frac{U}{d}$。老师说，前面讲过 $\frac{U}{d}$ 在匀强电场里等于场强；如果是非匀强电场，用这一段的电势差除以这一段的距离，算出来是这一段的平均场强。当 $d$ 趋近于 $0$，距离无限小的时候，根据微元法的思想，这一小段的平均场强就等于这一点的场强。所以斜率 $k$ 的大小就等于这个点的场强大小。老师还类比了必修 1 讲瞬时速度：位移除以时间是平均速度，时间趋近于 $0$ 时这段时间的平均速度就等于这一点的瞬时速度，道理一样。老师希望我们不要只记结论，把为什么看斜率，是根据斜率的定义一步步推出来的这个过程也听明白。

### bixiu3-39-c07　〔方法〕比较两点场强：画切线看陡缓，只看斜率大小，不管正负

讲义第 6 页 · 视频 09:23 · 关键词：斜率、切线、陡峭程度、场强大小、比较场强、切线斜率、核心2、φ-x图像、电场强度、E · 题型：方法、判断、选择题

老师说：比较场强大小，就画出各点的切线，看切线的陡峭程度，切线越陡峭，斜率的大小越大，场强越大。老师举例：曲线上取 A、B、C 三点，A 的切线是一条一般陡的线，B 在最高处，切线基本水平，C 的切线比 A 更陡。所以 C 最陡，其次是 A，最平缓的是 B，于是 $E_C>E_A>E_B$。老师特别提醒：不要纠结斜率是正的还是负的，因为核心 1 里已经把电场的方向都画出来了，场强的方向已经知道，核心 2 只为了分析场强的大小，所以只看 $k$ 的大小。老师说场强会分析了吧，就是看斜率，就这么简单。〔整理注：曲线最高点或最低点的切线水平，斜率为零，该点场强为零；直线的斜率处处相等，所以直线段上场强大小处处相等（老师在例题 2、例题 3 中用到）。〕

### bixiu3-39-c08　〔例题〕例题 1：B、C 两点场强大小与方向，O 点电场力，负电荷从 B 移到 C 的做功

讲义第 7 页 · 视频 10:56 · 关键词：φ-x图像、电场线、场强大小、斜率、电场力、电场力做功、负电荷、场强方向、O点 · 题型：例题、选择题、判断

例题 1 是 φ-x 图的基础题，直接用两个核心：先画 x 轴电场线，再用斜率比较场强大小。老师用它来演示：场强的方向看画出的电场线，场强的大小看切线陡缓；电场力的大小由场强大小决定，电场力的方向由电场方向和电荷正负决定；做功正负由力与位移方向的关系判断。

**题目**：空间某一静电场的电势 $\varphi$ 在 $x$ 轴上分布如图所示，$x$ 轴上两点 B、C 的电场强度在 $x$ 方向上的分量分别是 $E_{Bx}$、$E_{Cx}$。下列说法正确的有（   ）
A. $E_{Bx}$ 的大小大于 $E_{Cx}$ 的大小
B. $E_{Bx}$ 的方向沿 $x$ 轴正方向
C. 电荷在 O 点受到的电场力在 $x$ 轴方向上的分量最大
D. 负电荷沿 $x$ 轴从 B 移到 C 的过程中，电场力先做正功，后做负功

**解法**：

1. 老师说：题目信息都在图上，养成好习惯，第一件事先把 x 轴上的电场线画出来。O 点电势最高，有两个单调区间：从左边到 O 单调增，从 O 往右单调减，分两段画。左边这段 O 最高，O 的左边都在降低，由高指向低，所以从 O 指向负半轴（向左）。右边也是 O 最高，越往右越低，从 O 指向右边（向右）。
2. A：看斜率。画 B 点和 C 点的切线，肉眼看 C 点的切线更平缓，所以 B 点的场强大于 C 点，A 对。
3. B：电场方向就是场强方向，也就是第一步画的电场方向。B 点在 O 左边的箭头上，向左指，所以 $E_{Bx}$ 沿 $x$ 轴负方向，B 错。
4. C：问的是电场力，电场力 $F=Eq$，本质上还是问场强，场强越大电场力越大。O 点的切线基本水平，斜率最小，场强最小，电场力也最小，所以 C 错。
5. D：因为是负电荷，电场力方向与电场方向相反，在 O 的左边电场力向右，在 O 的右边电场力向左。负电荷从 B 往 C 移，从 B 到 O，力向右、位移向右，做正功；从 O 到 C，位移向右、力向左，做负功。所以先做正功后做负功，D 对。选 AD。
6. 老师总结：把握住两个核心，画电场线加分析场强，这个题就很简单了。

**答案**：AD

### bixiu3-39-c09　〔例题〕例题 2：曲线加直线、关于纵轴对称的 φ-x 图，判断场强与电势能

讲义第 8 页 · 视频 13:29 · 关键词：φ-x图像、曲线、直线、关于纵轴对称、斜率、场强大小、电势能、负电荷、Ep=qφ、电势 · 题型：例题、选择题、判断

例题 2 的图是曲线加直线的对称图形。老师借它强调三点：曲线上各点斜率不同，场强大小不同，直线上斜率相同，场强大小相同；对称的两点电势相同，同一电荷电势能也相同；比较电势能时，用 $E_p=q\varphi$ 算，带负电的粒子要注意不等号变号。

**题目**：在 $x$ 轴上存在与 $x$ 轴平行的电场，$x$ 轴上各点的电势随 $x$ 点位置变化情况如图所示。图中 $-x_1\sim x_1$ 之间为曲线，且关于纵轴对称，其余均为直线，也关于纵轴对称。下列关于该电场的论述正确的是（   ）
A. $x$ 轴上各点的场强大小相等
B. 从 $-x_1$ 到 $x_1$ 场强的大小先减小后增大
C. 一个带正电的粒子在 $x_1$ 点的电势能大于在 $-x_1$ 点的电势能
D. 一个带负电的粒子在 $-x_1$ 点的电势能大于在 $-x_2$ 的电势能

**解法**：

1. 老师说：第一步先画电场线。图像以 O 点为最低点，先单调减再单调增（转录里误作先单调减再单调减），分两段画。左边这段 O 点电势最低，电场线从高指向低，向右指向 O；右边这段越往右越高，电场线从右边指向 O。所以 O 是电势最低的点。
2. A：看 $-x_1$ 到 $x_1$ 这段，是曲线，场强大小看斜率，曲线上每个点的斜率都不一样，只有直线斜率才一样，所以 A 不对。
3. B：从 $-x_1$ 到 O，曲线的切线越来越平缓，斜率的大小越来越小；过了 O 又越来越陡峭，斜率的大小越来越大。所以场强大小先减小后增大，B 对。
4. C：$x_1$ 和 $-x_1$ 两点对称，纵坐标一样，两点电势一样，$E_p=q\varphi$，电势一样电势能就一样，所以 C 不对。
5. D：比较 $-x_1$ 和 $-x_2$，明显 $-x_2$ 的电势高于 $-x_1$，即 $\varphi_{-x_2}>\varphi_{-x_1}$。又因为是带负电的粒子，不等式两边同乘一个负数，不等号变号，$-q\varphi_{-x_2}<-q\varphi_{-x_1}$，左边是粒子在 $-x_2$ 的电势能，右边是粒子在 $-x_1$ 的电势能，所以 $-x_1$ 点的电势能大于 $-x_2$ 点，D 对。选 BD。
6. 老师提醒：这道题四个选项里没有用到画出的电场方向，但还是建议大家养成起手先画电场方向的习惯，多画多练就更熟练，多画画肯定没坏处。

**答案**：BD

### bixiu3-39-c10　〔方法〕用 φ-x 图比较电势能：用 $E_p=q\varphi$，负电荷不等号变号

### bixiu3-39-c11　〔例题〕例题 3：粒子由静止从 M 向右运动，判电性、能否通过 N 点、场强与电场力

讲义第 9 页 · 视频 16:53 · 关键词：φ-x图像、电性判断、带负电、电场力、电场力做功、动能定理、场强大小、斜率、直线斜率不变、恒力、OM=ON · 题型：例题、选择题、判断

例题 3 是河北省石家庄市正定中学 2020-2021 学年高二上学期第一次月考的题，也是讲义第 3 页题型特征里的那道题。老师说这道题稍微有点难，尤其是 B 选项，把之前讲的动能定理也综合进来了。用到的点：由静止出发的运动方向判断电场力方向，再对比电场方向判断电性；比较电场力做功的正负和多少，用场强大小（斜率）比较力的大小，距离相同时力大则功大。

**题目**：空间存在着方向平行于 $x$ 轴的静电场，A、M、O、N、B 为 $x$ 轴上的点，$OA<OB$，$OM=ON$，AB 间的电势 $\varphi$ 随 $x$ 的分布如图所示，一个带电粒子在电场中仅在电场力作用下从 M 点由静止开始沿 $x$ 轴向右运动，则下列判断正确的是（   ）
A. 粒子一定带负电
B. 粒子一定能通过 N 点
C. AO 间的电场强度小于 OB 间的电场强度
D. 粒子从 M 向 O 运动过程中所受电场力均匀增大

**解法**：

1. 老师说：还是第一步先画电场线。O 点电势最高，电场方向从 O 向左、从 O 向右，是先单调增后单调减两个单调区间，分两段画。
2. A：判断带正电还是带负电，要看电场力方向与电场方向是否相同，相同带正电，相反带负电。粒子在 M 点由静止开始向右运动，说明在 M 点电场力方向向右。M 点在 O 的左边，电场方向向左，与电场力方向相反，所以粒子带负电，A 对。
3. B：画出运动过程：M、O、N 中，OM 等于 ON。从 M 到 O，电场力向右，设为 $F_1$；从 O 到 N，电场方向向右，粒子带负电，电场力方向相反，向左，设为 $F_2$。M 到 O 段 $F_1$ 做正功，O 到 N 段 $F_2$ 做负功，两段距离一样。如果 $F_1>F_2$，第一段做的正功多，合起来做正功，动能增加，N 点有动能，说明一定能到 N 点。所以只要比较 $F_1$ 和 $F_2$ 谁大，就是比较这两段的场强 $E_1$ 和 $E_2$。
4. 比较场强：因为 $OA<OB$，老师画了一个夸张一点的图，OA 这段斜线更陡峭，斜率的大小更大，所以 $E_1>E_2$，$F_1>F_2$。第一段距离相同、力大，正功多；第二段负功少；从 M 到 N 总的做正功，动能增加，N 点有速度，一定能到 N 点，B 对。
5. C：分析 AO 间与 OB 间的电场强度，在分析 B 时已经分析过：$E_{AO}>E_{OB}$，所以 C 不对。
6. D：从 M 到 O，φ-x 图是一条直线，直线斜率不变，斜率的大小就表示场强大小，所以场强不变，电场力是恒力，不是均匀增大，D 不对。选 AB。

**答案**：AB

例题 4 是吉林省延边第二中学 2020-2021 学年高二（上）期末的题，图甲是带电圆环加 x 轴，图乙是 x 轴上的 φ-x 图。老师借它复习：无穷远处电势为零时，整条线电势全为正说明带正电；曲线最高点切线水平、斜率为零，场强为零；比较两点场强看哪点的切线更陡；正电荷受力与电场同向，据此判断各段做功正负，再判断电势能的变化。注意本题要选不正确的。

**题目**：有一个均匀带电细圆环，以圆环圆心 O 为坐标原点，过 O 点且垂直于圆环平面的线为 $x$ 轴，如图甲所示，现测得 $x$ 轴上各点的电势随坐标 $x$ 变化的图像如图乙所示，H、I 分别是 $x$ 轴负、正半轴上的点，且 $HO>OI$，取无穷远处电势为 $0$。以下分析不正确的是（   ）
A. 该圆环带正电
B. $x$ 轴上 O 点的电场强度为零
C. H 点的电场强度一定小于 I 点的电场强度
D. 将一个正的试探电荷沿 $x$ 轴从 H 点移动到 I 点的过程中，电势能先减小后增大

**解法**：

1. 老师说：注意问的是分析不正确的，选错的。还是第一步先画电场线：O 点电势最高，O 往左电势降低，O 往右电势也降低，电场线从 O 指向两边。
2. A：题目说无穷远处电势为 $0$，图中整条线上所有位置电势都是正的。无穷远处电势为零时，正电荷周围电势都是正的，负电荷周围电势都是负的，所以圆环带正电，A 对，不能选。
3. B：O 点的切线是水平的，斜率为零，所以 O 点场强为零。也可以这样想：圆环上均匀带正电，把圆环分成无数个关于圆心对称的小对，每对在中心处的场强都抵消，合起来中心处场强为零。直接用 φ-x 图分析就可以，B 对，不能选。
4. C：I 点和 H 点相比，I 点的切线更陡峭，I 点斜率更大，I 点场强大，所以 H 点的场强一定小于 I 点，C 对，不能选。

**答案**：D
