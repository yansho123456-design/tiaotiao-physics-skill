# 交变电流 第1讲 正余弦交流电（基础课）

讲次代号：jiaobian-01

## 这一讲讲了什么

这一讲是交变电流模块的第一课，弄清什么是交流电，并推出正弦、余弦交流电的表达式。先分清直流和交流：只看电流方向，方向周期性变化就是交流，图线一定在 t 轴上下都有。再讲正余弦交流电：线框在匀强磁场中绕与 B 垂直的轴匀速转动产生，老师从正面看装置，用 v⊥ 推出以线框面与 B 垂直的时刻为 0 时刻时 e=NBSωsinωt，以线框面与 B 平行的时刻为 0 时刻时 e=NBSωcosωt，装置完全一样，只差 0 时刻的选取。判断 sin 还是 cos 不要死记，画 0 时刻的速度方向：v∥B 则 e=0 是 sin，v⊥B 则 e 最大是 cos。系数 NBSω 用谐音你爸是我记。配五道例题：判断哪些是交变电流、由初始位置选 sin 或 cos、改变转速和面积后写新表达式、线圈转到图示位置的电流方向和电动势和变化率和安培力、判断哪种转轴不能产生交流电。最后一个小点是转轴：转轴与 B 平行时本质是旋转切割，电流方向不变，不能产生交流电。

### jiaobian-01-c02　〔概念〕直流电 DC 与交流电 AC：区别只在电流方向是否随时间变化

讲义第 3 页 · 视频 00:30 · 关键词：直流电、DC、交流电、AC、电流方向、i-t 图、正弦交流电 · 题型：概念、读图、判断直流还是交流

老师说，直流电简称 DC，指方向不随时间变化的电流。交流电简称 AC，指方向随时间周期性变化的电流。直流电的两张图：左图在 0 到 T/2 是一段恒定电流，T/2 到 T 电流变小，成为另一段较小的恒定电流，T 之后又变大，电流的大小在变，但方向没有变；右图是电流先增大、再减小、又增大，大小可以变大、变小，都行，方向没有变化，所以它们都表示直流电。交流电的两张图：左图 0 到 T/2 是一段恒定电流，T/2 到 T 图线从 t 轴上方跑到了下方，说明电流方向发生了变化，T 时刻之后图线又回到 t 轴上方，说明方向又变了，电流方向一直在变，这就是交流电；右图是一个正弦交流电，因为它的 i-t 图线是 sin 函数，一段时间电流是一个方向，过了某个时刻图线从 t 轴上方跑到下方，电流开始反向，再过某个时刻又回到上方，电流又反向，也是交流电。

### jiaobian-01-c03　〔方法〕判断直流还是交流：不看电流大小怎么变，只看电流方向

讲义第 3 页 · 视频 02:26 · 关键词：直流电、交流电、电流方向、判断直流交流、大小变化 · 题型：方法、判断直流还是交流

老师说，看一个电流是直流还是交流，不要看电流是在变大还是变小，只看电流的方向：是始终朝着一个方向，还是方向在不停地变化。只要电流的方向在不停地变化，不用管大小怎么变，它就是交流电；方向始终不变，大小再怎么变都是直流电。在 i-t 图上，这个判断落到图线有没有从 t 轴的一侧穿到另一侧，见本讲 c04。

### jiaobian-01-c04　〔结论〕交流电的 i-t 图线特征：t 轴上方、下方一定都有

讲义第 4 页 · 视频 02:55 · 关键词：交流电、i-t 图、t 轴上下都有、电流方向变化时刻、穿过 t 轴 · 题型：结论、读图、判断直流还是交流

老师总结，交流电的图线有一个特征：一定是 t 轴上方、下方都有。如果图线只在 t 轴的上方，或只在下方，就说明电流的方向没有变，不是交流电。图线从 t 轴上方穿到下方，或从下方穿到上方的那个时刻，就是电流方向变化的那个时刻。老师在讲义这页写下的结论是：t 轴上下都有的一定是交流电。

### jiaobian-01-c05　〔例题〕例题 1：四种电流随时间变化的图，哪些是交变电流

讲义第 4 页 · 视频 02:45 · 关键词：交流电、直流电、i-t 图、t 轴上下都有、判断直流交流 · 题型：例题、多选、读图、判断直流还是交流

老师说，这道题考的就是根据图线判断直流还是交流，抓住上下都有就行。老师最后问，到这儿根据图线判断是直流电还是交流电这个点，大家没问题了吧。

**题目**：如图所示的 4 种电流随时间变化图中，属于交变电流的有（　）
A. 锯齿形的 i-t 图，图线只在 t 轴上方
B. 正弦形的 i-t 图，图线始终在 t 轴上方
C. 方波形的 i-t 图，t 轴上方、下方都有
D. 正弦形的 i-t 图，t 轴上方、下方都有
〔整理注：讲义里 A、B、C、D 四个选项是四张图，这里把每张图的形状用文字记在选项后面，图见下面的选项图。〕

**解法**：

1. 先用结论：交流电的图线一定 t 轴上方、下方都有；只在 t 轴一侧的，电流方向没变。
2. A：图线只在 t 轴上方，电流先变大，突然变到 0，再变大，电流方向没有变化，是直流电。
3. B：电流先变大，再变小，再变大，但始终在 t 轴上方，没有穿过 t 轴，只表示电流的大小在变，方向没变，也不是交流电。
4. C：t 轴上方、下方都有，说明电流方向肯定在变，是交流电。
5. D：上方、下方都有，也是交流电。
6. 所以选 C 和 D。

**答案**：CD

### jiaobian-01-c08　〔概念〕推导正弦交流电的设定：匀强磁场、线框匀速转动、以线框面与 B 垂直的时刻为 0 时刻

讲义第 6 页 · 视频 05:13 · 关键词：正弦交流电、表达式推导、0时刻、匀强磁场、角速度、θ=ωt、线框面与磁场垂直、正面图 · 题型：概念、推导

老师说，装置是这样的：左边是 N 极，右边是 S 极，把 N、S 中间的磁场近似当成匀强磁场来分析，B 的方向从 N 指向 S，水平方向从左到右。线框 abcd 以 OO′ 为轴，在磁场里做匀速圆周运动，转动方向是逆时针，设角速度是 ω，目标是推出电动势 e 随时间 t 变化的函数表达式。
第一件事是定 0 时刻：以线框的平面与磁场垂直的时刻作为 0 时刻，也就是线框转到竖直位置的时候，因为 B 是水平的，线框竖直时线框面与 B 垂直。

设经过时间 t，线框从 0 时刻转到图中位置，转过的角度设为 θ。老师说，角速度的定义就是单位时间转过的角度，用单位时间转过的角度乘以转动的时间，就是转过的总角度，所以 θ=ωt。

### jiaobian-01-c09　〔方法〕线框转到任意位置：把 CD、AB 边的速度分解成 v∥ 和 v⊥，只取 v⊥，两边电动势方向相同要叠加

讲义第 6 页 · 视频 08:10 · 关键词：动生电动势、速度分解、v垂直、v平行、右手定则、电动势叠加、切割磁感线、正交分解 · 题型：方法、推导、判断电流方向

老师说，线框转动时 CD 边和 AB 边在切割磁感线，产生感应电流。转到图中位置时，CD 边的速度方向是图中红箭头方向，AB 边的速度方向也是红箭头方向，它们与 B 都不垂直。前面讲过，算切割的动生电动势要用与 B 垂直的那个速度，速度不垂直就要做正交分解：把速度分解成与 B 平行的 v∥ 和与 B 垂直的 v⊥，只要 v⊥，不要 v∥。AB 边也一样分解成 v∥ 和 v⊥，也只要 v⊥。
判断电流方向用右手定则。先看 CD 边：让 B 穿过掌心，此时速度方向朝下，大拇指朝下，四指指向是从 c 到 d，所以电流在 CD 边中由 c 流向 d，再从 d 流向 a，再流到 b。再看 AB 边：大拇指朝上，电流方向由 a 指向 b。两边电流沿 a、b、c、d 绕行是同一个方向，所以 CD 边、AB 边产生的电流方向一样，两边的电动势要叠加。

### jiaobian-01-c10　〔方法〕先算 CD 边的电动势：E_CD = B·L_CD·v⊥，v⊥ = v sinθ，v = ω·L_AD/2，最后得 (BSω/2) sinωt

讲义第 6 页 · 视频 10:30 · 关键词：E_CD、动生电动势、v垂直=v sinθ、线速度 v=ωr、面积 S、正弦交流电、表达式推导 · 题型：方法、推导、计算

老师说，先算 CD 边的电动势：E_CD 等于 B 乘以切割长度 L_CD 再乘以 v⊥，即 $E_{CD}=B L_{CD} v_\perp$。
第一步求 v⊥。老师在图上标出，v 与水平方向的夹角也是 θ（老师用错角和互余的角相等来说明），θ 的对边是 v⊥，斜边是 v，所以 $v_\perp=v\sin\theta$。
第二步求 v。v 是线速度，等于角速度乘以半径，当线框这样转时，半径是 AD 边的一半（从正面看，这一段长度就是 AD 边的一半），所以 $v=\omega\cdot\dfrac{L_{AD}}{2}$。
第三步代入。v⊥ 就是 $\omega\cdot\dfrac{L_{AD}}{2}\sin\theta$，再把 θ 换成 ωt，得 $v_\perp=\omega\cdot\dfrac{L_{AD}}{2}\sin\omega t$。
第四步代回 E_CD：$E_{CD}=B L_{CD}\cdot\omega\cdot\dfrac{L_{AD}}{2}\sin\omega t$。这里 L_CD 乘以 L_AD，对于矩形线框就是面积 S，所以 $E_{CD}=\dfrac{BS\omega}{2}\sin\omega t$。
AB 边的过程一模一样：它的夹角同样是 θ，v⊥ 也等于 v sinθ，所以 $E_{AB}=\dfrac{BS\omega}{2}\sin\omega t$。

### jiaobian-01-c11　〔易错〕sin 里面的 ωt 是一个整体，不是先 sinω 再乘以 t

讲义第 6 页 · 视频 11:57 · 关键词：sinωt、ωt是整体、表达式书写、正弦交流电 · 题型：易错、表达式

老师提醒，把 θ 换成 ωt 代进去的时候要注意，ωt 是一个整体，两个都在 sin 里面，写成 sinωt，它可不是说先 sinω 再乘以 t。

### jiaobian-01-c12　〔结论〕正弦交流电的表达式：e = NBSω sinωt（以线框面与 B 垂直的时刻为 0 时刻）

讲义第 6 页 · 视频 13:19 · 关键词：正弦交流电、e=NBSωsinωt、表达式、匝数 N、电动势叠加、瞬时表达式 · 题型：结论、表达式、推导

老师说，CD 边和 AB 边的电流方向一样、要叠加，所以总电动势 $e=E_{CD}+E_{AB}=BS\omega\sin\omega t$。这时 e 与 t 的关系是一个 sin 函数，所以叫正弦交流电。老师提醒，上面举的是单匝线框，如果线框有 N 匝，算 e 的时候还要乘以匝数 N，更通用的表达式是 $e=NBS\omega\sin\omega t$，这就是正弦交流电的函数表达式。〔整理注：式中 N 是匝数，B 是匀强磁场的磁感应强度，S 是线框面积，ω 是线框转动的角速度。〕

### jiaobian-01-c13　〔结论〕余弦交流电的表达式：e = NBSω cosωt（以线框面与 B 平行的时刻为 0 时刻）

讲义第 7 页 · 视频 14:14 · 关键词：余弦交流电、e=NBSωcosωt、表达式、0时刻、线框面与磁场平行、v垂直=v cosθ · 题型：结论、表达式、推导

老师说，说完了正弦，再说余弦。产生正弦和余弦交流电的装置是一模一样的，没有任何区别，唯一的区别是 0 时刻选的线框位置不一样：刚才是以线框面与 B 垂直的时刻作为 0 时刻，现在是以线框面与 B 平行的时刻作为 0 时刻，也就是线框转到水平位置的时候（图中绿色虚线）。
再推一次关系：
（1）从 0 时刻转到图示位置，转过的角度还是 θ=ωt。
（2）速度还是分解成平行的 v∥ 和垂直的 v⊥，只取 v⊥。
（3）和刚才唯一的区别：这时 v⊥ 与 v 的关系变了，老师说这个 v⊥ 变成了邻边，所以 $v_\perp=v\cos\theta$。
（4）剩下的步骤一模一样，所以结果相比刚才只是把 sin 变成了 cos：单匝时 $e=BS\omega\cos\omega t$，N 匝时 $e=NBS\omega\cos\omega t$。这时表达式是余弦，所以叫余弦交流电。

配图：jiaobian-01-cosine-front-view

### jiaobian-01-c14　〔结论〕正弦和余弦交流电没有本质区别：装置一样，只看 0 时刻选哪个位置

讲义第 7 页 · 视频 16:20 · 关键词：正弦交流电、余弦交流电、0时刻、没有本质区别、线框面与B垂直、线框面与B平行 · 题型：结论、概念

老师总结，正弦交流电和余弦交流电没有本质区别，使用的装置是一样的，本质完全一样，唯一的区别就是开始的那个 0 时刻你选哪个位置：以线框的面与 B 垂直的时刻作为 0 时刻，表达式就是 sin；以平行的时刻作为 0 时刻，就是 cos。老师说，就这么简单。老师同时提醒，这一句不建议死记，快速判断的办法见本讲 c15。

### jiaobian-01-c15　〔方法〕快速判断 sin 还是 cos：画出 0 时刻线框切割边的速度方向，看 v 与 B 是否平行

讲义第 8 页 · 视频 16:57 · 关键词：判断sin还是cos、0时刻、v∥B、v⊥B、速度与磁场关系、不切割、函数值、初始位置 · 题型：方法、判断、判断 sin 还是 cos、选表达式

老师教的小妙招：分析 0 时刻 v 和 B 的关系就行了，不用记。方法是画一画。
以线框面与 B 垂直的时刻作为 0 时刻：画 B 水平向右，线框画成竖直，设线框这样转，0 时刻线框在这个位置，上面那个点的速度方向水平向左，下面那个点的速度方向水平向右，这时切割的两条边速度与 B 平行，v∥B，不切割，电动势为 0，0 时刻函数值是 0。sin 函数在 0 时刻值为 0，所以它肯定是 sin 函数。
以线框面与 B 平行的时刻作为 0 时刻：B 还是水平向右，线框画成水平，线框还是这样转，0 时刻切割的这两条边速度方向与 B 垂直，v⊥B，产生的电动势最大，函数值也最大。cos 函数在 0 时刻函数值最大，所以它是 cos 函数。
所以判断时，画一个 0 时刻速度方向的图，看 v 与 B 是否平行：平行，e=0，是 sin；垂直，e 最大，是 cos。老师在讲义这页写的结论就是：0 时刻 B、v 平行，不切割，函数值为 0，对应 sin 函数；0 时刻 v⊥B，E 最大，函数值最大，对应 cos 函数。

### jiaobian-01-c20　〔例题〕例题 3：角速度提高一倍、面积减小一半，电动势表达式变成什么

讲义第 11 页 · 视频 23:05 · 关键词：Em=NBSω、最大电动势、角速度变化、面积变化、表达式、交流发电机、小写 e · 题型：例题、单选、表达式、改变转速和面积

老师说，这个题直接用 $E_{\rm m}=NBS\omega$：系数里 S 和 ω 变化后乘积不变，里面的 ω 换成 2ω。关键是把你爸是我这个系数记牢，并且不要忘了 sin 里面的 ω 也跟着变。

**题目**：交流发电机在工作时电动势为 $e=E_{\rm m}\sin\omega t$，若将发电机的角速度提高一倍，同时将线框所围面积减小一半，其他条件不变，则其电动势变为（　）
A. $e'=E_{\rm m}\sin\omega t$
B. $e'=2E_{\rm m}\sin\omega t$
C. $e'=E_{\rm m}\sin2\omega t$
D. $e'=\dfrac{E_{\rm m}}{2}\sin2\omega t$

**解法**：

### jiaobian-01-c21　〔例题〕例题 4：线圈转到图示位置时，电流方向、电动势、磁通量变化率、安培力

讲义第 12 页 · 视频 24:16 · 关键词：感应电流方向、右手定则、点叉表示方向、磁通量变化率、安培力、最大电动势、v⊥B · 题型：例题、多选、判断电流方向、判断电动势、判断安培力

B. 线圈中的感应电动势为 $2nBL_2\omega$
C. 穿过线圈的磁通量随时间的变化率最大

### jiaobian-01-c27　〔结论〕转轴与 B 平行为什么不能：本质是旋转切割模型，电流方向始终不变，是直流

讲义第 13 页 · 视频 28:52 · 关键词：转轴与磁场平行、旋转切割模型、E=BR²ω/2、左视图、电源正负极、直流电、不能产生交流电 · 题型：结论、推导、易错、判断能否产生交流电

老师说，当线框这样转时，线框上与转轴垂直的两条边在切割磁感线，产生电动势。分析左边这条边，画一个左视图：左视图里磁场变成垂直纸面向里，是个叉场，这条边绕中间这个点转动，底下这样转，上面这样走。这种转法老师问眼不眼熟，就是前面讲过的旋转切割模型。老师设这一段长度是 R，则这个边产生的电动势 $E=\dfrac{1}{2}BR^2\omega$，电流方向是从转动的中心往外，相当于中心是电源的负极，两个端点是电源的正极。给它接两根导线挂一个外电路，转动过程中外电路里电流的方向始终不变，比如观察流过这个电阻的电流，始终是从上往下流，没有一会上一会下。电流方向没有发生变化，所以它不是交流电，而是直流电。
