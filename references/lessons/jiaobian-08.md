# 交变电流 第8讲 LC振荡电路（基础课）

讲次代号：jiaobian-08

## 这一讲讲了什么

这是交流电部分的最后一讲，讲 LC 振荡电路。先说概念：振荡电流是频率很高的交流电，能产生振荡电流的电路叫振荡电路，最简单的是由电感线圈和电容器串联而成的 LC 振荡电路。然后老师用一个振荡周期的四个阶段（放电、充电、放电、充电）配 i-t 图和 q-t 图，讲清楚电容器先带电、线圈自感阻碍电流变化，所以放电时电流从 0 逐渐增大、充电时电流逐渐减小，最后浓缩成做题的核心一句话：电流增大对应电容器放电，电流减小对应电容器充电。再讲振荡周期 T=2π√(LC)，L、C 越大周期越大、频率越小，题里问周期还是频率要看清；再讲能量转化，电流增大时电场能减小、磁场能增大，电流减小时相反。最后四道例题：由电流方向和增减判断极板电性、电场方向、电势高低，由 i-t 图分时间段判断，以及给 q-t 图的题先画 i-t 图；另外提到 LC 振荡电路不是开放电路，不能有效发射电磁波。下节课开始讲变压器。

### jiaobian-08-c04　〔概念〕阶段①：放电，电流逆时针、从 0 逐渐增大，电荷量逐渐减小到 0

讲义第 4 页 · 视频 02:07 · 关键词：放电、第一阶段、自感、线圈阻碍电流、电流从零逐渐增大、电荷量减小、逆时针电流、电容器放电 · 题型：概念、振荡过程、判断电流方向、i-t 图问题、q-t 图问题

老师说，第一个阶段，电容器带电，上极板带正电、下极板带负电，而且正极板到负极板之间有通路，所以电容器放电。把电容器当电源，电流从正极板出发、从负极板回来，电路里的电流方向是逆时针。逆时针对应 i-t 图的负方向，所以这一段图线画在 t 轴下方。如果这里没有线圈，电容器放电的电流会瞬间达到最大，但这里有线圈：放电电流流过线圈，相当于线圈里的原电流从无到有，线圈会产生自感，自感阻碍原电流，所以电流不会一瞬间达到最大，要从 0 开始逐渐增加。电容器放电，电容器带的电荷量就在逐渐减小，q-t 图这一段从最大值逐渐减小，减到 0 的时候第一个阶段放电结束，这时电容器不带电了。

### jiaobian-08-c05　〔概念〕阶段②：充电，自感电流仍逆时针、逐渐减小，给电容器反向充电

讲义第 4 页 · 视频 03:54 · 关键词：充电、第二阶段、自感电流、增反减同、电流逐渐减小、电容器反向充电、下极板带正电、q-t 图在轴下方 · 题型：概念、振荡过程、判断极板电性、i-t 图问题、q-t 图问题

老师说，第一阶段放电结束的瞬间，原来逆时针的电流要消失，流过线圈的电流突然消失，线圈又会产生自感。老师说按照减同来分析，原电流减小，感应电流的方向和原电流方向相同，所以会产生一个逆时针方向的感应电流。〔整理注：减同是楞次定律口诀增反减同的后半句。〕老师提醒，之前讲自感的时候讲过，自感开始的瞬间，感应电流的大小和原电流一样，然后自感逐渐减弱。所以第二个阶段电流接着第一阶段结束时的那个值，逐渐减小，减到 0 时自感结束。这时电容器已经不带电了，这个逆时针的感应电流会给电容器充电：把电流当成正电荷的移动，正电荷会流到电容器的下极板上，给下极板充上正电，上极板就带负电。所以第二个阶段是电容器充电，电荷量从 0 逐渐增加，因为上极板带负电，q-t 图这一段画在 t 轴下方。第二阶段线圈自感结束以后，电容器充满电，自感电流消失，下极板带正电、上极板带负电。

### jiaobian-08-c06　〔概念〕阶段③④：下板带正电开始反向放电、再充电，方向都与①②相反

讲义第 4 页 · 视频 05:59 · 关键词：第三阶段、第四阶段、顺时针电流、上极板充正电、放电、充电、反向放电、回到初始状态 · 题型：概念、振荡过程、判断电流方向、判断极板电性、i-t 图问题、q-t 图问题

老师说，第二阶段结束时电容器下极板带正电、上极板带负电，电容器又该放电了，这就是第三个阶段，又是放电。这时电容器下极板带正电，电流从下极板流出、从上极板流入，电流方向是顺时针，对应 i-t 图的正方向，画在 t 轴上方。同样因为有线圈，电流需要从 0 开始逐渐增加，电荷量逐渐减小，这是第三阶段的图线。放电结束、电流消失的瞬间，线圈又会产生自感，产生一个和之前方向相同的感应电流，也就是顺时针，自感逐渐减弱，所以第四阶段电流逐渐减小。这个电流给电容器的上极板充上正电，电容器的电荷量从放完电的 0 逐渐增加，因为这时上极板带正电，q-t 图在 t 轴上方，又是一个充电的过程。充电结束，又回到了上极板带正电、下极板带负电的初始状态。

### jiaobian-08-c07　〔结论〕四个阶段循环往复形成周期性的振荡电流；理想情况永远振荡，实际有电阻则最大值逐渐减小到 0

讲义第 4 页 · 视频 07:37 · 关键词：周期性振荡电流、理想情况、没有电阻、没有能量损耗、实际情况、导线电阻生热、最大值逐渐减小、阻尼振荡、衰减振荡 · 题型：结论、判断、概念、振荡电流图像

老师说，电路回到上极板带正电、下极板带负电的状态以后，又会重复放电、充电、放电、充电，一直循环，就形成了周期性的振荡电流，这就是 LC 振荡电流振荡的过程。老师提醒注意：在理想情况下，所有导线都没有电阻，振荡的过程没有能量损耗，这个振荡应该会永远持续下去；但在现实情况下，导线上肯定有电阻，只要有电流通过就会生热，生热就是能量的消耗，所以实际的振荡电流是一个最大值逐渐减小、最后减到 0 的图线（老师在黑板上画的就是这样一条衰减的曲线）。老师说，振荡的过程其实很复杂，但是做这种题不需要清楚每一个细节，只需要把握住下一条的一句话就够了，见 c08。

### jiaobian-08-c08　〔口诀〕核心一句话：电流增大对应电容器放电，电流减小对应电容器充电

### jiaobian-08-c09　〔结论〕振荡周期 T=2π√(LC)，频率是周期的倒数：L、C 越大，周期越大

讲义第 6 页 · 视频 10:07 · 关键词：振荡周期、振荡频率、T=2π√LC、f=1/(2π√LC)、自感系数、电容、周期公式、周期的倒数 · 题型：结论、公式、计算、判断

老师说，振荡周期指的是振荡电流的周期，这是一个考点。周期公式是 $T=2\pi\sqrt{LC}$，其中 L 是线圈的自感系数，C 是电容器的电容。根据这个公式，线圈的自感系数越大、电容器的电容越大，振荡的周期就越大。频率是周期的倒数，所以振荡频率 $f=\dfrac{1}{2\pi\sqrt{LC}}$，L 或 C 越大，频率越小。〔整理注：老师口头讲频率公式时转录文字顺序混乱，这里按老师板书写的 $f=\dfrac{1}{2\pi\sqrt{LC}}$ 整理，也就是周期的倒数。〕

### jiaobian-08-c10　〔方法〕分析 L 或 C 变大变小对周期、频率的影响：直接用周期公式

讲义第 6 页 · 视频 10:37 · 关键词：增大 L、增大 C、周期变大、频率变小、周期公式的应用、仅增大自感系数、仅增大电容 · 题型：方法、判断、单选、周期频率变大变小

老师说，经常有题目问：如果增大了 L 或者增大了 C，这个周期是变大还是变小，这个频率是变大还是变小。分析这个问题的时候，就用周期公式 $T=2\pi\sqrt{LC}$ 来分析。做法是先看清题目问的是周期还是频率；周期随 L、C 同向变化，增大 L 或 C 周期变大；若问的是频率，记住频率是周期的倒数，增大 L 或 C 频率变小。例题 1 的 C、D 选项就是这样，仅增大线圈的自感系数或者仅增大电容器的电容，振荡频率都减小，所以 C、D 都不对。

### jiaobian-08-c11　〔结论〕振荡过程中的能量转化：电流增大时电场能转化为磁场能，电流减小时磁场能转化为电场能

讲义第 7 页 · 视频 11:01 · 关键词：能量转化、电场能、磁场能、电场能转化为磁场能、磁场能转化为电场能、电荷量与电场能、电流与磁场 · 题型：结论、判断、单选、能量转化

老师说，分析能量转化还是分电流增大的阶段和电流减小的阶段。先考大家：电流增大对应电容器的充电还是放电？是放电，这是核心。电容器放电，两个极板上的电荷量在减小，电荷量越小，电容器里的电场能就越小，所以电流增加的时候电场能在减小。减小的电场能去哪了？电流在增加，线圈上的磁场会变强，电流越大磁场越强，所以电场能转化成了磁场能，也就是电流增加的过程是电场能减小、磁场能增大的过程。电流减小的时候，对应电容器的充电，电容器的电场能在增大，磁场能就减小。这就是振荡过程中的能量转化。

### jiaobian-08-c12　〔方法〕由电流方向和增减判断极板电性、电场方向、电势高低：先定充放电，再看电流流入哪块极板

讲义第 8 页 · 视频 13:27 · 关键词：判断极板电性、判断电场方向、判断电势高低、电流流入负极板、放电、充电、正极板电势高、场强方向 · 题型：方法、判断、单选、多选、判断电场方向、比较电势高低、判断极板电性

老师说，题里常给一个 LC 回路，图上标出电流方向，再说电流正在增大或正在减小，让你判断电容器哪块极板带什么电、板间电场方向、两点电势高低。照老师的讲法分三步。第一步，由电流增减定充放电：电流增大是放电，电流减小是充电（c08）。第二步，由充放电和图上电流流入、流出的极板定电性：放电时电流从正极板出、从负极板回，所以电流流入的那块极板是负极板；充电时正好相反，电流从负极板出、流回正极板，所以电流流入的那块是正极板，流出的是负极板。第三步，板间电场由正极板指向负极板；比较电势高低时，只要看电容器哪块极板是正极板、哪块是负极板，正极板电势高，靠近正极板的点电势高。例题 1 到例题 3 都是这个思路。〔整理注：这一条是把老师在例题 1 的 B、例题 2 的 B 和 D、例题 3 的 B 和 D 里的分析步骤整理在一起，老师没有单独列成三步。〕

### jiaobian-08-c13　〔易错〕题里问的是周期还是频率要看清，不要搞混

讲义第 8 页 · 视频 14:31 · 关键词：周期还是频率、频率是周期的倒数、增大 L、增大 C、易混 · 题型：易错、判断、单选

老师提醒，例题 1 讲到 C、D 选项时，一定要注意看清楚到底问的是频率还是周期，不要搞混了。周期公式是 $T=2\pi\sqrt{LC}$，频率是周期的倒数 $f=\dfrac{1}{2\pi\sqrt{LC}}$，增大 L 或 C 时周期变大、频率变小，方向相反。老师在周期公式那一段也说过同样的话：分析的时候看清楚它到底分析的是周期还是频率，若是频率的话，记住是周期的倒数。

### jiaobian-08-c15　〔例题〕例题 2：甲、乙、丙、丁四个 LC 电路，判断电压、电场方向、磁场强弱

老师说，这道题一口气给了四个振荡电路。做法就是牢牢把握住电流增大对应电容器放电。老师说，现在给你一个振荡电路，告诉你电流正在增大、正在减小，这类题会分析了吧。老师在这里又重复了一遍：电流增大，对应电容器的放电。

**题目**：甲、乙、丙、丁四个 LC 振荡电路，某时刻振荡电流 $i$ 的方向如图中箭头所示。下列对各回路情况的判断正确的是（　）
A. 若甲电路中电流 $i$ 正在增大，则该电路中电容器两端的电压必定在增大
B. 若乙电路中电流 $i$ 正在增大，则该电路中电容器的电场方向必定向下
C. 若丙电路中电流 $i$ 正在减小，则该电路中线圈周围的磁场必定在增强
D. 若丁电路中电流 $i$ 正在减小，则该电路中电容器的电场方向必定向上

5. 选 BD。
