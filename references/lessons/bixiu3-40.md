# 必修3 第40讲 E-x图像（题型技巧课）

讲次代号：bixiu3-40

## 这一讲讲了什么

这一讲是静电场部分最后一节课，讲电场图像里的 E-x 图像，题型是已知 x 轴上场强 E 随 x 的分布图，分析 x 轴上各点的各种物理量。老师说，这节课要和上一节 φ-x 图像一起听。分析 E-x 图像有两个核心。核心一是画出 x 轴上的电场线：按图像与 x 轴的交点分段，E 为负的一段箭头指向 x 轴负方向，E 为正的一段指向正方向。核心二是图像与 x 轴围成的面积表示电势差，老师用小矩形加微元法证明，并类比 v-t 图的面积表示位移；电势差的下标要按电场线方向从高电势写到低电势，保证面积是正值。三道例题依次是对称折线图比较各点电势（面积相等推电势相等）、等量异种电荷的 E-x 图判断 c、d 两点的场强和电势、两个点电荷的 E-x 图判断零电势、电性、电荷量比和两点电势高低。老师说，E-x 图考频比 φ-x 图还低，这三道题就够了。

### bixiu3-40-c01　〔概念〕E-x 图像的题型特征：给各位置的场强，分析 x 轴上各点的物理量

讲义第 3 页 · 视频 00:46 · 关键词：E-x图像、场强随位移变化图像、电场图像、题型特征、x轴上的电场、E-x图、场强、E · 题型：概念、识图

老师说：E-x 图的特征跟上一节课的 φ-x 图很像，都只研究电场里一条线上的各个点，也就是 x 轴上的各点。区别是上节课的图体现各个位置的电势，这节课换成各个位置的场强。题目会告诉你各位置的场强对应哪个图像，然后让你分析 x 轴上各点的各个物理量的变化。老师把题型特征写作：已知 x 轴上场强随 x 的分布图，分析 x 轴上各种物理量。老师说，对 E-x 图的分析跟上节课一样，也是两个核心。老师强烈建议这节课和上节课放在一起听，先听上节课再听这节课，一口气把电场图像问题听完，效果更好。讲义上写着这是电场综合问题里电场图像问题的第二节课，也是整个静电场部分的最后一节课。

### bixiu3-40-c02　〔方法〕核心一：画出 x 轴上的电场线，按图像与 x 轴的交点分段，E 的正负定方向

讲义第 4 页 · 视频 01:15 · 关键词：E-x图像、x轴电场线、画电场线、分段、场强正负、电场方向、核心1、核心一、场强、E · 题型：方法、识图、画图

老师说：核心一跟上节课一样，也是画出 x 轴上的电场线，只不过上节课基于电势来画，这节课基于场强来画，反倒更简单。用讲义第 4 页左图举例：这个图就是把上节课那个图的纵坐标电势换成场强。图像与 x 轴有两个交点。第一个交点左边这一段，每个点的纵坐标都是负的，也就是这一段 x 轴上每个点的场强都是负的，场强为负说明场强指向负方向。老师强调，E-x 图只能表示 x 轴这个一维空间上的分布，一维空间只有两个方向，x 轴箭头向右，向右就是正方向，向左就是负方向，所以这一段的电场方向是向左的箭头。两个交点中间这一段，所有点的纵坐标都是正的，场强方向是正方向，是向右的箭头。第二个交点右边，纵坐标又都成负的，每个点场强都是负方向，还是向左的箭头。这样 x 轴上的电场线就画出来了：第一段向左，第二段向右，第三段向左。提炼方法有三条。第一，要分段，但不像上节课按单调区间分，直接按图像与 x 轴的交点分段，因为交点左右两边一定是一正一负，从正变到负或从负变到正一定会跟 x 轴有交点，也就是按图像的正负来分段。第二，这一段场强都是负的，就画指向 x 轴负方向（向左）的箭头。第三，这一段场强都是正的，就画指向 x 轴正方向（向右）的箭头。老师说，这比上节课画的两条线还要简单一些，这是这一期最重要的一个点，每次做这类题，第一件事就是先把 x 轴上的电场线画出来。

### bixiu3-40-c05　〔结论〕核心二：E-x 图像与 x 轴围成的面积表示两点间的电势差

### bixiu3-40-c06　〔方法〕面积表示电势差的证明：近似成小矩形，距离远了就分割成很多小矩形再相加

讲义第 5 页 · 视频 04:56 · 关键词：微元法、面积、电势差、E-x图像、匀强电场、U=Ed、v-t图像、位移、类比、电压、场强、E · 题型：推导、方法、概念

老师说：先选两个点 $x_1$、$x_2$，离得很近，图像与它们围成的面积是一块不规则的面积。因为很近，可以把底抹平，近似成一个小矩形。因为距离很短，可以把 $x_1$ 到 $x_2$ 看成匀强电场；场强可能不是处处相同，但差别不大，这是微元法的思想，足够小的时候场强可以当成一样。小矩形的面积是它的底（两点间距离 $d$）乘高（场强 $E$），$S=Ed$。而 $Ed$ 就是电势差 $U$，所以这个小矩形的面积表示 $x_1$、$x_2$ 的电势差。如果 $x_1$、$x_2$ 之间距离远了，用一个矩形近似误差大，那就分割成很多个小矩形。每个小矩形的面积表示这一小段的电势差，从左往右一个个过，把所有小矩形的面积加起来，$S_{总}=U_{x_1x_2}$。老师把这个类比到 v-t 图：取一个小矩形，近似认为这一小段时间内做匀速直线运动，小矩形的面积就是这一段的位移，整段面积就表示这一段时间内的位移，所以 v-t 图面积表示位移，用微元法很容易证明。老师说，大家用微元法的思想就能证明，这里不需要背。

配图：bixiu3-40-area-small、bixiu3-40-area-many、bixiu3-40-area-vt

### bixiu3-40-c07　〔方法〕电势差下标怎么写：按电场线方向从高电势写到低电势，面积都写成正的

讲义第 5 页 · 视频 07:48 · 关键词：电势差、面积、电势高低、沿电场线电势降低、U从高到低、E-x图像、电压、电势、φ · 题型：方法、识图、列式

老师说：怎么确定哪个点电势高、哪个点电势低呢，根据第一步画电场线的箭头来确定。例如 $x_1$、$x_2$ 在中间这一段，这一段电场线向右，肯定是 $x_1$ 电势高，写成 $U_{x_1x_2}$。如果 $x_1$、$x_2$ 在右边那一段，那一段电场向左，沿电场线方向电势降低，越往右电势越高，$x_2$ 电势高，就得写成 $U_{x_2x_1}$。这时候面积都写成正的就行，因为从高电势到低电势写，电势差一定是正的。老师说，写电势差的时候还是养成好习惯，尽量都写成从高电势到低电势的电势差，保证它是正的，会比较简单。〔整理注：这是在 E-x 图例题里把面积翻译成电势的办法，见例题 1、例题 3。〕

### bixiu3-40-c08　〔方法〕由 x 轴上的电场线方向推场源电性：电场线从场源指向外是正电荷，指向场源是负电荷

讲义第 7 页 · 视频 12:09 · 关键词：场源电荷、电性判断、等量异种电荷、同种电荷、x轴电场线、E-x图像、电荷、Q、电场线 · 题型：方法、判断、识图

老师说：例题 2 里已知 a、b 两点各有一个场源，能根据这两个场强方向把场源带正电还是负电推出来。左边那一段电场线向左，离 a 近，这条电场线一定是 a 点的场源发出的；它从场源指向外，说明 a 肯定带正电，因为正电荷是一个发散的电场，从自己出发往外指。b 点右边的电场线向左，指向 b，指向场源，说明 b 带负电。所以两个场源一正一负，是等量异种电荷的电场分布，再把两个场源连线上的电场线补出来，从正指向负。例题 3 也是这样：电场线都是从场源往外发出，所以两个场源都是正电荷。用法：先按核心一画出电场线，再看场源两侧的箭头是背离场源还是指向场源。

### bixiu3-40-c09　〔易错〕场强为 0 的点电势不一定为 0；两个同种正电荷连线上电势不可能为 0

讲义第 8 页 · 视频 14:33 · 关键词：场强为零、电势为零、电势不一定为零、两个正点电荷、E-x图像、电势、φ、场强、E · 题型：易错、判断、选择题

老师说：注意，E-x 图像与 x 轴的交点说明这个点的场强为 0，但场强为 0，电势可不一定为 0，这两个不是一回事。例题 3 的 A 项就是这个坑：2a 处图像与 x 轴相交，场强为零，但电势不一定为零。老师还推了一下：两个场源都是正电荷，在整个空间中除了无穷远处电势为 0，整个空间的电势都是正的，所以它们中间连线上的电势是不为 0 的。所以 A 项不对。

### bixiu3-40-c10　〔方法〕图像与 x 轴的交点是场强为 0 的点：用两个场源的场强叠加为零求电荷量之比

讲义第 8 页 · 视频 15:38 · 关键词：场强为零、场强叠加、点电荷场强、电荷量之比、E-x图像、E=kQ/r^2、电荷、Q · 题型：方法、计算、选择题

老师说：要求两个电荷量的关系，就基于场强为 0 的这个点来分析。两个场源在 $2a$ 处产生的场强合起来为 0。设左边是 $Q_1$、右边是 $Q_2$。$Q_1$ 在 $2a$ 处的场强 $E_1=\frac{kQ_1}{(2a)^2}$，因为它到 $2a$ 的距离是 $2a$；$Q_2$ 在 $2a$ 处的场强 $E_2=\frac{kQ_2}{a^2}$，因为它在 $3a$ 处，到 $2a$ 的距离是 $a$。两个场强能抵消，所以 $\frac{kQ_1}{(2a)^2}=\frac{kQ_2}{a^2}$，$k$ 约掉，$\frac{Q_1}{4a^2}=\frac{Q_2}{a^2}$，$a^2$ 约掉，得 $Q_1=4Q_2$。所以是 4 倍，不是 2 倍。〔整理注：讲义 C 项写成 $Q_1$ 是 $Q_2$ 的 2 倍，是一个错误选项。〕

### bixiu3-40-c11　〔方法〕比较不在同一电场线两侧的两点电势：把各自到同一点的电势差，再转换成电势去比

讲义第 8 页 · 视频 16:54 · 关键词：面积、电势差、电势高低、比较电势、E-x图像、转换电势差为电势、电势、φ · 题型：方法、判断、选择题

老师说：例题 3 的 D 项要比较 $1.5a$ 和 $2.5a$ 处的电势高低，这是这节课稍微难一些的一类。做法是利用面积，找这两个点到同一点（这里是 $2a$）的电势差，再把电势差转换成电势去分析。步骤：先在右边画一个大点的图，标出 O、a、2a、3a，中间的点是 $1.5a$、$2.5a$。按图像画，从 a 到 2a 画得平缓一些，从 2a 到 3a 画得陡峭一些。设 $1.5a$ 到 $2a$ 之间的面积为 $S_1$，$2a$ 到 $2.5a$ 之间的面积为 $S_2$。看含义：左边那段电场线向右，所以 $1.5a$ 的电势高于 $2a$，$S_1=\varphi_{1.5a}-\varphi_{2a}$；右边那段电场线向左，$2.5a$ 的电势高于 $2a$，$S_2=\varphi_{2.5a}-\varphi_{2a}$。再比较面积：肉眼一看，$S_2$ 大，因为下面这段曲线更陡峭，高要高一些，所以一定是 $S_2>S_1$。即 $\varphi_{2.5a}-\varphi_{2a}>\varphi_{1.5a}-\varphi_{2a}$，两边 $-\varphi_{2a}$ 约掉，得 $\varphi_{2.5a}>\varphi_{1.5a}$，也就是 $1.5a$ 处的电势小于 $2.5a$ 处的电势。老师说，这个题好好总结一下，以后类似的题都会做了。

### bixiu3-40-c13　〔例题〕例题 1：关于 O 点对称的 E-x 折线图，判断各点电势

讲义第 6 页 · 视频 08:41 · 关键词：E-x图像、对称电场、面积、电势差、电势高低、沿电场线电势降低、x轴电场线、电势、φ · 题型：例题、判断、选择题

考点是先画 x 轴电场线判断电势高低，再用面积表示电势差比较对称两点。老师强调，重点是用面积表示电势差这一点。〔整理注：讲义图中 $x_1$ 和 $x_3$ 两点的场强相等，但场强相等不等于电势相等，要看它们在电场线上的位置。〕

**题目**：空间有一沿 x 轴对称分布的电场，其电场强度 E 随 x 变化的图象如图所示，下列说法正确的是（   ）
A. O 点的电势最低
B. $x_1$ 和 $x_3$ 两点的电势相等
C. $x_2$ 和 $-x_2$ 两点的电势相等
D. $x_2$ 的电势最高

**解法**：

1. 第一步画 x 轴电场线：O 点是图像与 x 轴的交点，O 右边 E 都是正的，是向右的箭头；O 左边 E 都是负的，是向左的箭头。这个电场关于 O 对称分布，电场线是从 O 往两边指。
2. A 项：沿着电场线的箭头方向电势降低，箭头从 O 往两边指，O 往左电势降低，O 往右电势也降低，所以 O 点电势应该最高，A 不对。D 项也不对，电势最高的应该是 O。
3. B 项：$x_1$、$x_3$ 两点在同一条电场线上，沿电场线箭头电势降低，应该是 $x_1$ 电势高、$x_3$ 电势低，B 不对。
4. C 项用面积分析：图像是对称的，找出 $x_2$ 和 $-x_2$，O 到 $-x_2$ 的三角形面积与 O 到 $x_2$ 的三角形面积相等。左边三角形面积表示 $U_{O,-x_2}$，注意从高往低写，右边三角形面积等于 $U_{O,x_2}$，两者相等。拆开写成 $\varphi_O-\varphi_{-x_2}=\varphi_O-\varphi_{x_2}$，$\varphi_O$ 消掉，得 $\varphi_{-x_2}=\varphi_{x_2}$，两点电势相等，C 正确。
5. 老师给的另一种想法：图是对称的，都是从 O 往两边电势下降，距离相同时下降得也一样，所以这两个点电势一样。老师说，讲 C 项主要是想让大家再练习一下面积的含义。选 C。

**答案**：C

### bixiu3-40-c14　〔例题〕例题 2：等量电荷的 E-x 图，判断 c、d 两点的场强与电势

讲义第 7 页 · 视频 11:26 · 关键词：E-x图像、等量异种电荷、电场线、场强相同、电势高低、对称、x轴电场线、电势、φ、场强、E · 题型：例题、判断、选择题、综合

考点是 E-x 图与等量异种电荷电场的综合。老师说这个题综合得蛮不错。方法是先按核心一画出能画的电场线，再由场强方向推场源电性，进而补全连线上的电场线。

**题目**：在 x 轴上关于原点对称的 a、b 两点处固定有两个电荷量相等的点电荷，如图 E-x 图象描绘了 x 轴上部分区域的电场强度（以 x 轴正方向为电场强度的正方向）。对于该电场中 x 轴上关于原点对称的 c、d 两点，下列结论正确的是（   ）
A. 两点场强相同，c 点电势更高
B. 两点场强相同，d 点电势更高
C. 两点场强不同，两点电势相等，均比 O 点电势高
D. 两点场强不同，两点电势相等，均比 O 点电势低

**解法**：

1. 老师说这是综合题：把之前讲过的等量电荷的电场分布和 E-x 图综合在一起。先把给出的部分对应的电场线画出来。左边这部分纵坐标都为负，场强方向是负方向，箭头向左；a 点右边靠近 b 的一段也为负，同样箭头向左。
2. 由 a、b 各有一个场源，推场源电性：左边箭头离 a 近，是 a 发出的，从场源指向外，a 带正电；b 处的电场线指向 b，b 带负电。所以它们是一正一负的等量异种电荷的电场分布。
3. 把两个场源连线上的电场线补出来，方向是从正指向负。c、d 两点的电势：沿电场线箭头电势降低，所以 $\varphi_c>\varphi_d$，而且 c 离正电荷近，电势也可能高。
4. 场强要看大小和方向：两点场强方向一样，都向右；大小也一样，因为是等量电荷，可以根据对称性再画几条电场线，左右对称，c 位置和 d 位置的疏密是一样的。所以 c、d 两点场强大小方向都一样，场强相同。
5. 所以选 A：两点场强相同，c 点电势高于 d。

**答案**：A

### bixiu3-40-c15　〔例题〕例题 3：两个点电荷连线上的 E-x 图（福建师大附中期中），判断零电势、电性、电荷量比、电势高低

讲义第 8 页 · 视频 13:55 · 关键词：E-x图像、两个点电荷、场强为零、电势为零、电荷量之比、电势高低、面积、电势差、同种电荷、电势、φ、场强、E · 题型：例题、判断、选择题、综合

这是百强高中福建师范大学附属中学 2019-2020 学年高二上学期期中的题，老师说这道题稍微难一些，需要根据电势差，找 $1.5a$ 和 $2.5a$ 到同一点的电势差，再把电势差转换成电势去分析。老师说这个题好好总结一下，以后类似的题就都会做了。讲义图中 $x=2a$ 处曲线与 x 轴相切（E=0），$3a$ 处有一条虚线，曲线向负方向趋向很大。〔整理注：老师口述的 $S_2$ 比 $S_1$ 大是看图作的判断，不是算出来的；没有给出 E 随 x 的函数式。〕

**题目**：真空中相距为 3a 的两个点电荷 $Q_1$、$Q_2$，分别固定于 x 轴上 $x_1=0$ 处和 $x_2=3a$ 的两点上，在它们连线上各点场强 E 随 x 变化关系如图所示，取沿 x 轴正方向的场强为正方向，以下判断正确的是（   ）
A. $x=2a$ 处的电势一定为零
B. 点电荷 $Q_1$、$Q_2$ 一定为异种电荷
C. 点电荷 $Q_1$ 所带电荷量是 $Q_2$ 所带电荷量的 2 倍
D. $x=1.5a$ 处的电势小于 $x=2.5a$ 处的电势

**解法**：

1. 第一步画 x 轴电场线：图像与 x 轴交点处，左边这段场强都为正，是向右的箭头；右边这段场强都为负，是向左的箭头。图像没给 E 的地方不画。
2. A 项：$2a$ 处图像与 x 轴相交，说明这个点场强为 0。场强为 0，电势不一定为 0。而且电场线都是从场源往外发出的，两个场源一定都是正电荷；两个都是正电荷时，除无穷远处，整个空间电势都是正的，所以它们中间连线上的电势不为 0，A 不对。
3. B 项：分析 A 时已经得出两个都是正电荷，不是异种电荷，B 不对。
4. C 项：两个场源在 $2a$ 处产生的场强合起来为 0。$E_1=\frac{kQ_1}{(2a)^2}$，$E_2=\frac{kQ_2}{a^2}$，两者抵消得 $\frac{Q_1}{4a^2}=\frac{Q_2}{a^2}$，$Q_1=4Q_2$。是 4 倍，不是 2 倍，C 不对。
5. D 项：画一个大点的示意图，标出 O、a、2a、3a 和 $1.5a$、$2.5a$ 两点。$1.5a$ 到 $2a$ 之间曲线较平缓，$2a$ 到 $2.5a$ 之间曲线较陡峭。设两块面积为 $S_1$、$S_2$，$S_1=\varphi_{1.5a}-\varphi_{2a}$（左段电场线向右，$1.5a$ 电势高于 $2a$），$S_2=\varphi_{2.5a}-\varphi_{2a}$（右段电场线向左，$2.5a$ 电势高于 $2a$）。因为 $S_2>S_1$，得 $\varphi_{2.5a}-\varphi_{2a}>\varphi_{1.5a}-\varphi_{2a}$，约掉 $-\varphi_{2a}$，得 $\varphi_{2.5a}>\varphi_{1.5a}$。所以 $1.5a$ 处电势小于 $2.5a$ 处电势，D 正确。选 D。

**答案**：D
