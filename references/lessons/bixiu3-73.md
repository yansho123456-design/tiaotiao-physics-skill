# 必修3 第73讲 环形电流问题（题型技巧课）

讲次代号：bixiu3-73

## 这一讲讲了什么

这一讲是磁场与安培力部分的最后一节题型技巧课，老师称它是一个小破题，考法非常固定。题型特征是给一个条形磁铁，再给一个环形电流，问线圈怎么动：是平移还是转动，往哪个方向转。方法只有一条：俯视，把环形电流等效成一块条形磁铁，再用同斥异吸分析两块磁铁。具体做法分三步：想象一个水平面，把线圈从俯视画成一边叉、一边点；用安培定则画出磁感线，看最中间那根磁感线的箭头，箭头朝下，下端就是 N 极；把等效磁铁和原来的磁铁放在一起，按同名磁极相斥、异名磁极相吸判断转动方向和靠近还是远离。因为环形电流和条形磁铁的磁感线分布一样，所以可以这样等效。老师说这题唯一的难点是把圆环在俯视视角里画对，要看清电流从哪边扎进去、哪边钻出来。两道例题分别是线圈在固定磁铁 S 极附近（选 C，顺时针转动并靠近）和线圈挂在磁铁 N 极附近（选 A，顺时针转动并靠近）。

## 知识卡

### bixiu3-73-c01　〔概念〕题型特征：环形电流加条形磁铁，问线圈怎么动

讲义第 3 页 · 视频 00:19 · 关键词：环形电流、线圈、条形磁铁、磁铁、题型特征、线圈运动、平移、转动、磁场与安培力 · 题型：概念、判断、选择题

老师说：这类题的题型特征特别典型，题目一定会给一个条形磁铁，再给一个环形电流，把它们放在一起，问这个时候线圈怎么动。例如讲义第 3 页这道题，会问线圈是平移还是转动，要是转动，往哪个方向转，让你分析线圈的运动。题目里常见的说法是线圈悬挂在条形磁铁附近，线圈与磁铁在同一竖直平面内，通入图示方向的电流。老师把这个特征概括成一句话：环形电流加磁铁，并强调这类题的考法非常固定，是一个小破题。一见到环形电流加条形磁铁让你分析，就用本讲的方法，不要直接去分析磁铁和电流之间的力。

### bixiu3-73-c02　〔方法〕第一步：俯视，把线圈画成一边叉、一边点

讲义第 4 页 · 视频 00:40 · 关键词：环形电流、俯视、点和叉、垂直纸面、电流方向、扎进去、钻出来、等效磁铁 · 题型：方法、画图、判断

老师说：这类题最简单的方法，是用俯视的视角，把环形电流等效成一块磁铁，所以第一步是把环在俯视视角里画出来。画法是想象有一个平面，这个环穿过这个平面，就像之前讲安培定则时，老师用跳跳的项圈做的举例：一个环只是一个圈，它穿过一个平面，从俯视看，你只能看到这么一条线。判断怎么表示这个环，就看环的哪边扎进去、哪边钻出来：扎进去的一边画叉，钻出来的一边画点。以讲义第 4 页的悬挂线圈为例，老师从俯视看，线圈左边扎进去，应该是叉，右边钻出来，应该是点，所以把这个环形电流表示成左边一个叉、右边一个点。老师提醒，这一步是整道题唯一的难点，要看清电流从哪边进、哪边出。〔整理注：图中线圈电流左边向下、右边向上，向下穿过想象的水平面是扎进去，向上穿过是钻出来，所以左叉右点。〕

配图：bixiu3-73-ring-topview-symbols

### bixiu3-73-c03　〔方法〕第二步：用安培定则画磁感线，最中间那根箭头朝下，下端就是 N 极

讲义第 4 页 · 视频 01:56 · 关键词：安培定则、右手螺旋定则、磁感线、中心磁感线、等效磁铁、N极、S极、环形电流 · 题型：方法、画图、判断

老师说：画成左叉右点之后，用安培定则抓一下，它产生的磁场是一圈一圈的，叉的周围一圈，点的周围一圈，这样一个磁场。这时看最中间那根磁感线：中间这根磁感线的箭头如果朝下指，那就等效成条形磁铁，下面是 N 极、上面是 S 极。老师强调等效时就用这根中心磁感线，一边俯视，一边去找它中心的那根磁感线，用它来等效就行了。〔整理注：左边叉的磁感线绕向是顺时针，右边点的磁感线绕向是逆时针，两边在中间都朝下，所以最中间的磁感线朝下。如果电流方向反过来，中间磁感线朝上，则上端是 N 极，这一点是顺着老师说的规则推出来的，老师没有单独讲这个情形。〕

配图：bixiu3-73-ring-topview-field、bixiu3-73-ring-equiv-magnet

### bixiu3-73-c04　〔结论〕为什么能等效：环形电流和条形磁铁的磁感线分布一样

讲义第 4 页 · 视频 02:15 · 关键词：等效磁铁、环形电流、条形磁铁、磁感线分布、磁场分布、等价、磁感线 · 题型：概念、推导、判断

老师说：环形电流就跟一个条形磁铁产生的磁场一模一样。条形磁铁的磁感线也是一圈一圈的，外面从 N 回到 S，内部再从 S 回到 N，画一圈也是一样的，所以可以根据环形电流中间那条磁感线，把它等价成一个条形磁铁。因为等效完之后，它们的磁场分布是一样的，所以可以这么等效。老师说，等效之后问题就变成了给你两个条形磁铁，让你分析它们怎么动，直接根据它们 N 极和 S 极的位置去分析就行，这要比直接分析一个磁铁和一个电流简单得多。

配图：bixiu3-73-ring-equiv-magnet、bixiu3-73-ring-topview-field

### bixiu3-73-c05　〔方法〕第三步：两块磁铁用同斥异吸分析，转动和靠近一起判断

讲义第 4 页 · 视频 03:08 · 关键词：同斥异吸、同名磁极相斥、异名磁极相吸、等效磁铁、转动方向、顺时针、逆时针、靠近、远离、环形电流 · 题型：方法、判断、选择题

老师说：等效成条形磁铁之后，变成了给你两个条形磁铁让你分析它们怎么动，那就直接根据同斥异吸，也就是同名磁极相斥、异名磁极相吸，根据它们 N 极和 S 极的位置去分析。老师特别强调，以后只要见到一个环形电流加一个条形磁铁让你分析，一律是把这个环形电流等效成一个条形磁铁来分析，等效的办法是俯视图里找它中心的那根磁感线。题目里的转动和靠近两件事要分别判断：磁极被异名磁极吸引的那一端会向对方转过去，同时两块磁铁会靠近，最后可能吸在一起。〔整理注：判断转动方向时，先看被吸引的那一端要往哪边转，再从上往下看它是顺时针还是逆时针；判断靠近或远离时，看相互吸引的两个异名磁极是否在靠近。〕

配图：bixiu3-73-q1-analysis、bixiu3-73-q2-analysis

### bixiu3-73-c06　〔易错〕唯一的难点：把圆环在俯视视角里画对，看清从哪边进、哪边出

讲义第 7 页 · 视频 07:50 · 关键词：环形电流、俯视、点和叉、电流方向、易错点、难点、想象平面、反向电流 · 题型：易错、画图、判断

老师说：这个题如果说有难点，唯一的难点就在于怎么把这个圆环在俯视视角里画出来，要看清楚电流从哪边进、哪边出。如果不熟练，就想象这里有一个平面，看电流穿过平面的方向。例如电流方向反过来的话，一边是扎出来，另一边扎进去：老师举的例子是左边钻出来画点、右边扎进去画 X，所以应该是右边是个 X、左边是个点。老师说，多练练就没问题了。〔整理注：电流方向一旦画反，叉和点就换了位置，中间磁感线的方向会跟着反过来，等效磁铁的 N、S 也会反过来，最后转动和靠近的结论就全错，所以这一步必须看准。〕

配图：bixiu3-73-ring-reverse-symbols、bixiu3-73-ring-topview-symbols

### bixiu3-73-c07　〔口诀〕本讲小结：环形电流加磁铁，俯视等效成磁铁，同斥异吸

讲义第 7 页 · 视频 07:18 · 关键词：环形电流、等效磁铁、同斥异吸、俯视、小结、题型特征 · 题型：口诀、概念、方法

题型特征：环形电流加磁铁。等效磁铁：俯视，将环形电流等效成磁铁，用同斥异吸分析。具体思路：俯视画出圆环，看电流从哪边进、哪边出，进的画叉，出的画点；用安培定则找最中间那根磁感线，箭头朝下则下端为 N 极；再把两块磁铁用同斥异吸分析，判断转动方向和靠近还是远离。老师说，这一课讲了一个小破题，环形电流问题，大家通过前面讲的题好好练习怎么以俯视的视角把圆环画出来；多练练就没问题。下节课进入磁场中最核心、最重要的模块：带电粒子在匀强磁场中的运动，也就是洛伦兹力。

### bixiu3-73-c08　〔例题〕例题 1：线圈悬挂在固定磁铁 S 极附近，判断线圈的运动

讲义第 5 页 · 视频 04:10 · 关键词：环形电流、等效磁铁、同斥异吸、线圈、顺时针转动、靠近磁铁、固定磁铁、S极附近 · 题型：例题、判断、选择题

考点是环形电流加条形磁铁的等效磁铁方法。老师说，等效完之后直接分析两块磁铁，根据同斥异吸，就简单多了，这类题听懂了没问题。〔整理注：图中线圈电流左边向下、右边向上，所以俯视是左叉右点。老师口述 N 极往上转，指 N 极向着固定磁铁的 S 极转过去，从上往下看是顺时针，与选项 C 一致。选项 A、B 说平移，而等效后两块磁铁之间是吸引并转动，不是单纯平移。〕

**题目**：如图所示，在固定位置的条形磁铁 S 极附近悬挂一个金属线圈，线圈与水平磁铁位于同一竖直平面内，当线圈中通入沿图示方向的电流时，将会看到（   ）
A. 线圈向左平移
B. 线圈向右平移
C. 从上往下看，线圈顺时针转动，同时靠近磁铁
D. 从上往下看，线圈逆时针转动，同时靠近磁铁

**解法**：

1. 认出题型：条形磁铁加环形电流，问线圈怎么动，用等效磁铁的方法。注意条形磁铁是固定的，不会动，只有线圈会动。
2. 画俯视图：条形磁铁从俯视看仍是左边 N、右边 S。线圈想象有一个平面，左边扎进去，画叉，右边钻出来，画点。
3. 找中间磁感线：用安培定则握一下，最中间的磁感线 B 朝下，把线圈等效成一块条形磁铁，箭头往下指，所以下面是 N 极、上面是 S 极。
4. 同斥异吸：左边固定磁铁的右边是 S 极，会吸引右边等效磁铁的 N 极，所以这个 N 极往固定磁铁的 S 极转过去，同时 N 极还会靠近 S 极。
5. 转动方向：从上往下看，这个转动方向是顺时针，同时靠近磁铁，最终两块磁铁吸在一起。所以选 C。

**答案**：C

### bixiu3-73-c09　〔例题〕例题 2：线圈挂在磁铁 N 极附近，判断线圈的转动和远近

讲义第 6 页 · 视频 06:09 · 关键词：环形电流、等效磁铁、同斥异吸、线圈、顺时针转动、靠近磁铁、N极附近、轻质导线圈 · 题型：例题、判断、选择题

考点与例题 1 相同，换成了线圈挂在磁铁 N 极附近，其他步骤一样。老师说，这类题模式都很像，也不用多讲，因为都很固定，讲两个会了就行。〔整理注：与例题 1 对比，线圈电流方向相同，所以等效磁铁都是上 S 下 N，区别只在线圈和磁铁的左右位置：例题 1 线圈在磁铁 S 极的右边，是等效磁铁的 N 极靠近固定磁铁的 S 极；这道题线圈在磁铁 N 极的左边，是等效磁铁的 S 极靠近磁铁的 N 极；两题都是顺时针转动并靠近。〕

**题目**：把轻质导线圈用细线挂在磁铁 N 极附近，磁铁的轴线穿过线圈中心，且在线圈平面内，如图所示，当线圈通以图示方向的电流时，从上往下看，线圈将（   ）
A. 顺时针转动，同时靠近磁铁
B. 顺时针转动，同时远离磁铁
C. 逆时针转动，同时靠近磁铁
D. 逆时针转动，同时远离磁铁

**解法**：

1. 认出题型：与例题 1 模式很像，老师说这题不读了，直接分析。
2. 画俯视图：想象有一个平面，圆环从左边扎进去是叉，右边钻出来是点，所以左边叉、右边点。
3. 找中间磁感线：B 的方向握一下，朝下，所以可以把线圈等价成一个条形磁铁，下面是 N 极、上面是 S 极。右边还有一个条形磁铁，左边是 N、右边是 S。
4. 同斥异吸：线圈等效磁铁的 S 极（上端）会被右边磁铁的 N 极吸引，一边向它转过去，一边靠近右边的磁铁。
5. 转动方向：从上往下看，这是顺时针转动，同时靠近磁铁。所以选 A。

**答案**：A
