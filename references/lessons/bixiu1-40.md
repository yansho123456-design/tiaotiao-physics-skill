# 必修1 第40讲 摩擦力方向分析（题型技巧课）

讲次代号：bixiu1-40

## 这一讲讲了什么

这一讲是重力、弹力与摩擦力模块的最后一节，专门教怎么判断摩擦力的方向，老师给了两招。第一招是平衡法：读题先找静止或匀速这类关键词，只要物体平衡，不管是滑动摩擦力、静摩擦力，甚至不是摩擦力的力，一律用平衡来定方向。配套的小技巧有两个：对象复杂时换成相互作用力的另一方来分析，不知道有没有摩擦力时用假设法。爬杆和走路要看直接接触的手和脚，不看整个人。第二招叫劫富济贫，专门分析同向叠块问题：两个物体叠在一起朝同一个方向运动但速度不同，速度慢的物体受到的摩擦力与速度同向，速度快的物体受到的摩擦力与速度反向，不用再去分析相对运动。这个口诀背后的道理是摩擦力要阻碍相对运动，让快的减速、慢的加速，直到共速。还有几个易错点：只告诉某时刻的速度不能认为是匀速，摩擦力方向是跟相对运动方向相反而不是跟运动方向相反，没有外力干预时相对运动最终会停止。七道例题依次是竹竿攀爬、三个物体叠放、叠放匀速拉动、长木板与物块的填空、汽车与货物、长木板与物块的判断、光滑水平面上的木板与物体。

讲义第 3 页 · 视频 00:20 · 关键词：摩擦力方向、摩擦力方向分析、同向叠块、叠块问题、题型特征、两招 · 题型：概念、摩擦力方向分析

### bixiu1-40-c02　〔方法〕第一招平衡法：读题先找静止或匀速，只要平衡就一律用平衡分析力的方向

讲义第 4 页 · 视频 01:24 · 关键词：平衡法、第一招、静止、匀速、平衡、合力为零、二力平衡、等大反向、关键词 · 题型：方法、摩擦力方向分析、平衡法

老师说：做力学分析题要养成一个好习惯，先留意有没有静止或者匀速这样的关键词。如果有，就表示这个物体当前是受力平衡的，合力为零。老师要大家记住这句话：任何一道力学分析题，不管让你分析什么，只要分析出来这个物体是平衡的，一律利用平衡来分析，分析摩擦力方向也不例外。具体做法很简单：比如一个物体受到两个力并且平衡，已知一个力向右，让你分析另一个力的方向，那肯定是向左，因为两个力要平衡必须反向（等大反向）。老师强调，这时候不管是滑动摩擦力还是静摩擦力，甚至不是摩擦力，随便哪一个力，都用平衡来分析。只要读题时找到了表明平衡的关键词，就用平衡来分析。老师说，这是最重要的一招，也是最优先的方法。〔整理注：讲义第 4 页的原话是先看是否有关键词静止或匀速，如果有，无论啥力，一律用平衡分析。〕

### bixiu1-40-c03　〔方法〕换对象：对象的受力太复杂时，改分析相互作用力的另一方

讲义第 6 页 · 视频 07:55 · 关键词：换对象、相互作用力、牛顿第三定律、作用力与反作用力、整体法与隔离法、摩擦力方向 · 题型：方法、摩擦力方向分析、选择题

老师说：有时候要分析的那个物体受力比较多、比较复杂，这时候有个小技巧。例题 2 的 A 选项问的是 A 对 C 的摩擦力，即分析 C 受到的力，但 C 受力比较复杂。这时可以想到：A 对 C 的力和 C 对 A 的力是一对相互作用力，等大反向。所以可以先不分析 A 对 C，改去分析 C 对 A，也就是以 A 为对象，因为 A 的受力比较简单。A 平衡，水平方向受到向左的 $F$，就一定要有一个力把 $F$ 抵消，这个力只能是 C 给 A 的摩擦力，所以 C 对 A 的摩擦力向右；既然 C 对 A 的摩擦力向右，A 对 C 的摩擦力就一定向左。老师总结：当你的对象比较复杂、比较麻烦的时候，可以换一个对象，利用力的相互作用来分析。这是做题非常常用的方法。

### bixiu1-40-c04　〔方法〕假设法：已知平衡又不知有没有摩擦力，先假设有，找不到别的力平衡就是没有

讲义第 6 页 · 视频 10:53 · 关键词：假设法、摩擦力有无、静摩擦力、平衡、矛盾、平衡法 · 题型：方法、摩擦力有无判断、选择题

老师说：平衡的物体，如果不知道某个接触面有没有摩擦力，可以先假设有。具体做法：以要问的那个物体为对象，假设它在水平方向受到摩擦力；因为它是平衡的，合力为零，那么水平方向还得有一个别的力跟这个摩擦力平衡。这时去找：有没有外力拉着它或推着它？如果找不到别的力，它在水平方向要么一个力都不受，要么只受这个摩擦力，只受摩擦力就没有力跟它平衡，这跟匀速（平衡）的条件矛盾，所以摩擦力不存在。老师在例题 2 的 B 选项（B 与 C 之间有没有摩擦力）和例题 3（A 受到 B 的摩擦力是多少）连用了两次这个思路，并总结：如果已知是平衡的，不知道摩擦力有没有，就先假设有，看能不能找到别的力跟它平衡，找不到那肯定就没有。老师说大家要好好练习这个假设法。

### bixiu1-40-c05　〔易错〕爬杆和走路：摩擦力不看整个人的相对运动，要看直接接触的手和脚

讲义第 5 页 · 视频 04:41 · 关键词：爬杆、走路、相对运动趋势、静摩擦力、手、脚、摩擦力方向、摩擦力是动力 · 题型：易错、概念、摩擦力方向分析

老师说：例题 1 里很多同学有个疑问：人往上爬杆时，人相对杆的运动是向上的，摩擦力应该与相对运动相反，向下才对，为什么摩擦力也向上？走路也一样：人往前走，相对地面是向前的，按理摩擦力应该向后，但其实不是。问题出在不能看整个人和杆（或地面）的相对运动，要看跟杆（或地面）直接接触的那个部位。爬杆时，手要抓住杆，胳膊带着手往下按，人才能上去，所以手相对杆的运动趋势是向下的，杆给手一个向上的摩擦力，这跟前面讲的并不矛盾。走路时，腿带着脚有一个向后蹬地的劲，脚有向后的运动趋势，地面给脚向前的摩擦力，人就向前走。老师总结：爬杆看手，走路看脚，要分析手和脚的相对运动。老师接着说，这个题还是建议直接用平衡来分析，讲这么多是怕有的同学想不明白、钻牛角尖，知道就可以，做题还是用平衡。

### bixiu1-40-c06　〔例题〕例题 1：民间艺人握竹竿匀速上攀和匀速下滑，比较摩擦力 $f_1$、$f_2$

讲义第 5 页 · 视频 02:50 · 关键词：平衡法、爬杆、匀速、摩擦力方向、摩擦力大小、重力、f=G · 题型：例题、选择题、摩擦力方向分析

考点是平衡法：有匀速就用平衡，直接绕过对摩擦力本身（滑动还是静）的分析。老师说，用平衡来分析这个题最简单。关于上攀时摩擦力为什么向上，见本讲爬杆和走路那一条。

**题目**：民间艺人用双手握住竖立的竹竿匀速上攀和匀速下滑时，他所受的摩擦力大小分别为 $f_1$、$f_2$，则（   ）
A. $f_1$ 向上、$f_2$ 向上，且 $f_1=f_2$
B. $f_1$ 向下、$f_2$ 向上，且 $f_1=f_2$
C. $f_1$ 向上、$f_2$ 向上，且 $f_1>f_2$
D. $f_1$ 向下、$f_2$ 向上，且 $f_1>f_2$

**解法**：

1. 找关键词：题目说匀速上攀和匀速下滑，匀速表示平衡，合力为零，所以用平衡来分析。老师说不用纠结上去时是滑动摩擦还是静摩擦、下来时是滑动摩擦还是静摩擦。
2. 匀速上攀：人受到向下的重力 $G$，要平衡，摩擦力必须向上，且 $f_1=G$，两个力抵消。
3. 匀速下滑：人同样受到向下的重力 $G$，要平衡，摩擦力继续与重力等大反向，向上，$f_2=G$。
4. 所以上去和下来摩擦力大小一样、方向都向上，选 A。

**答案**：A

### bixiu1-40-c07　〔例题〕例题 2：A、B 放在 C 上，水平力 $F$ 拉 A 使三者一起匀速，判断各接触面的摩擦力

讲义第 6 页 · 视频 07:19 · 关键词：平衡法、换对象、假设法、相互作用力、摩擦力方向、摩擦力有无、三个物体叠放、匀速 · 题型：例题、选择题、多选题、摩擦力方向分析

老师说这个题特别经典：A 选项里换对象、利用相互作用力的技巧，B 选项里用假设法确定有没有摩擦力，都是做题非常常用的方法，要把这道题彻底搞懂。

**题目**：如图所示，物体 A、B 放在物体 C 上，水平力 $F$ 作用于 A，使 A、B、C 一起匀速运动，各接触面间的摩擦力的情况是（   ）
A. 物体 A 对物体 C 有向左的摩擦力
B. 物体 B 与物体 C 之间没有摩擦力
C. 物体 C 受到三个摩擦力的作用
D. 地面对物体 C 有向右的摩擦力

**解法**：

1. 找关键词：一起匀速运动，说明 A、B、C 三个物体每一个合力都为零，都平衡，所以用平衡来分析。
2. A 选项（A 对 C 的摩擦力）：C 受力复杂，先不分析 A 对 C，改分析 C 对 A，以受力简单的 A 为对象。A 平衡，受到向左的 $F$，水平方向没有别的力，一定有 C 给 A 向右的摩擦力把 $F$ 抵消。A 对 C 的力和 C 对 A 的力是一对相互作用力，等大反向，所以 A 对 C 的摩擦力向左，A 正确。
3. B 选项（B、C 之间）：以 B 为对象，假设 C 对 B 有摩擦力。B 也是匀速，合力为零，水平方向就需要别的力跟它平衡，但没有外力拉着或推着 B，所以与匀速矛盾，B、C 之间没有摩擦力，B 正确。
4. D 选项（地面对 C）：以 C 为对象，C 合力为零，受到 A 对它向左的摩擦力，就还需要一个向右的摩擦力去平衡，只能是地面给 C 的，所以地面对 C 有向右的摩擦力，D 正确。
5. C 选项：C 一共受到两个摩擦力，A 对 C 的向左、地面对 C 的向右，不是三个，C 错误。所以选 ABD。

**答案**：ABD

### bixiu1-40-c09　〔概念〕同向叠块问题：两块叠放、同向运动、速度不同；速度不同时一定是滑动摩擦力

讲义第 8 页 · 视频 13:45 · 关键词：同向叠块、叠块问题、滑动摩擦力、相对运动、相对静止、速度不同、反向叠块 · 题型：概念、摩擦力方向分析、同向叠块

老师说：第二招劫富济贫，是专门用来分析同向叠块问题的。什么叫同向叠块问题？就是两个块叠在一起，朝着一个方向运动，也就是速度方向相同，但快慢不同，让你分析彼此对对方的摩擦力。老师说这里只讲同向，不讲反向，因为反向太简单：比如 B 在下、A 在上，A 向左运动、B 向右运动，那 B 给 A 的摩擦力肯定向右、A 给 B 的摩擦力肯定向左，一眼就能看出来，不需要分析。同向就比较麻烦。老师特别提醒：对这种同向叠块问题，当它们的速度大小不一样的时候，这时候的摩擦力一定是滑动摩擦力。道理是：如果速度一样（比如 A、B 都是 5 m/s），它们相对静止，没有相对运动；如果速度不一样（比如一个 5、一个 3），它们之间就一定有相对运动，产生的就是滑动摩擦力。

### bixiu1-40-c10　〔方法〕传统方法：先判相对运动方向，摩擦力与它相反；同向叠块里这样做很麻烦

讲义第 8 页 · 视频 15:18 · 关键词：相对运动方向、滑动摩擦力、传统方法、同向叠块、摩擦力方向、相对运动 · 题型：方法、摩擦力方向分析、同向叠块

老师说：先用之前讲过的传统方法把滑动摩擦力分析出来，再从结果里挖出简单的规律，分两种情况。第一种，A 的速度比 B 快（$v_A>v_B$），两者都向右运动：A 比 B 快，A 会往 B 的前头移动，所以 A 相对 B 向右运动，A 受到的摩擦力与相对运动方向相反，向左；B 相对 A 就向左运动，B 受到的（A 对它的）摩擦力向右。老师说这里只分析 A、B 之间的摩擦力，先不管地面。第二种，A 的速度小于 B（$v_A<v_B$），B 快 A 慢：A 相对 B 向左运动，A 受摩擦力向右；B 相对 A 向右运动，B 受摩擦力向左。老师说这个过程没问题，但高中阶段分析相对运动是一件很麻烦的事情，是比较难的东西，不怪大家，尤其是两个物体都同向运动的时候更恶心。所以下面教的方法是不用分析相对运动，直接看出摩擦力方向。〔整理注：判断摩擦力用的是相对运动方向，与某个物体相对地面往哪个方向运动是两回事，对地速度只用来比快慢。〕

### bixiu1-40-c11　〔口诀〕第二招劫富济贫：速度快的物体受摩擦力与速度反向，速度慢的物体与速度同向

讲义第 8 页 · 视频 17:20 · 关键词：劫富济贫、速度快的物体、速度慢的物体、摩擦力与速度反向、摩擦力与速度同向、同向叠块、第二招 · 题型：口诀、方法、摩擦力方向分析、同向叠块

老师说：把两种情况的结果放在一起看规律。$v_A>v_B$ 时，快的 A 受到的摩擦力向左，与 A 的速度方向相反；慢的 B 受到的摩擦力向右，与 B 的速度方向相同。$v_A<v_B$ 时，B 快，B 受的摩擦力向左，与运动方向相反；A 慢，A 的摩擦力向右，同向，规律也成立。所以规律是：速度慢的物体受到的摩擦力与速度同向，速度快的物体受到的摩擦力与速度反向。老师说，用这个规律可以根据速度大小直接看出摩擦力方向，不需要分析相对运动。这个方法叫劫富济贫：富指速度快，贫指速度慢。你快，我的摩擦力就要打压你、劫你，怎么劫？跟你唱反调，跟你方向相反；你速度慢，我就要帮你、济你，怎么济？跟你同向，支持你一把。老师说用这招做题，感觉就像爸爸打儿子一样轻松。〔整理注：转录把劫富济贫误写成节负即频等，这里按讲义写法。〕

### bixiu1-40-c12　〔概念〕劫富济贫为什么成立：摩擦力阻碍相对运动，让快的减速、慢的加速，直到共速

讲义第 8 页 · 视频 19:14 · 关键词：阻碍相对运动、摩擦力作用、共速、减速、加速、劫富济贫、同向叠块 · 题型：概念、摩擦力方向分析

老师说：如果深刻地理解了摩擦力是阻碍相对运动这件事，这个口诀其实很好理解。两个物体朝同一个方向走，速度一个快一个慢，摩擦力要阻碍相对运动，怎么阻碍？就是让速度快的那个慢一点，让速度慢的那个快一点：让快的减速，让慢的加速，当两个物体速度一样的时候就没有相对运动了，摩擦力的任务就完成了。所以摩擦力跟速度快的物体方向相反，让它减速；跟速度慢的物体方向相同，让它加速。老师说，这样也可以对摩擦力的理解更深一步。

### bixiu1-40-c13　〔例题〕例题 4：长木板 A 以 3 m/s、物体 B 以 1 m/s 同向运动，判断地面对 A、A 对 B 的摩擦力方向

讲义第 9 页 · 视频 20:17 · 关键词：劫富济贫、同向叠块、地面摩擦力、摩擦力方向、速度慢的物体、长木板 · 题型：例题、填空题、摩擦力方向分析

老师说，第二问不需要分析 A、B 之间的相对运动，用劫富济贫一下子就写出来了。老师提醒，这个题要注意总结下一条那句话：只告诉速度、没说匀速，不能认为是匀速。

**题目**：如图所示，A 为长木板，在水平地面上以 3 m/s 的速度向右运动，物体 B 在木板 A 的上面以 1 m/s 的速度向右运动，则：
（1）地面对 A 的摩擦力方向为水平向____；
（2）A 对 B 的摩擦力方向为水平向____。

**解法**：

1. 第一问分析的是 A 和地面之间，不需要什么方法，直接看：A 相对地面向右运动，所以地面对 A 的摩擦力向左。
2. 第二问分析的是 B 受到 A 的摩擦力，这是同向叠块，不用分析相对运动，直接用劫富济贫：B 的速度（1 m/s）比 A（3 m/s）慢，速度慢的物体摩擦力与速度同向，B 的速度向右，所以 A 对 B 的摩擦力向右。

**答案**：（1）左；（2）右

### bixiu1-40-c14　〔易错〕只告诉速度、没说匀速，不能认为是匀速，不能当作平衡

讲义第 9 页 · 视频 20:26 · 关键词：匀速、瞬时速度、平衡法、审题、不能认为匀速、关键词 · 题型：易错、审题、摩擦力方向分析

老师说：例题 4 里，看到长木板在地面上以 3 m/s 的速度向右运动，很多同学会有个误区，觉得它在做匀速运动。注意不是的，这个 3 m/s 只能说明此时此刻的速度是 3 m/s。如果是匀速，题目会明确地说以这个速度向右匀速运动；没有说匀速，就不能认为人家做的是匀速，可能下一个时刻就加速或者减速了，只知道这一个时刻的速度是 3 m/s。所以千万不要读完这句话就觉得这个物体是匀速的、是平衡的，没有这个条件。老师在讲义上用红字写着：只告诉速度，但没说匀速不能认为匀速。〔整理注：这一条与第一招的关系是，只有题目明确说了静止或匀速，才能用平衡法。〕

### bixiu1-40-c15　〔例题〕例题 5：汽车 B 与车上货物 A 同向运动，判断汽车与货物之间的摩擦力

讲义第 10 页 · 视频 22:14 · 关键词：劫富济贫、同向叠块、汽车与货物、滑动摩擦力、速度快的物体、速度慢的物体 · 题型：例题、选择题、多选题、摩擦力方向分析

老师说，这个题如果用相对运动方向来分析，老麻烦了；用劫富济贫，只根据速度的大小就可以一步到位把力画出来。

**题目**：如图所示，汽车 B 在平直的路面上以速度 $v_1$ 向右运动，车上的货物 A 以速度 $v_2$ 也向右运动，$v_1$、$v_2$ 均以地面为参照物，关于汽车与货物之间的摩擦力，下列说法正确的是（   ）
A. 若 $v_1<v_2$，货物 A 受到了汽车 B 所施加的向右的滑动摩擦力
B. 若 $v_1<v_2$，汽车 B 受到了货物 A 所施加的向右的滑动摩擦力
C. 若 $v_1>v_2$，货物 A 受到了汽车 B 所施加的向左的滑动摩擦力
D. 若 $v_1>v_2$，汽车 B 受到了货物 A 所施加的向左的滑动摩擦力

**解法**：

1. 认出这也是同向叠块问题：一个是货物 A，一个是汽车 B，而且同向。用劫富济贫，只看速度大小。
2. A、B 选项是 $v_1<v_2$：A 的速度是 $v_2$，所以 A 快、B 慢。快的 A 受到的摩擦力与速度反向，向左，所以 A 选项（说 A 受向右的）不对；慢的 B 受到的摩擦力与速度同向，向右，B 选项正确。
3. C、D 选项是 $v_1>v_2$：这时 B 变成快的，B 受到的摩擦力反向，向左；A 变成慢的，A 受到的摩擦力同向，向右。C 选项说 A 受到向左的，不对；D 选项说 B 受到向左的，正确。
4. 所以选 B 和 D。

**答案**：BD

### bixiu1-40-c16　〔例题〕例题 6：长木板 A 与物块 B 同向运动，比较 $v_1$、$v_2$ 判断滑动摩擦力方向

讲义第 11 页 · 视频 24:20 · 关键词：劫富济贫、同向叠块、共速、滑动摩擦力、长木板与物块、速度相等 · 题型：例题、选择题、摩擦力方向分析

老师说，这道题就是开头讲义第 3 页那道题型特征题，分析过程中全程根本没有用到相对运动方向。

**题目**：如图所示，A 为长木板，在水平面上以速度 $v_1$ 向右运动，物块 B 在木板 A 的上面以速度 $v_2$ 向右运动。下列判断正确的是（   ）
A. 若是 $v_1<v_2$，B 受到了 A 所施加向右的滑动摩擦力
B. 若是 $v_1>v_2$，A 受到了 B 所施加向右的滑动摩擦力
C. 若是 $v_1=v_2$ 且二者保持匀速运动，则 A、B 之间无滑动摩擦力

**解法**：

1. C 选项：速度相等，它们之间没有相对运动，所以没有滑动摩擦力，C 正确。

3. B、D 选项都是 $v_1>v_2$：$v_1$ 是 A 的速度，A 快，摩擦力向左；B 慢，摩擦力向右。B 选项说 A 受到向右的，不对；D 选项说 B 受到向左的，也不对。
4. 所以只有 C 正确。

**答案**：C

### bixiu1-40-c17　〔易错〕相对运动方向在简单情况仍要用；同向叠块这种麻烦题才用劫富济贫

### bixiu1-40-c18　〔例题〕例题 7：木板 A 在光滑水平面上，物体 B 在 A 上滑动，$v_1<v_2$，判断摩擦力的情况

讲义第 12 页 · 视频 25:53 · 关键词：劫富济贫、共速、相对运动停止、光滑水平面、同向叠块、摩擦力消失、始终 · 题型：例题、选择题、摩擦力方向分析

老师说，这个题把一些非常重要的考点都考到了，要好好总结。题目里 $v_1<v_2$ 这句话很重要，一看就知道谁快谁慢。〔整理注：本题讲义原图的速度标注为 $v_1$（A，下）、$v_2$（B，上）。〕

**题目**：如图所示，木板 A 沿光滑水平面向右运动，速度为 $v_1$，物体 B 以速度 $v_2$（对地）沿 A 物体上表面滑动，已知 $v_1$、$v_2$ 方向相同，且 $v_1<v_2$，A、B 接触面粗糙，木板 A 足够长。则下列说法正确的是（   ）
A. 物体 B 始终受到 A 对它的摩擦力作用，方向水平向右
B. 物体 B 始终受到 A 对它的摩擦力作用，方向水平向左
C. 因为 A、B 两物体所受摩擦力的方向都跟它们的运动方向相反，所以摩擦力方向都水平向左
D. 在 A、B 两物体的速度达到相同之前，物体 A 受摩擦力方向为水平向右，物体 B 受摩擦力方向水平向左。当两物体有共同速度之后，它们之间不存在摩擦力作用

**解法**：

1. 先判断谁快谁慢：$v_1<v_2$，所以 A 慢、B 快。用劫富济贫：A 受到的摩擦力与速度同向，向右；B 受到的摩擦力与速度反向，向左。
2. A、B 选项都说物体 B 始终受到摩擦力，错在始终：木板足够长，B 受摩擦力减速、A 受摩擦力加速，总有一个时刻两者速度相同，共速以后没有相对运动，摩擦力就消失了，所以摩擦力不能永远存在，方向不用再分析。
3. C 选项说摩擦力方向跟运动方向相反，不是跟相对运动方向相反，而且 A 受向右、B 受向左，方向并不都向左，错误。
4. D 选项：共速之前 A 受摩擦力向右，B 受摩擦力向左，共速之后没有相对运动，不存在摩擦力，正确。所以选 D。

**答案**：D

### bixiu1-40-c19　〔结论〕没有其他外力干预时，最终相对运动都会停止，共速后摩擦力消失

讲义第 12 页 · 视频 26:38 · 关键词：共速、相对运动停止、摩擦力消失、始终、无外力干预、同向叠块 · 题型：结论、选择题、摩擦力方向分析

老师说：例题 7 里的始终是什么意思？题目说 A 足够长，长度无限长，始终就是这个摩擦力永远都存在。老师要大家总结一句话：在没有其他外力干预的情况下，最终相对运动都会停止。因为快的 B 会减速、慢的 A 会加速，总有一个时刻他俩速度相同，开始共速，这时候没有相对运动，就没有摩擦力了。所以摩擦力不能永远存在，凡是说始终受到摩擦力的选项肯定不对。讲义第 12 页用红字写着：在没有其他外力干预的情况下，最终相对运动都会停止。〔整理注：这条结论针对没有其他外力干预的情形，例题 7 的水平面光滑。〕
