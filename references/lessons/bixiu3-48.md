# 必修3 第48讲 路端电压-电流关系图像（基础课）

讲次代号：bixiu3-48

## 这一讲讲了什么

这一讲是电路基础里闭合电路欧姆定律的第三节课，从图像角度考闭合电路欧姆定律。同一个电源接滑动变阻器，路端电压 $U$ 与总电流 $I$ 满足 $U=E-Ir$，把 $I$ 当自变量、$U$ 当因变量，就是一条向下倾斜的直线。图像上只要抓三个关键信息：纵截距是电动势 $E$（电流为零、开路时路端电压等于电动势），横截距是短路电流（路端电压为零时的电流），斜率的大小是内阻 $r$。问电动势看纵截距，问内阻算斜率大小。最大的坑是纵轴不从 0 开始：此时电动势不受影响，但算斜率时分子要用实际的电压差，横截距也不再是短路电流。题型除了读图求 $E$ 和 $r$，还有比较两个电源的电动势和内阻（比纵截距和陡峭程度），以及图像没画完时自己延长补画、用内电压 $Ir$ 或 $E-U$ 分析。四道例题依次是读图求 $E$、$r$，纵轴不从 0 开始的坑，比较两条直线的 $E$、$r$，以及找出两个电源 $A$、$B$ 图像的错误说法。

## 知识卡

### bixiu3-48-c01　〔概念〕路端电压-电流关系图像是什么：由 $U=E-Ir$ 画出的向下倾斜直线

讲义第 3 页 · 视频 00:37 · 关键词：路端电压、U-I图像、路端电压-电流关系图像、闭合电路欧姆定律、U=E-Ir、一次函数、自变量、因变量、总电流、滑动变阻器 · 题型：概念、图像

老师说：路端电压和电流的关系，针对的是同一个电源。电路里同一个电源接一个滑动变阻器，滑动变阻器就是路端的电阻；电压表测的是路端电压，电流表测的是总电流。改变滑动变阻器的阻值，电压表和电流表的读数都会变，它们之间的关系就是之前学过的闭合电路欧姆定律 $U=E-Ir$。前两节课研究的都是这个表达式，这一节换一个角度：把电流 $I$ 当成自变量，把路端电压 $U$ 当成因变量，得到一个函数图像。类比数学里的 $y=kx+b$，把 $U$ 当成 $y$、$I$ 当成 $x$，就得到 $y=E-rx$。老师说，首先它是一个一次函数的图像；其次自变量 $I$ 的系数是负的（$-r$），说明图像向下倾斜。所以路端电压-电流的关系图像大致都是这个样子，一条向下倾斜的直线。老师说，对这个图像最重要的是要从中提取到关键信息。

### bixiu3-48-c02　〔结论〕纵截距：电流为零时的路端电压，等于电动势 $E$

讲义第 4 页 · 视频 02:12 · 关键词：纵截距、纵轴截距、电动势、E、开路、电流为零、路端电压等于电动势、U-I图像关键点 · 题型：概念、结论、图像、求电动势

老师说：图像关键信息一共三个，先看纵截距。纵截距指图像与纵轴交点到原点的距离，等于这个交点的纵坐标。这个点在纵轴上，横坐标为零，而横坐标表示电流，所以这个点的物理意义是电流为零时对应的路端电压。电流为零说明当前是开路（或近似开路），开路时路端电压 $U$ 就等于电动势 $E$（之前讲过）。所以纵截距的物理意义是电动势：当电流为零，路端电压等于电动势。老师说，这个图像如果问电动势是多少，就直接去找纵截距，这个点是最重要的一个点。〔整理注：也可以从 $U=E-Ir$ 看出，令 $I=0$ 得 $U=E$。〕

### bixiu3-48-c03　〔结论〕横截距：路端电压为零时的电流，是短路电流

讲义第 4 页 · 视频 03:19 · 关键词：横截距、横轴截距、短路电流、路端电压为零、短路、U-I图像关键点 · 题型：概念、结论、图像、判断

老师说：第二个关键信息是横截距，就是图像与横轴交点到原点的距离，等于这个交点的横坐标。这个点在横轴上，纵坐标为零，所以它的物理意义是路端电压为零时对应的电流。路端电压为零是什么意思？是短路。只有短路的时候，路端电压才为零。所以这个点的电流是短路电流。老师在最后总结时再次强调：横截距表示短路电流。注意这个结论有前提，纵轴要从 0 开始，纵轴不从 0 开始时横截距就不是短路电流，见本讲后面的易错卡片。

### bixiu3-48-c04　〔结论〕斜率的大小：等于电源内阻 $r$

讲义第 4 页 · 视频 04:02 · 关键词：斜率、斜率的大小、内阻、r、k=-r、一次函数、U-I图像关键点、陡峭程度 · 题型：概念、结论、图像、求内阻

老师说：第三个关键信息是斜率的大小。看表达式 $U=E-Ir$，$I$ 是自变量，根据一次函数的知识，自变量的系数叫斜率，就像 $y=kx+b$ 里 $x$ 的系数 $k$ 就是斜率。所以这个图像的斜率 $k=-r$（$I$ 的系数是 $-r$）。但电阻都是正的，没有负的，所以取斜率的大小，$|k|=r$。老师说，如果题目给你一个图像让你求内阻，就去算斜率的大小就可以了。〔整理注：斜率大小的算法就是直线上两点的纵坐标差除以横坐标差，例题 1 里写成这一段除以这一段。〕

### bixiu3-48-c05　〔方法〕给图像求电动势和内阻：电动势看纵截距，内阻算斜率大小

讲义第 5 页 · 视频 04:53 · 关键词：求电动势、求内阻、纵截距、斜率、U-I图像、读图、电动势和内阻、E、r · 题型：方法、图像、计算、选择题

老师说：这类题一般都是给你一个图，同时问你电动势和内阻。你要知道，让你算电动势的时候，看纵截距；让你算内阻的时候，算斜率的大小就可以了。具体做法是三步：第一步，读纵截距，得到电动势 $E$，先把电动势不对的选项排除；第二步，在直线上取这一段竖直长度除以这一段横向长度，算出斜率的大小，就是内阻 $r$；第三步，按算出的 $E$、$r$ 选答案。老师特别提醒，这种题有时会在题目里埋一个大坑，就是纵轴不从 0 开始，见下面的易错卡片。

### bixiu3-48-c06　〔易错〕大坑：纵轴不从 0 开始，算斜率的分子要用实际的电压差

讲义第 6 页 · 视频 06:49 · 关键词：纵轴不从0开始、U轴不从0开始、斜率、内阻、易错、坑点、电压差、U-I图像 · 题型：易错、图像、计算、选择题

老师说：这类图像题有时会在题目中埋一个很大的坑，很容易掉进去。例题 1 的 $U$ 轴是从 0 开始的，读 0、1、2、3，而例题 2 的 $U$ 轴是从 3 开始的，不是从 0 开始。老师说，考试中经常给一个不从 0 开始的 $U$ 轴，所以算的时候一定要注意纵轴是不是从 0 开始。以例题 2 为例：如果直接拿 6 除以 0.6 得到 10 Ω，就掉进坑里了，错了。因为纵轴从 3 开始，图像两端之间的竖直长度不是 6，应该是从 3 到 6，即 $6-3$，所以 $r=\frac{6-3}{0.6}=5\ \Omega$，选 B。老师说，这是考试中经常会考的一个出错点；可以等出错之后再总结，但听课时还没有考试，不如先有个意识，先打一个疫苗，病毒入侵时就能抵御住。老师要求大家把纵轴不从 0 开始的情况专门总结一下，这是一个过来人给大家的忠告。讲义上用红字写着：算斜率时，一定要注意纵轴是不是从 0 开始。

### bixiu3-48-c07　〔易错〕纵轴不从 0 开始时：电动势不受影响，横截距不再是短路电流

讲义第 6 页 · 视频 07:55 · 关键词：纵轴不从0开始、电动势、纵截距、横截距、短路电流、U=3V时的电流、易错、U-I图像 · 题型：易错、判断、图像

老师说：如果 $U$ 轴不从 0 开始，电动势不受影响，因为电动势是图像与 $U$ 轴的交点，不管纵轴从几开始，这个交点的纵坐标反正都是 6，所以不管图画的是从 0 开始还是从 3 开始，都是 6，不受影响；但算内阻就受影响了。同时，横截距也不再是短路电流：例题 2 里这个横截距 0.6 A 的含义是当 $U$ 等于 3 V 时对应的电流，因为这个点的纵坐标是 3，不是 0；而短路电流指的是 $U$ 等于 0 时对应的电流。所以老师要求大家一定要把 $U$ 轴不从 0 开始的情况专门总结一下。〔整理注：判断一个图里横截距算不算短路电流，先看横轴所在位置对应的纵坐标是不是 0。〕

### bixiu3-48-c08　〔方法〕比较两个电源的电动势和内阻：比纵截距，比陡峭程度

讲义第 7 页 · 视频 08:54 · 关键词：比较电动势、比较内阻、纵截距、斜率、陡峭程度、两个电源、U-I图像、E1、E2、r1、r2 · 题型：方法、图像、判断、选择题

老师说：这种图像题有时不让求具体的电动势和内阻，而是给两个图像，让你比较谁的电动势大、谁的内阻大。比较电动势，就看谁的纵截距大。比较内阻，内阻是斜率的大小，也就是 $k$ 的绝对值，看的是图像的陡峭程度：哪条线更陡，$|k|$ 就更大，内阻就更大。例题 3 里直线 1 的纵截距大，所以 $E_1>E_2$；直线 1 更陡峭、直线 2 更平缓，所以 $r_1>r_2$。老师说，比的时候就直接比纵截距和斜率就可以了。

### bixiu3-48-c10　〔方法〕内电压怎么比：$U_{内}=Ir$，也可以用 $E-U$

讲义第 8 页 · 视频 11:32 · 关键词：内电压、内阻分压、U内=Ir、E-U、路端电压、电动势、闭合电路欧姆定律、两种分析方法 · 题型：方法、判断、图像、选择题

老师说：内电压就是内阻的分压，应该等于 $I$ 乘以 $r$。例题 4 里已经分析过 $r_A>r_B$，所以当电流相等（都是 $I_1$）时，显然 $Ir_A>Ir_B$，两个电源的内电压是不相等的。老师说还可以换一个角度：内电压应该等于电动势减去路端电压，即 $E-U$。当电流都是 $I_1$ 时，两个电源的路端电压 $U$ 是相等的（图上两条线在 $I_1$ 处相交），但两个电源的电动势 $E$ 不相等（前面分析过 $E_A>E_B$），所以 $E-U$ 也不相等，同样推出内电压不相等。老师说，用内电压 $Ir$ 分析也行，用电动势减去路端电压分析也行，对闭合电路欧姆定律比较熟练之后，就有多种方式去分析。

### bixiu3-48-c12　〔例题〕例题 1：读 $U$-$I$ 图像求电源的电动势和内阻（纵轴从 0 开始）

讲义第 5 页 · 视频 05:14 · 关键词：U-I图像、电动势、内阻、纵截距、斜率、读图、求电动势和内阻 · 题型：例题、图像、计算、选择题

考点是读图求电动势和内阻。老师说，这种题经常让求电源的电动势和内阻，电动势看纵截距，内阻看斜率的大小。老师说这个图像非常简单，但这种题有时会在题目中埋一个大坑，下面专门看。〔整理注：这道题的纵轴从 0 开始，所以竖直长度就是 3，下一道题就不是这样了。〕

**题目**：如图所示为电源的路端电压 $U$ 与电流 $I$ 的图像，根据图像可求得该电源的电动势和内阻分别为（   ）
A. 电源的电动势为 $6$ V，内阻为 $2\ \Omega$
B. 电源的电动势为 $3$ V，内阻为 $2\ \Omega$
C. 电源的电动势为 $3$ V，内阻为 $0.5\ \Omega$
D. 电源的电动势为 $6$ V，内阻为 $0.5\ \Omega$

**解法**：

1. 求电动势：电动势就是纵截距，这个题的纵截距直接读出是 3，所以电动势 $E=3$ V，把 A、D 排除。
2. 求内阻：内阻是图线斜率的大小。斜率大小用这一段（竖直方向的 3，从 0 到 3）除以这一段（横轴方向的 6，从 0 到 6）。
3. 计算：$r=\frac{3}{6}=0.5\ \Omega$，选 C。

**答案**：C

### bixiu3-48-c13　〔例题〕例题 2：纵轴从 3 开始的 $U$-$I$ 图像求电动势和内阻（大坑）

讲义第 6 页 · 视频 06:20 · 关键词：纵轴不从0开始、U-I图像、电动势、内阻、斜率、测定电源电动势和内阻、易错、电压差 · 题型：例题、图像、计算、易错、选择题

考点是纵轴不从 0 开始的坑。老师说，这是考试中经常会考的一个出错点，要先打个疫苗，有了这个意识才不会错。〔整理注：分子用 $6-3$ 的原因是，直线上相距 0.6 A 的两点，电压从 6 V 降到 3 V，电压差是 3 V，斜率的大小是电压差除以电流差。〕

**题目**：在“测定电源电动势和内阻”的实验中，某同学根据实验数据，作出了 $U$-$I$ 图像，如图所示。由图像我们可以得到电源电动势 $E$ 和内阻 $r$ 分别为（   ）
A. $E=3$ V，$r=5\ \Omega$
B. $E=6$ V，$r=5\ \Omega$
C. $E=3$ V，$r=10\ \Omega$
D. $E=6$ V，$r=10\ \Omega$

**解法**：

1. 求电动势：电动势直接看纵截距，是 6 V，把 A、C 排除。
2. 错误做法：照例题 1 的办法用这一段除以这一段，$r=\frac{6}{0.6}=10\ \Omega$，选 D，错了。
3. 找出区别：这个图的 $U$ 轴不是从 0 开始，而是从 3 开始，所以竖直这一段的长度不是 6，应该是从 3 到 6，即 $6-3$。
4. 正确计算：$r=\frac{6-3}{0.6}=5\ \Omega$，选 B。
5. 补充：$U$ 轴不从 0 开始时，电动势不受影响（纵截距仍是 6 V），但内阻要受影响；右端点 0.6 A 是 $U=3$ V 时的电流，不是短路电流。

**答案**：B

### bixiu3-48-c14　〔例题〕例题 3：直线 1、2 是两个电源的 $U$-$I$ 图像，比较电动势和内阻

讲义第 7 页 · 视频 08:54 · 关键词：比较电动势、比较内阻、两个电源、纵截距、陡峭程度、U-I图像、E1、E2、r1、r2 · 题型：例题、图像、判断、选择题

考点是比较两个电源的电动势和内阻，不求具体数值。老师说，比的时候直接比纵截距和斜率就可以了。

**题目**：如图，直线 1、2 分别是两个电源的路端电压随电流变化的图像，由图可知（   ）
A. 电动势 $E_1>E_2$，内阻 $r_1<r_2$
B. 电动势 $E_1>E_2$，内阻 $r_1>r_2$
C. 电动势 $E_1<E_2$，内阻 $r_1>r_2$
D. 电动势 $E_1<E_2$，内阻 $r_1<r_2$

**解法**：

1. 比电动势：电动势看谁的纵截距大。图中直线 1 的纵截距更大，所以 $E_1>E_2$。
2. 比内阻：内阻是斜率的大小，也就是 $|k|$，看图像的陡峭程度。直线 1 比较陡峭，直线 2 比较平缓，所以直线 1 的 $|k|$ 更大，$r_1>r_2$。
3. 结论：$E_1>E_2$，$r_1>r_2$，选 B。

**答案**：B

### bixiu3-48-c15　〔例题〕例题 4：两电源 $A$、$B$ 的 $U$-$I$ 图像，选出错误的说法

讲义第 8 页 · 视频 09:50 · 关键词：两个电源、U-I图像、延长补画、电动势比较、内阻比较、干路电流、内电压、E-U、错误选项、交点 · 题型：例题、图像、判断、选择题、错误选项

考点是综合运用图像：比纵截距、比斜率、看交点、用内电压分析。老师说，题目选错误，要逐个判断；图像不完整就自己补画；内电压用 $Ir$ 或 $E-U$ 都可以分析。〔整理注：干路电流就是总电流。〕

**题目**：下图为两个电源 $A$ 和 $B$ 分别连接纯电阻电路时的路端电压 $U$ 与其总电流 $I$ 的关系图像，则下列说法错误的是（   ）
A. 电路 $A$ 的电动势大于电路 $B$ 的电动势
B. $A$ 中电源的内阻大于 $B$ 中电源的内阻
C. 路端电压都为 $U_1$ 时，它们的干路电流相同
D. 电流都是 $I_1$ 时，两电源内电压相等

**解法**：

1. 注意题目选的是错误的说法。
2. A：电动势看纵截距，图像没画出纵截距，就自己延长补画（A 画到纵轴，B 也画到纵轴），明显 A 的纵截距更大，A 对，不能选。
3. B：内阻看倾斜程度，A 比较陡峭，B 比较平缓，所以 A 的内阻大于 B，B 对，不能选。
4. C：路端电压都是 $U_1$ 时，A 对应的电流是 $I_1$，B 对应的电流也是 $I_1$（两条线正好在这里有个交点），干路电流（总电流）相同，C 对，不能选。
5. D：内电压是内阻的分压，等于 $Ir$，$r_A>r_B$，电流相等时 $Ir_A>Ir_B$，内电压不相等；换一个角度，内电压等于 $E-U$，电流都是 $I_1$ 时 $U$ 相等，但 $E$ 不相等，$E-U$ 也不相等。所以 D 错误，选 D。

**答案**：D
