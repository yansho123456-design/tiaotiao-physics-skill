# 安培定则（右手螺旋定则）

一句话：安培定则讲的是电流和它产生的磁感线之间的位置与方向关系，可以用右手点赞手势来判断。老师不按学校的「握电、握磁」两套讲法教，而是把电和磁都删掉，只看「直线穿环」：已知直线的方向，大拇指对直线，四指看环；已知环的方向，四指对环，大拇指看直线。点叉表示法（叉进点出）是配套的工具，用来在纸面上画垂直于纸面的箭头。〔卡 bixiu3-67-c05、bixiu3-67-c06、bixiu3-67-c07、bixiu3-67-c27〕

## 老师怎么讲

### 学校的讲法为什么容易晕，以及四个常见问题（必修3第67讲）

老师说，安培定则是磁场中一个非常重要的技能，已知电流判断磁的方向，或者已知磁判断电流方向，都要用到它。这个定则本身不难，但无数同学学不懂，原因是学校的讲法有问题。学校一般讲两种：通电直导线，右手握住导线，大拇指指电流方向，四指表示磁感线的环绕方向；通电螺线管，右手握住螺线管，四指弯曲与电流方向一致，大拇指表示螺线管的 N 极，也就是管内磁感线的方向。老师指出，第一种里大拇指指的是电流，第二种里大拇指指的是磁感线方向，一会儿大拇指表示电、一会儿表示磁，听一遍就懵了，情况一多自己做题时完全搞不定。〔卡 bixiu3-67-c01〕

![讲义第 3 页原图：学校里常讲的两条安培定则，左边是右手握直导线，大拇指指电流、四指环绕方向是磁感线；右边是右手握螺线管，四指沿电流、大拇指指 N 极。老师说这样讲大拇指一会儿表示电、一会儿表示磁，容易讲晕](https://panda-1.tail2e9885.ts.net/wuli/img/bixiu3-67-school-two-rules.png)

老师列出同学们最常见的四个问题。第一，左右手分不清，这个老师帮不了，得靠自己克服。第二，点叉分不清，因为磁场经常用点叉表示，点叉常搞反。第三，到底握磁还是握电搞不清，有时握电有时握磁。第四，已知电判断磁会了，已知磁判断电又完全懵了。老师说除了第一个，其余三个这节课彻底解决：点叉靠面前一张纸来判断，握电握磁、知电判磁与知磁判电靠跳氏安培定则把电磁删掉来解决。课程结尾他逐条回头验证了这四个问题。〔卡 bixiu3-67-c02、bixiu3-67-c27〕

### 点叉表示法（必修3第67讲）

老师说，大部分同学第一次见到点叉是学磁场时用点叉表示磁场，先入为主以为点叉只能表示磁场，后来遇到点叉表示电流的题就炸了。其实点叉是一种通用的表示方法，用来表示箭头，既可以表示电流，也可以表示磁感线。为什么要用点叉：因为我们生活在三维空间。箭头就在纸面内，直接在平面上画箭头就行；箭头与平面垂直，要在平面上画出来，就得用点和叉。老师特别强调，只有箭头与平面垂直时才能用点和叉；箭头虽然不在平面内但也不垂直，是斜着的，也不能用点叉。〔卡 bixiu3-67-c03〕

怎么判断画点还是画叉：想象面前有一张白纸，把手指伸出来，用手指把白纸捅一个洞，直接往前伸、插进去。这时指尖的方向对应叉，叉就是插进去（老师说叉和插读音一样），箭头方向从你的脸出发、指向白纸，在纸上画一个叉。反方向则是把手绕到白纸后面，手指通过小洞钻出来，从你眼睛看就是手指钻出来，用点表示，箭头方向从白纸出发、指向你的脸。老师说如果忘记方向，就想你的手指沿什么方向最简单地能把纸捅个洞，那个方向就是插进去的方向。〔卡 bixiu3-67-c04〕

### 安培定则的内容，以及「直线穿环」的简化（必修3第67讲）

安培定则也叫右手螺旋定则，是安培发现的。直线电流产生的磁感线是一圈一圈的闭合环（老师补充，看电流产生的磁感线时，磁感线都是闭合曲线这一点很明显）。右手摆成点赞手势放在自己面前，电流是直的，大拇指也是直的，电流向上时，四指圈起来的方向就与磁感线环绕方向对上。环形电流则是右手点赞，大拇指向右指，中间穿过的磁感线是直的，与大拇指对应，四指弯成的环与电流的箭头也能对上。老师提醒，讲义上手的照片是他自己的视角，要把右手摆在自己面前，看到的和照片一样才算摆对。讲义结论是：电流、磁感线的位置和方向满足右手点赞（右手螺旋）手势。〔卡 bixiu3-67-c05〕

老师说，他自己一开始也是按学校的方法学，有一天做题时突然开悟：大量做题之后发现，所有电和磁的位置关系都可以简化成直线穿环的模型。不管哪个是电哪个是磁，单纯看图都是直线穿环。题目给的已知要么是直线的方向，要么是环的方向：给了直线，右手比划来比划去，其实是为了确定环的方向；给了环，比划来比划去，其实是为了确定直线的方向。就算题目给了一条直线却没告诉你是电还是磁，也能把环的方向确定出来。确定完也不用担心这个环是电还是磁：一共就两样东西，已知给的是电，分析出来的肯定是磁；已知给的是磁，分析出来的一定是电。所以老师把电和磁直接删掉，只确定方向，之前纠结的什么时候四指表示电、什么时候四指表示磁的问题就彻底解决了。讲义红字：其实电磁不重要，只要已知直线方向会确定环方向，或已知环方向会确定直线方向就可以了。〔卡 bixiu3-67-c06〕

### 跳氏安培定则的步骤（必修3第67讲）

这是老师总结的方法的精髓：分析时把电磁直接删掉，核心放在方向上，也就是确定环和直线的方向。第一步，把右手握成点赞手。第二步分两种情况：已知直线的方向，握住这条直线，大拇指的指尖和直线的箭头保持一致，环的方向看四指；已知环的方向，让四个指头弯成的环和已知的环对上，直线的方向直接看大拇指。老师总结的十二字真言是「直线穿环，确定方向，忘掉电磁」。〔卡 bixiu3-67-c07〕

### 怎么表示「环」的方向（必修3第67讲）

老师说，怎么表示环的方向，学校老师上课都不讲，但这个点不清楚，真正做题画图时一定会有疑问。分两种情况。

环就在纸面上：它就是个圆，顺时针还是逆时针，在圆上画一个小箭头就看得出来。想表示环上某一点的方向，就过这个点作一条切线，箭头沿切线方向。〔卡 bixiu3-67-c08〕

环与纸面垂直：老师用跳跳的项圈当标准圆环，为简单起见只研究圆环正好被纸面一分为二、一半在纸前一半在纸后的情况。这时你面对着纸，看到的是一条线。圆环在与纸面相交的点处，方向沿这一点的切线，而纸面正好是圆环的直径所在处，所以切线与纸面垂直。结合你的眼睛：右边这个点，箭头从眼睛出发指向纸面、插进去，画叉；左边这个点，箭头钻出来，画点。所以看它在哪个点插进去、哪个点钻出来，插进去的画叉，钻出来的画点，一个叉、一个点就把圆环的方向画出来了。老师说，学校不专门讲这个的话，看到点叉你无论如何想不到它是个环。〔卡 bixiu3-67-c09、bixiu3-67-c14〕

### 知直求环（必修3第67讲）

已知直线、求环的方向，老师说就两种情况。

直线在纸面上：直接给一个箭头，环肯定垂直穿过纸面。握这条直线，大拇指跟箭头方向一致（图中都向上），四个指头一定是从箭头的右边插进纸面、从左边钻出来，所以这条直线对应的环是右边一个叉、左边一个点。〔卡 bixiu3-67-c10〕

直线垂直纸面：已知是一个叉，叉表示插进去的箭头，直线与纸面垂直，环就在纸面上。箭头是插进去的，大拇指也要插进去，往前去捅这张纸，这时四指握成的圆，方向看四指指尖，是顺时针。〔卡 bixiu3-67-c11〕

### 知环求直（必修3第67讲）

已知环、求直线的方向，老师讲了四种给法。

环在纸面上：比如图中是逆时针。四指在纸面上跟它一模一样，环是什么方向，指尖就是什么方向，大拇指指向你自己的脸，从纸面指向自己的脸是钻出来，所以穿过圆的直线是个点，在圆中间标一个点。〔卡 bixiu3-67-c12〕

〔整理注：卡 bixiu3-67-c12 的整理注推出，环顺时针时大拇指应指向纸里，直线画叉；老师在那一页没有单独讲。〕

老师特别提醒一点：如果这个环表示的是环形电流，磁场在环内和环外不一样，要么里面是点、外面是叉，要么里面是叉、外面是点。比出一个点之后，不要纠结它在环内还是环外。用的是直线穿环，这条直线一定在环内，所以它表示的一定是环内的方向。比出来是点，就说明环内磁场是点、环外是叉。〔卡 bixiu3-67-c13〕

一个点一个叉（讲义里用虚线连起来）表示一个环，这个环从右边扎进去、从左边出来，环与纸面垂直。你的四指也从右边扎进去、左边出来，大拇指应该往上，所以中间穿环的直线方向向上。老师说这种表示一般表示环形电流，看得见的环就多给两个虚线，但现在不管电磁，只要知道这是一个环就够了。〔卡 bixiu3-67-c14〕

一条线的一边是一排点、另一边是一排叉：把每个点叉对当成一个小环，选一个来分析，同样右边进去、左边出来，大拇指朝上，中间这条直线方向朝上。〔卡 bixiu3-67-c15〕

环内是点、环外是叉：有两种比法，老师说都行。第一种，看成一个环，中心穿环的直线是点，大拇指比个点指向你的脸，四指指尖方向就是环的方向，应该是逆时针。第二种，看环上一小段，一边点一边叉就是一个小环，从右边扎进去、左边扎出来，大拇指往上，这一小段的方向向上，整个环的方向也就确定了，结果一样。老师说看你自己觉得哪种爽就用哪种。〔卡 bixiu3-67-c16〕

### 螺线管（必修3第67讲）

老师说，螺线管很多同学特别不好想象，其实很简单：螺线管就是绕了一圈一圈的导线，每圈导线是一个环，只分析一个环就行。先把纸面想象成正好把螺线管一分为二的位置，像易拉罐被纸面切成两半。题中的例子是电源正极在右边，电流从背后走到前面，从上面的点钻出来，从正面走到下面，再从纸面扎进去回到背面，所以每圈上面是点、下面是叉。圆环是下面扎进去、上面出来，你的四指也下面扎进去、上面出来，这时大拇指向右，螺线管的磁感线就是向右的。只要分辨出螺线管上每个环是上面进下面出，还是上面出下面进，确定了上下谁是点谁是叉，就回到知环求直。〔卡 bixiu3-67-c17〕

### 小磁针与电子流两个坑（必修3第67讲）

小磁针：小磁针的 N 极跟磁感线方向一致。例如通电螺线管内部放一个小磁针，N 极在左边，说明管内磁感线一定向左，相当于直线的方向已经告诉你了，大拇指往左指，四指弯成的环就是每一环电流上面进、下面出，再结合电源正负极和螺线管的 N 极就能定下来。小磁针指向的 N 极端，也就是螺线管的 N 极端。〔卡 bixiu3-67-c20〕

电流方向与电子运动方向相反：老师说，直线的方向要么是电流的方向，要么是磁感线的方向，直线不能是电子的运动方向。电子流向上，要先转化成电流向下，这才是真正的直线的方向，直接按电子方向比划会得到错误答案。老师说这一点电路部分讲过好多次，这是一个小坑，并且强调不要小看安培定则，高考也有概率直接考。〔卡 bixiu3-67-c23〕

### 分子电流假说（必修3第67讲）

安培提出分子电流假说，用来解释为什么有的东西有磁性（比如磁铁），有的东西没有。设想是：万物都由分子构成，每个分子都有一个环形电流。有磁性的东西，内部的这些环形电流排列整齐，每一个的磁感线都向右，叠加起来表现为右边是 N 极、左边是 S 极。像木头这样的物质，内部环形电流杂乱，磁感线相互抵消，就没有磁性。老师说，这个假说的核心其实就是环形电流，所以考试出题的话就会考环形电流。〔卡 bixiu3-67-c25〕

### 与左手定则分左右手（必修3第69讲）

老师在左手定则一讲里提前给了一个区分左右手的办法：以后学到电磁感应，会出现一会儿用左手、一会儿用右手，有时一道题要同时用左手和右手，容易混。只要跟力有关的，都是左手；跟力无关的，通通用右手。左手定则是判断力的方向的，用左手；安培定则是给电判磁、给磁判电，里面没有力，所以用右手。〔卡 bixiu3-69-c03〕

### 箭头电流的磁场方向（必修3第72讲）

到了磁场叠加一讲，老师把第 67 讲的「知直求环」用在题目里的箭头形电流上：电流是个箭头，就在纸面上，用右手去握这个箭头，大拇指指向箭头方向，看四指从纸的哪一面插进去、从哪一面钻出来，插进去的那一边是叉，钻出来的那一边是点。例子：箭头朝上，四指从右边插进去、左边出来，所以右边是叉、左边是点；箭头水平向右，四指从下面插进去、上面钻出来，所以下面是叉、上面是点。老师说这块如果还有问题，去看专门讲安培定则的那节课，所有判断磁场方向的问题都能解决。〔卡 bixiu3-72-c06〕

老师在这一讲开头还说，磁场叠加考的就是安培定则：题目会先给电流，让你用安培定则把每个电流的磁场分析出来，再做合成，安培定则用得对，后面的合成不难。电流有箭头形和点叉形两种给法，点叉形分析起来要麻烦一些。〔卡 bixiu3-72-c01〕

### 点叉电流的磁场：连线做垂线，再用叉顺点逆（必修3第72讲）

点叉电流产生的磁场是以电流为圆心的一个个同心圆，所以某点的 $B$ 一定是圆在这个点的切线。切线跟半径垂直，所以不用真的画圆，把这个点和电流连起来，再做这条连线的垂线就行，这样既好画也比较准确。但还要知道是垂线的哪个方向，这要看圆环磁场的方向：叉电流用右手比划，大拇指对着进去，四指指尖是顺时针；点电流是逆时针，与叉相反。所以步骤是两步：第一步，把这个点跟电流连线，做垂线；第二步，根据圆环磁场方向（顺时针还是逆时针）判断是垂线的哪头。老师还提醒，顺时针逆时针要分得清，分不清看家里的钟表。〔卡 bixiu3-72-c14〕

![老师画的点叉电流圆环磁场：叉电流的圆环磁场是顺时针，点电流的圆环磁场是逆时针；任一点的 $B$ 沿圆的切线，与这点到电流的连线垂直；图中点的位置是自取的](https://panda-1.tail2e9885.ts.net/wuli/img/bixiu3-72-xshun-dian-ni.png)

老师给的小口诀是「叉顺点逆」，比每次用右手比划要快。口诀要配合上面的两步用：先连线做垂线，再用叉顺点逆定垂线的哪头。〔卡 bixiu3-72-c15〕

题目一般不会给出围着电流的那一圈圆。不熟练时可以只画这个点附近的一小段圆弧：叉是顺时针，就按顺时针转向画这一小段；点是逆时针，就按逆时针转向画。画圆弧的目的是帮你看清楚顺时针到底是哪个方向。很熟练可以直接分辨，不熟练画一小段圆弧，再不熟练就把整个圆画出来，不过老师说一般不至于。〔卡 bixiu3-72-c16〕

### 环形电流等效成磁铁（必修3第73讲）

环形电流一讲里，老师用安培定则把环形电流等效成一块磁铁。第一步，用俯视的视角把环画出来：想象有一个平面，环穿过这个平面，俯视只能看到一条线，哪边扎进去画叉、哪边钻出来画点。以讲义第 4 页的悬挂线圈为例，线圈左边扎进去，是叉；右边钻出来，是点，所以表示成左边一个叉、右边一个点。老师提醒，这一步是整道题唯一的难点，要看清电流从哪边进、哪边出。〔卡 bixiu3-73-c02〕

第二步，用安培定则画磁感线：叉的周围一圈、点的周围一圈。看最中间那根磁感线，如果箭头朝下，就等效成条形磁铁，下面是 N 极、上面是 S 极。老师强调等效时就用中心这根磁感线。〔卡 bixiu3-73-c03〕

![按安培定则画出俯视图（左叉右点）的磁感线：叉周围顺时针、点周围逆时针，两边的磁感线在中间都朝下，最中间那根磁感线（红色箭头）朝下；形状按老师板书的一圈一圈重画](https://panda-1.tail2e9885.ts.net/wuli/img/bixiu3-73-ring-topview-field.png)

### 由 B感 的方向判断 I感：叉顺点逆（电磁感应第 5 讲）

楞次定律进阶一讲里，老师把必修三的叉顺点逆当作快速判断电流方向的实用口诀拿出来用。已知一个环形电流在环中间产生的磁场方向，就能判断这个环形电流的方向。叉顺：环中间的磁场是叉场（垂直纸面向里），电流一定是顺时针，用安培定则比划，大拇指朝纸面里面伸，四个指头就是顺时针的指向。点逆：环中间的磁场是点场（垂直纸面向外），电流一定是逆时针。老师说这个口诀做题特别实用，因为分析楞次定律的题，就是要根据 B感 的方向推出 I感 的方向：B感 是叉，I感 一定是顺时针；B感 是点，I感 一定是逆时针。B感 沿竖直方向时，老师用右手握一下的办法，大拇指指向 B感，从上往下看四指的方向就是电流方向，例如 B感 向上，从上往下看是逆时针。〔卡 dianci-05-c02〕

![叉顺点逆：环形电流在环内产生的磁场是叉（垂直纸面向里），电流一定是顺时针；是点（垂直纸面向外），电流一定是逆时针；讲义原页只有两个空圆，叉、点和箭头按老师讲解补画](https://panda-1.tail2e9885.ts.net/wuli/img/dianci-05-cross-dot-rule.png)

### 环形电流圈内圈外磁场反向（电磁感应第 6 讲）

双圈问题一讲开头先复习环形电流的磁场。老师说环形电流有磁效应，环内、环外都有磁场，但磁感线方向不同。例如环内每一条磁感线都是从下往上穿过环，因为磁感线是闭合曲线，穿过环之后在环外要从上往下转回来，所以圈内圈外 $B$ 的方向相反。判断方向用叉顺点逆：电流是顺时针，环中间产生叉形磁场，环外面就是点形磁场；电流是逆时针，环内部是点形磁场，环外面是叉形磁场。因为每条磁感线都是闭合的，所有内部的磁感线都要从外部绕回来，所以环内与环外的磁感线条数一样多。有人问正中间那条是直的，老师的回答是把它理解为在无限远的地方绕回来，总之内外磁感线总条数一样多。老师说叉顺点逆这个口诀在必修三系统课讲过，上一节课也专门复习了。〔卡 dianci-06-c02〕

![老师板书：顺时针的环形电流，圈内产生叉形磁场，圈外产生点形磁场（叉表示垂直纸面向里，点表示垂直纸面向外）](https://panda-1.tail2e9885.ts.net/wuli/img/dianci-06-ring-field-cw.png)

![老师板书：逆时针的环形电流，圈内产生点形磁场，圈外产生叉形磁场](https://panda-1.tail2e9885.ts.net/wuli/img/dianci-06-ring-field-ccw.png)

〔整理注：这两讲沿用的是第 67 讲「知环求直」和「环内是点、环外是叉」的结论，只是换了用途：必修三用它在纸上画磁场，电磁感应用它由 B感 反推 I感。第 5 讲的叉顺点逆说的是「环中间的磁场是叉或点，环电流是顺时针或逆时针」，而必修三第 72 讲的叉顺点逆说的是「叉电流或点电流周围的磁场是顺时针或逆时针」。两句话的对象不同，一个讲环中心的直线，一个讲垂直纸面的直线电流，但都是第 67 讲直线穿环的同一个手势，口诀字面一样。第 5 讲和第 6 讲都说这个口诀是必修三讲过的，两讲没有说它出自必修三的第几讲，把它对到第 72 讲是整理者的归纳。第 6 讲圈外方向相反的说法，老师给的理由是磁感线闭合，第 67 讲讲的是用的是直线穿环，直线在环内，所以比出来的一定是环内的方向（卡 bixiu3-67-c13），两处讲的是同一件事。〕

## 几讲之间的关系

〔整理注：这几讲是同一套办法在不同题型里的逐步使用。第 67 讲把办法建立起来，把「电」「磁」两个身份删掉，只保留直线和环两种形状。第 72 讲遇到的题目只给箭头形或点叉形电流，用的就是第 67 讲的「知直求环」：箭头形电流是直线在纸面上，点叉形电流是直线垂直纸面。第 72 讲又从中提炼出叉顺点逆，省掉每次比划，适用的前提是电流垂直纸面，也就是第 67 讲的「直线垂直纸面」一类。第 73 讲反过来，把环画成一叉一点，用的是第 67 讲「环垂直于纸面」的画法，再看中心磁感线的方向，是「知环求直」。第 69 讲只提供一个区分左右手的原则，安培定则与力无关，所以用右手。〕

〔整理注：电磁感应第 5、6 讲回头用的是第 67 讲的「知环求直」，方向反了过来：楞次定律里先由磁通量变化定出 B感，再用叉顺点逆定 I感，也就是已知直线（环中心的磁场）求环（电流）。条件没有变，仍是环中心的直线方向对应环的方向，环内环外相反。第 6 讲多出来的是把环外的方向一起说清，并解释了条数相等，这是第 67 讲没有展开的部分。〕

〔整理注：叉顺点逆在第 67 讲没有以口诀出现，第 67 讲只在例题里得到「直线是叉，环顺时针」和「环内是点时环逆时针」。把它们说成同一件事是整理者的归纳。〕

## 做题套路

1. 先看清题目给的是直线还是环，不管它是电还是磁。〔卡 bixiu3-67-c06、bixiu3-67-c07〕
2. 右手握成点赞手。已知直线，大拇指对直线，环的方向看四指。已知环，四指对环，直线的方向看大拇指。〔卡 bixiu3-67-c07〕
3. 如果直线是电子流，先换成相反方向的电流再当直线。〔卡 bixiu3-67-c23、bixiu3-67-c24〕
4. 画点叉时想面前一张纸，手指从脸指向纸是叉，从纸指向脸是点。〔卡 bixiu3-67-c04〕
5. 直线在纸面上，环就垂直穿纸面：箭头朝上时右边叉、左边点。〔卡 bixiu3-67-c10、bixiu3-72-c06〕
6. 螺线管只分析一个环，先看上下哪边是点、哪边是叉，再回到知环求直。〔卡 bixiu3-67-c17〕
7. 给小磁针：N 极指向就是磁感线方向，相当于直线方向已知。〔卡 bixiu3-67-c20〕
8. 点叉电流求某点的 $B$：连线做垂线，再用叉顺点逆定垂线的哪头；不熟练就画一小段圆弧。〔卡 bixiu3-72-c14、bixiu3-72-c15、bixiu3-72-c16、bixiu3-72-c23〕
9. 环形电流等效成磁铁：俯视画成一叉一点，再看中心磁感线朝向，朝下的一端是 N 极。〔卡 bixiu3-73-c02、bixiu3-73-c03〕
10. 楞次定律里由 B感 定 I感：B感 是叉，I感 顺时针；B感 是点，I感 逆时针；B感 竖直时右手握一下，大拇指指 B感，从上往下看四指。〔卡 dianci-05-c02〕
11. 环形电流的磁场圈内圈外相反：顺时针电流圈内叉、圈外点，逆时针电流圈内点、圈外叉。〔卡 dianci-06-c02〕

## 口诀

- 叉进点出（讲义写作 ×进·出）：叉表示插进去，点表示钻出来。〔卡 bixiu3-67-c04、bixiu3-67-c27〕
- 直线穿环，确定方向，忘掉电磁（十二字真言）。〔卡 bixiu3-67-c07、bixiu3-67-c27〕
- 右手握成点赞手，已知直用大拇指对，已知环用四指对。〔卡 bixiu3-67-c27〕

- 只要跟力有关的都是左手，与力无关的是右手。〔卡 bixiu3-69-c03〕
- 叉顺点逆（电磁感应用法）：环中间的磁场是叉，环形电流顺时针；是点，逆时针。〔卡 dianci-05-c02〕

## 易错

- 点叉分不清：想面前一张纸，叉是插进去，点是钻出来。〔卡 bixiu3-67-c02、bixiu3-67-c04〕
- 点叉只用于箭头垂直于纸面的情况，斜着的箭头不能用点叉。〔卡 bixiu3-67-c03〕
- 以为点叉只能表示磁场，其实也可以表示电流。〔卡 bixiu3-67-c03〕
- 知环求直时比出来的点或叉，一定是环内的方向，不要纠结它在环内还是环外。〔卡 bixiu3-67-c13〕
- 直线不能是电子的运动方向，电子流要先换成相反的电流方向。〔卡 bixiu3-67-c23、bixiu3-67-c24〕
- 讲义页面上老师在例题 3 题号处圈了 B，但口头解答是 B 和 C 都对，卡片按两个都对记。〔卡 bixiu3-67-c21〕

## 例题

- **必修3第67讲 例题 1**：画出三个彼此独立的图中 P 点的磁感线方向。图 1 电流向上、P 在右侧；图 2 电流向下、P 在右侧；图 3 电流垂直纸面向里、P 在右上方。答案：图 1 为叉，图 2 为点，图 3 沿以电流为圆心的圆在 P 点的切线，向右下。要点：三问都是知直求环，大拇指对直线，右手四指从右边插入还是从左边插入决定右边是叉还是点；图 3 按自己的视角，大拇指指向纸面，四指方向就是磁感线环绕方向。〔卡 bixiu3-67-c18〕
- **必修3第67讲 例题 2**：六张图补画电流方向或磁感线方向，a、b 是直线电流，c、d 是环形电流，e、f 是螺线管。答案：a 中间电流叉（垂直纸面向里）；b 直线电流向上；c 环形电流逆时针；d 环中间的磁感线向上；e 管内磁感线向左；f 管内磁感线向右。要点：完全不管电和磁，只看给的是直的还是环的方向。〔卡 bixiu3-67-c19〕
- **必修3第67讲 例题 3**（百强高中辽宁阜新实验中学 2018-2019 高二上）：通电螺线管内小磁针静止，判断电源哪端是正极、螺线管哪端是 N 极。答案 BC：b 端为电源正极，c 端为通电螺线管 N 极。要点：小磁针 N 极向左，管内磁感线向左，大拇指向左，每环电流上面进、下面出，推出电流从 b 端出发；小磁针 N 极指向螺线管的 N 极端。〔卡 bixiu3-67-c21〕
- **必修3第67讲 例题 4**：判断四种情形下小磁针静止时指向哪个正确（条形磁铁、环形电流、螺线管、直线电流）。答案 C。要点：A 用同名磁极相斥、异名磁极相吸，不用安培定则；B、C、D 用安培定则，螺线管要看清上下哪个是扎进去、哪个是扎出来；D 中磁感线垂直于纸面，小磁针不会在纸面上。〔卡 bixiu3-67-c22〕
- **必修3第67讲 例题 5**（2016 年上海高考）：电子沿 $z$ 轴正向流动，求 $y$ 轴上 A 点磁场方向。答案 A（$+x$ 方向）。要点：电子向上，电流向下，以电流向下为直线方向；若直接按电子向上比划，会得到 B。〔卡 bixiu3-67-c24〕
- **必修3第67讲 例题 6**（百强高中湖北武汉六校联考 2018-2019 高二上）：安培用环形电流解释地磁场，求电流方向。答案 A：由东向西垂直磁子午线。要点：把地球看成一个巨大的分子，地磁场在地球内部向下（老师上节课讲过），先定直线方向向下，再用右手点赞手确定环形电流的方向。〔卡 bixiu3-67-c26〕
