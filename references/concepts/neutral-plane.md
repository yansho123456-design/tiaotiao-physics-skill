# 中性面与平行面

一句话：线圈在匀强磁场里转动，线圈平面与 $B$ 垂直的位置叫中性面，此时磁通量 $\Phi$ 最大，$e$、$u$、$i$ 都为 0，电流在这里改变方向；线圈平面与 $B$ 平行的位置叫平行面，此时 $\Phi=0$，$e$、$u$、$i$ 最大。磁通量和电动势像一家人，不会同时最大，一个最大时另一个为 0。〔卡 jiaobian-02-c08、jiaobian-02-c09、jiaobian-02-c11〕

## 老师怎么讲

### 从切割边的速度方向看 $e$ 的大小（交变电流第 1 讲）

第 1 讲还没有使用「中性面」这个名字，讲的是怎样判断表达式是 sin 还是 cos。老师教的办法是不用记，画一画 0 时刻的速度方向就行：以线框面与 $B$ 垂直的时刻作为 0 时刻，切割的两条边速度与 $B$ 平行，$v\parallel B$，不切割，电动势为 0，函数值是 0，所以是 sin 函数。以线框面与 $B$ 平行的时刻作为 0 时刻，切割的两条边速度与 $B$ 垂直，$v\perp B$，电动势最大，函数值也最大，所以是 cos 函数。〔卡 jiaobian-01-c15〕

老师还说，速度方向与 $B$ 垂直的时刻，函数值最大，不管表达式是 $NBS\omega\sin\omega t$ 还是 $NBS\omega\cos\omega t$，最大时 sin 或 cos 都是 1，电动势就是 $NBS\omega$。再根据法拉第电磁感应定律 $e=n\dfrac{\Delta\Phi}{\Delta t}$，$e$ 最大就说明 $\dfrac{\Delta\Phi}{\Delta t}$ 最大，即磁通量随时间的变化率最大。老师提醒，不要学了后面的忘了前面的。〔卡 jiaobian-01-c23〕

〔整理注：第 1 讲讲的是 $v\parallel B$ 与 $v\perp B$ 两种位置对应的 $e$，第 2 讲再给这两个位置起名叫中性面和平行面，并补上磁通量这一条。两讲讲的是同一件事。〕

### 中性面与平行面的定义和特点（交变电流第 2 讲）

中性面指的是与磁场 $B$ 垂直的平面。以讲义的图为例，$B$ 水平向右，线圈竖起来时处在中性面。线圈沿箭头逆时针转，产生交流电的是 CD 边和 AB 边切割磁感线。线圈竖起来的瞬间，CD 边速度水平向左，AB 边速度水平向右，两条边的速度都与 $B$ 平行，不切割磁感线，所以 $e$ 为 0，$u$、$i$ 也为 0。老师说，中性就是既不正也不负，这是名字的来由。这时线圈平面与 $B$ 垂直，穿过线圈的磁通量最大。所以中性面的特点是：$B$、$v$ 平行，$e$、$u$、$i$ 均为 0，磁通量 $\Phi$ 最大。中性面上电流改变方向：电流先从某个方向减小到 0，到达中性面，下一刻方向就反过来了，所以中性面是电流改变方向的位置。〔卡 jiaobian-02-c08〕

![线圈竖起来，与 B 垂直，处在中性面：AB、CD 两边速度与 B 平行，不切割磁感线](https://panda-1.tail2e9885.ts.net/wuli/img/jiaobian-02-coil-neutral.png)

平行面指与磁场 $B$ 平行的平面。图中 $B$ 是水平方向，线圈转到水平位置就处于平行面。此时 CD 边速度竖直向下，AB 边速度竖直向上，两条边的速度都与 $B$ 垂直，$B$、$v$ 垂直时电动势最大，所以 $e$、$u$、$i$ 都最大。另一方面，线圈平面与 $B$ 平行，没有一条磁感线能穿过线圈，磁通量 $\Phi$ 为 0。平行面的特点正好与中性面相反：$B$、$v$ 垂直，$e$、$u$、$i$ 最大，$\Phi$ 为 0。〔卡 jiaobian-02-c09〕

![线圈转到水平，与 B 平行，处在平行面：AB、CD 两边速度与 B 垂直，电动势最大](https://panda-1.tail2e9885.ts.net/wuli/img/jiaobian-02-coil-parallel.png)

### 在 i-t 图和 e-t 图上找这两个面（交变电流第 2 讲）

中性面对应 i-t 图上 $i$ 等于 0 的点，也就是图线与横轴的交点（讲义图上的 B 点、D 点等）。这些时刻都是中性面，也正是电流改变方向的时刻。平行面对应 $i$ 最大的点，在 i-t 图里就是找波峰和波谷的位置（讲义图上的 A 点、C 点等）。判断时先看图线在题目所问的时刻是在横轴上（$i=0$，中性面，线圈平面与 $B$ 垂直，$\Phi$ 最大），还是在波峰波谷（$i$ 最大，平行面，线圈平面与 $B$ 平行，$\Phi=0$）。e-t、u-t 图同理。〔卡 jiaobian-02-c10〕

![i-t 图与横轴的交点（红点）对应中性面，此处 i = 0，电流改变方向](https://panda-1.tail2e9885.ts.net/wuli/img/jiaobian-02-it-neutral-points.png)

### 磁通量与 $e$ 不同时最大，变化率就是看 $e$（交变电流第 2 讲）

老师把磁通量 $\Phi$ 和 $e$、$u$、$i$ 当成一家人，它们不可能同时达到最大：一个达到最大时，另一个一定是 0。$e$、$u$、$i$ 最大时是平行面，$\Phi$ 为 0；$\Phi$ 最大时是中性面，$e$、$u$、$i$ 为 0。所以如果题目说某一位置或某一时刻磁通量和电动势都最大，一定是错的。老师说这个结论做题特别特别好用，要牢牢记住。〔卡 jiaobian-02-c11〕

![磁通量 Φ 与电动势 e 的曲线错开四分之一周期：一个最大时另一个为 0，不可能同时最大](https://panda-1.tail2e9885.ts.net/wuli/img/jiaobian-02-phi-vs-e.png)

选项里还要看清楚问的是磁通量，还是磁通量的变化率。问磁通量，就用上面的结论。问磁通量的变化率，本质上是在分析电动势 $e$：由 $e=N\dfrac{\Delta\Phi}{\Delta t}$，$N$ 是线圈匝数、是常数，所以 $e$ 最大时变化率最大，$e$ 为 0 时变化率为 0。老师说，如果对磁通量变化率不敏感，就把它翻译成 $e$ 再判断，并且提醒自己再写一遍：分析磁通量的变化率，其实就是分析 $e$。磁通量最大的时刻变化率反而是 0。〔卡 jiaobian-02-c12〕

### 第 2 讲的本讲总结

老师的总结里与本概念有关的一句：中性面 $\Phi$ 最大，$e$、$u$、$i$ 为 0；平行面相反，$\Phi$ 为 0，$e$、$u$、$i$ 最大；中性面上电流改变方向。〔卡 jiaobian-02-c20〕

### 零时刻先看函数值（交变电流第 3 讲）

第 3 讲讲怎么画 i-t、u-t 图线，用到了第 2 讲的结论。

做 u-t 图的选项题时，选项 D 问零时刻穿过线圈的磁通量是不是 0。老师说这是上节课讲过的内容：看图，零时刻对应的电压为 0，磁通量和 $e$、$u$、$i$ 是一个为 0 的时候另一个最大，所以零时刻磁通量应该最大，说它为零不对。做题时看到图线从原点出发，就是零时刻在中性面，磁通量最大。〔卡 jiaobian-03-c09〕〔整理注：这条卡自带的注释指向第 2 讲 c11。〕

画 i-t 图线时，老师的第一步是看零时刻函数值是零还是最大。例如以 abcd 为电流正方向、以图示位置作为零时刻：这个位置线框平面跟 $B$ 垂直，处在中性面上，磁通量最大，所以电流肯定是零，零时刻函数值为 0，先把原点这个点画出来。老师说，一看就看完了。〔卡 jiaobian-03-c13〕〔整理注：如果零时刻线框平面与 $B$ 平行（平行面），则 $i$ 最大，原点不在图线上而在峰值，依据见第 2 讲中性面、平行面。〕

### $\Phi$-t 图上的中性面与平行面（交变电流第 4 讲）

第 4 讲专讲 $\Phi$-t 图。前面是 e-t、i-t 图，现在横纵轴换成了磁通量。

**$BS$ 就是最大磁通量。** 最大电动势的表达式是 $NBS\omega$。其中 $BS$ 是线圈面与磁场垂直时的磁通量，$\Phi=BS$。线圈面与磁场垂直也就是中性面，这时的磁通量是最大磁通量，所以 $BS$ 等于最大磁通量 $\Phi_m$，也就是 $\Phi$-t 图函数的最大值（那张图上是 0.2 Wb）。给的是 $\Phi$-t 图时，把 $BS$ 直接代换成最大磁通量就能求最大电动势。〔卡 jiaobian-04-c04〕

**$\Phi$ 最大的时刻是中性面。** 给 $\Phi$-t 图，问某一时刻 $e$、$u$、$i$ 是最大还是 0，用前面讲过的知识：磁通量 $\Phi$ 与 $e$ 是一个最大时另一个为 0，一个为 0 时另一个最大。$\Phi$ 最大的时刻（那张图上的 0.1 秒和 0.3 秒），$e$、$u$、$i$ 等于 0，对应中性面，这时电流改变方向。所以问什么时候 $e$ 等于 0、什么时候是中性面、什么时候电流改变方向，其实就是找 $\Phi$ 最大的时刻。〔卡 jiaobian-04-c06〕

**$\Phi=0$ 的时刻是平行面。** 问什么时候 $e$、$u$、$i$ 最大，就看 $\Phi$ 等于 0 的时刻，在那张图上是 0、0.2、0.4 这三个时刻。〔卡 jiaobian-04-c07〕〔整理注：卡片的注释写明，$\Phi=0$ 即线圈平面与磁场平行，叫平行面，老师在例题 1 里点明它不是中性面。〕

![蓝点是 |Φ| 最大的时刻，是中性面，电流改变方向；红点是 Φ=0 的时刻，e、u、i 最大](https://panda-1.tail2e9885.ts.net/wuli/img/jiaobian-04-phi-points.png)

**看 $\Phi$ 的大小只看绝对值。** 正负号表示磁通量的方向，不影响大小。图上 0.1 s 时 $\Phi=0.2$，0.3 s 时 $\Phi=-0.2$，两个时刻 $\Phi$ 都是最大，对应的 $e$、$u$、$i$ 都为 0，不要因为 0.3 s 时 $\Phi$ 是负的，就当成最小值去判断。〔卡 jiaobian-04-c08〕〔整理注：卡片注释说明这里的最大指大小最大，所以 $\Phi$ 的最大值与最小值两个时刻同时算最大。〕

**变化率翻译成 $e$。** 题目问磁通量的变化率，就翻译成 $e$：变化率为零对应 $e=0$，变化率最大对应 $e$ 最大。再用 $\Phi$ 与 $e$ 此消彼长的关系判断：$\Phi$ 为 0 的时刻 $e$ 最大，即变化率最大，不是 0。〔卡 jiaobian-04-c09〕〔整理注：卡片注释补充，$\Phi$-t 图线上某点切线的斜率就是该时刻磁通量的变化率，图线过横轴处最陡，斜率最大，与 $\Phi=0$ 时 $e$ 最大是一回事。〕

**0 时刻 $\Phi=0$ 是平行面。** 中性面指 $e$ 等于 0、$\Phi$ 最大的位置。例题 1 的 A 选项说 0 时刻线圈在中性面，但图上 0 时刻 $\Phi$ 等于 0，表示 $e$ 最大，这个面是平行面。做题时看 0 时刻：$\Phi$ 为 0 是平行面，$e$ 最大；$\Phi$ 最大才是中性面，$e$ 为 0。〔卡 jiaobian-04-c10〕

**电流变向的时刻是 $\Phi$ 最大的时刻。** 电流改变方向是在 $i$ 等于 0 的时候，也就是 i-t 图线与 $t$ 轴相交的点。例题 2 的 B 选项说 0.2 s 和 0.4 s 电流改变方向，但这两个时刻 $\Phi$ 等于 0，是电流最大的时刻。电流改变方向要找 $\Phi$ 最大的时刻，也就是 0.1 s 和 0.3 s（对应中性面）。〔卡 jiaobian-04-c17〕〔整理注：卡片注释提醒，$\Phi$-t 图过横轴的点只是磁通量方向反过来了，不是电流变向的点。〕

### 在四值综合题里再用一遍（交变电流第 5 讲）

第 5 讲讲四值（瞬时值、最大值、有效值、平均值），题里的中性面判断直接沿用前几讲，见下面各道例题。线框从中性面开始转动时，初始时刻磁场与线框平面垂直，是中性面，$\Phi$ 最大对应 $e$ 为 0，所以表达式取 sin。〔卡 jiaobian-05-c18〕

## 做题套路

1. 先把磁通量的变化率翻译成 $e$，再判断。〔卡 jiaobian-02-c12、jiaobian-04-c09〕
2. 看图上某一时刻在哪里。i-t、e-t、u-t 图上，在横轴上（值为 0）是中性面，在波峰波谷是平行面。〔卡 jiaobian-02-c10〕
3. $\Phi$-t 图上正好相反：$\Phi$ 最大（看绝对值）的时刻是中性面，此时 $e$、$u$、$i$ 为 0，电流改变方向；$\Phi=0$ 的时刻是平行面，$e$、$u$、$i$ 最大。〔卡 jiaobian-04-c06、jiaobian-04-c07、jiaobian-04-c08〕
4. 选项里同时说磁通量和电动势都最大，直接判错。〔卡 jiaobian-02-c11〕
5. 问电流改变方向，找 $i=0$ 的点，也就是中性面，在 $\Phi$-t 图上要找 $\Phi$ 最大的点，不要找 $\Phi=0$ 的点。〔卡 jiaobian-02-c10、jiaobian-04-c17〕
6. 题目没给函数图线、只给线框位置时，同样用这两个位置的特点判断。〔卡 jiaobian-02-c14〕
7. 画图线或选表达式时，先看零时刻：线框面与 $B$ 垂直（中性面），函数值为 0，是 sin；线框面与 $B$ 平行，函数值最大，是 cos。〔卡 jiaobian-01-c15、jiaobian-03-c13〕
8. 要求最大电动势又给了 $\Phi$-t 图，用 $E_m=N\Phi_m\omega$，$BS$ 就是图上 $\Phi$ 的最大值。〔卡 jiaobian-04-c04、jiaobian-05-c29〕

## 口诀

- 老师的本讲总结：中性面 $\Phi$ 最大、$e$、$u$、$i$ 为 0，平行面相反，$\Phi$ 为 0、$e$、$u$、$i$ 最大；中性面上电流改变方向。〔卡 jiaobian-02-c20〕

## 易错

- 把 $\Phi$ 和 $e$ 当成同时最大。它们不能同时最大，一个最大另一个为 0。〔卡 jiaobian-02-c11〕
- 分不清问的是磁通量还是磁通量的变化率。变化率就是看 $e$，磁通量最大的时刻变化率反而是 0。〔卡 jiaobian-02-c12〕
- 把 i-t 图上 0.02 s 处的零点当成平行面。零点是中性面，平行面在波峰波谷。〔卡 jiaobian-02-c15〕
- 把图线从原点出发时的零时刻误认为磁通量为零。i-t、u-t 图从原点出发是中性面，磁通量最大。〔卡 jiaobian-03-c09〕
- 看到 $\Phi$-t 图 0 时刻 $\Phi=0$，就说线圈在中性面。$\Phi=0$ 是平行面，$e$ 最大。〔卡 jiaobian-04-c10〕
- 看 $\Phi$ 的大小时被负号带偏，把 $-0.2$ 当成最小。只看绝对值，$-0.2$ 与 $0.2$ 一样大。〔卡 jiaobian-04-c08〕
- 把 $\Phi$-t 图过横轴的点当成电流变向的点。电流变向要找 $\Phi$ 最大的点。〔卡 jiaobian-04-c17〕
- 在 e-t 图上把负的最大值当成中性面。大小最大的位置是平行面，中性面是曲线与横轴的交点。〔卡 jiaobian-05-c26〕

## 例题

- **交变电流第 2 讲 例题 2**：e-t 图，判断 $t_1$ 到 $t_3$ 时刻磁通量及其变化率。答案 D。要点：$e$ 为 0 是中性面，磁通量最大；$e$ 最大是平行面，磁通量为 0；变化率翻译成 $e$；$e$ 变换方向的时刻就是 $e$ 为 0 的时刻，磁通量最大。易错在 C 选项问的是变化率而不是磁通量。〔卡 jiaobian-02-c13〕
- **交变电流第 2 讲 例题 3**：给线框位置（与磁感线平行，绕 BC、AD 中点的轴转动），判断磁通量、变化率和电流。答案 B。要点：平行面 $\Phi=0$，$e$ 最大，变化率最大；转过 90° 到中性面，$\Phi$ 最大，$e$、$i$ 为 0，变化率为 0。〔卡 jiaobian-02-c14〕

- **交变电流第 2 讲 例题 4**：i-t 图，判断中性面、平行面、频率和方向改变次数。答案 A、C。要点：$i=0$ 的点是中性面，所以 0.01 s 和 0.02 s 都是中性面，不要把 0.02 s 的零点误当作平行面；$T=0.02$ s，$f=50$ Hz，一秒内方向改变 $2f=100$ 次。〔卡 jiaobian-02-c15〕
- **交变电流第 2 讲 例题 5**：i-t 图，判断线圈位置、磁通量变化快慢、电量和方向改变次数。答案 D。要点：$t_1$、$t_3$ 时 $i$ 最大，是平行面，不是垂直；$t_2$、$t_4$ 时 $i$ 为 0，变化率为 0，不是变化最快；电量看面积，$t_2$ 到 $t_4$ 不为 0；$T=0.02$ s 时一秒内方向改变 100 次。〔卡 jiaobian-02-c17〕
