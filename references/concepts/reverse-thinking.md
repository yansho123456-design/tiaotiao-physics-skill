# 逆向思维（等效思维）

一句话：遇到末速度为 0 的匀减速直线运动，就把它倒过来，等效成初速度为 0、加速度大小相同的匀加速直线运动。这样初速度不用再管，位移直接写 $x=\frac{1}{2}at^2$，末速度直接写 $v=at$。最后一段对应第一段，全程也可以整个对应。老师说这个办法在整个高中三年都很有用。〔卡 bixiu1-17-c14、bixiu1-17-c15、bixiu1-17-c16〕

〔整理注：这个办法在卡片里有两个名字。第 27 讲的卡片概念里记成「逆向思维」，其余各讲都叫等效思维。内容是同一件事。〕〔卡 bixiu1-27-c05〕

## 老师怎么讲

### 最后一段等效成第一段（必修 1 第 17 讲，刹车问题）

老师在刹车问题这一讲里第一次讲等效思维，称它是最后一个非常重要的做题等效思维，专门用来分析末速度为 0 的匀减速直线运动的最后一段，对后面分析竖直上抛特别有用。〔卡 bixiu1-17-c14〕

先说什么叫最后一段。看 $v$-$t$ 图里的红线，它是一段末速度为 0 的匀减速，初速度 $v_0$，加速度大小 $a$。如果让你求最后两秒（或最后三秒）的位移，这一段对应的就是红色阴影的三角形面积。常规做法是用位移时间公式，要先知道这一段的初速度，设为 $v_1$，列 $x=v_1t-\frac{1}{2}at^2$，还得根据题目的其他已知把 $v_1$ 求出来，至少要列两个式子，比较麻烦。〔卡 bixiu1-17-c14〕

等效思维的做法是：画一条与红线对称的橙线，两个角一样，斜率大小一样，陡峭程度一样。这条橙线表示初速度为 0 的匀加速直线运动，从那个点开始往前走，由于对称，它的加速度大小也是 $a$。分析这个匀加速的前两秒，位移就是橙色三角形的面积。橙色三角形跟红色三角形有一个角相同、底边长度相同，所以全等，面积相等，也就是橙色三角形的面积就是要求的最后两秒的位移。而初速度为 0 的匀加速，前两秒的位移直接列 $x=\frac{1}{2}at^2$ 就行，不需要再去分析 $v_1$。所以老师说，以后分析末速度为 0 的匀减速直线运动的最后一段，一律把它等效成初速度为 0 的匀加速直线运动的第一段。〔卡 bixiu1-17-c14〕

![等效思维的老师板书：红线是末速度为 0 的匀减速，红色阴影是它的最后 2 s（这一段初速度 $v_1$）；橙线与红线对称，是初速度为 0 的匀加速，加速度大小同为 $a$，橙色阴影是它的前 2 s；两个三角形全等，面积相等，所以最后 2 s 的位移可以用 $x=\frac{1}{2}at^2$ 求（图上只有字母，没有具体数值）](https://panda-1.tail2e9885.ts.net/wuli/img/bixiu1-17-equiv-vt.png)

老师接着补了几个细节。第一，要求最后一秒，就等效成第一秒。第二，等效成的那个匀加速，加速度大小跟原来一样，因为 $a$ 的大小一样，那两条线才能对称，面积才能相等。第三，不止最后一段可以等效，全程也可以等效：末速度为 0 的匀减速直线运动，全程直接等效成初速度为 0 的匀加速也行。老师在讲义最后一题（例题 6）用全程等效求刹车时间，又在打卡总结时再提了一次。老师还说，这个意识很容易掌握，有了它做题会比别人快很多。〔卡 bixiu1-17-c14、bixiu1-17-c15、bixiu1-17-c19〕

### 用在 0v0 模型的第二段（必修 1 第 18 讲，0v0 模型）

到了 0v0 模型，条件变了：题目一个位移都没给，不能靠「找两段位移的关系」来做，只能把第二段位移真的算出来。第二段 $x_2$ 是末速度为 0 的匀减速的位移，老师让大家用上一节课的等效思维，把它等效成初速度为 0、加速度大小为 $a_2$、运动时间为 $t_2$ 的匀加速的位移，写成 $x_2=\frac12a_2t_2^2$。老师强调，这样等效之后方程好列，因为初速度为 0，不用再管初速度。题目的核心就变成把 $t_2$ 求出来，而 $t_2$ 要靠 $a$ 与 $t$ 的关系。老师还说，如果对等效思维有问题，去听上一节讲刹车问题的课，那节课详细讲了。〔卡 bixiu1-18-c09〕

![例题 2：飞机从静止匀加速（$a_1=4.0$ m/s²），接到命令后匀减速（$a_2=6.0$ m/s²）直到停下，总时间 $t_1+t_2=30$ s，求减速阶段的位移 $x_2$；原题没有配图，v-t 图只示意形状（峰的位置按加速度反比取）](https://panda-1.tail2e9885.ts.net/wuli/img/bixiu1-18-q2-plane.png)

同一讲里还有一处用法：求 0v0 模型的最大速度 $v_m$。$v_m$ 是第二段的初速度，对一个末速度为 0 的匀减速，计算初速度可以等效成初速度为 0 的匀加速算末速度，等效成初速度为 0、加速度为 $a_2$、时间为 $t_2$ 的匀加速的末速度，所以直接用 $v_m=a_2t_2$。老师把最大速度的三种算法合起来写成 $v_m=a_1t_1=a_2t_2=\frac{2x}{t}$，其中第二种是等效思维，第一种是第一段本来就是初速度为 0 的匀加速，第三种是全程位移和总时间给了，用平均速度的 2 倍。〔卡 bixiu1-18-c15〕

〔整理注：第 17 讲的等效，是为了少设一个初速度，求最后一段的位移。第 18 讲的等效，是为了在没有位移条件时直接算整段位移和末端速度。两讲都是同一个办法，只是用在不同的未知量上。〕

### 零点推论里不分加速减速（必修 1 第 22 讲，零点推论）

第 22 讲把等效思维接到了零点推论上。如果物体做的是匀减速，比如从左往右做匀减速，走到右端时末速度等于零，它的终点就是零点。分析时用前面讲过的等效思维：匀减速的最后一段等效成匀加速的第一段。按 $T$ 来划分，匀减速的最后一个 $T$ 等效成匀加速的第一个 $T$，位移是 $x$；倒数第二个 $T$ 等效成匀加速的第二个 $T$，位移是 $3x$；以此类推是 $5x$、$7x$。所以不管匀加速还是匀减速，都是从零点开始数，$1:3:5:7$，只不过匀加速是从起点往终点数，匀减速是从终点往起点数。老师说，这是他讲零点推论跟别的老师的第一个重要区别：不要区分匀加、匀减，不管哪种都去找零点，从零点开始数就行。〔卡 bixiu1-22-c08〕

![匀减速的等时划分：末速度为 0 的点是零点，从终点往起点数，每段位移之比同样是 $1:3:5:7$（图中从左到右依次是 7、5、3、1）](https://panda-1.tail2e9885.ts.net/wuli/img/bixiu1-22-eqtime-decel.png)

等距划分也是一样。匀减速就把线段图画出来，找到零点，终点是零点，从终点往起点去分，每段距离 $x$；零点到第一段末尾的时间是 $t$，到第二段末尾是 $\sqrt{2}t$，到第三段末尾是 $\sqrt{3}t$。不管匀加速还是匀减速，都是从零点开始数。〔卡 bixiu1-22-c12〕

子弹穿三块相同木块的例题里，这个办法落到了速度上：$v_1$ 是匀减速的初速度，用等效思维看成从零点往回走的匀加速的末速度，走了 $\sqrt{3}T$，所以 $v_1=a\sqrt{3}T$，同理 $v_2=a\sqrt{2}T$，$v_3=aT$。〔卡 bixiu1-22-c22〕

![例题 5 求速度之比：子弹穿出第 3 块时速度为 0，是零点；$v_1$、$v_2$、$v_3$ 分别是射入第 1、2、3 块时的速度，对应零点到这些位置的时间 $\sqrt{3}T$、$\sqrt{2}T$、$T$，所以 $v_1:v_2:v_3=\sqrt{3}:\sqrt{2}:1$](https://panda-1.tail2e9885.ts.net/wuli/img/bixiu1-22-q5-speed.png)

〔整理注：第 17 讲讲的是单个匀减速的最后一段对第一段，第 22 讲把这个对应扩成连续多段：倒数第 $n$ 段对应第 $n$ 段，整体就是以终点为零点往回数。〕

### 竖直上抛的上升段与对称性（必修 1 第 26、27 讲，竖直上抛）

第 17 讲里老师说过，这个办法对后面的竖直上抛特别有用，到第 26 讲就用上了。竖直上抛分两段，分段分析是最基础、用得最多的思路：下降阶段是自由落体，重点是上升阶段。上升阶段是末速度为零的匀减速直线运动，根据刹车问题那节课讲过的等效思维，把它等效成初速度为零的匀加速直线运动来分析。这样原来匀减速的初速度 $v_0$ 就当成匀加速的末速度，那个零不用再考虑。〔卡 bixiu1-26-c06〕

求上升阶段的时间用 $t_1=\frac{v_0}{g}$。求上升的高度 $h_1$：如果不知道时间，用速度位移公式，把 $v_0$ 看成匀加速的末速度，得 $v_0^2=2gh_1$；如果知道时间，用位移时间公式 $h_1=\frac12gt_1^2$，因为等效成了初速度为零的匀加速，公式很简洁，不用再考虑初速度。〔卡 bixiu1-26-c06〕

![讲义第 4 页原图：竖直上抛分段分析，上升阶段（蓝）从 $v_0$ 出发上升 $h_1$，下降阶段（红）是自由落体](https://panda-1.tail2e9885.ts.net/wuli/img/bixiu1-26-segment-analysis.png)

到第 27 讲，老师说，如果前面讲的等效思维完全理解，不用像前面那样一步步分析，一眼就能看出对称性。上去这段，也就是从 A 到 O，是一个末速度为 0、加速度为 $g$ 的匀减速直线运动的最后 $h$ 米；下来这段，也就是从 O 到 A，是一个初速度为 0、加速度为 $g$ 的匀加速直线运动的前 $h$ 米。一个运动的最后一段位移与反过来运动的第一段位移可以等效，最后一段时间与第一段时间也可以等效。所以上去这段和下来这段是等效的，上去这段的初速度与下来这段的末速度等效，等效的意思是大小一样，所以 $v_上$、$v_下$ 大小相同，时间同理也相同。〔卡 bixiu1-27-c05〕

![速度对称性：竖直上抛两次经过同一点 A，上升时速度 $v_{上}$ 向上，下降时速度 $v_{下}$ 向下；A 到最高点 O 的高度记为 $h$，上升 $v_{上}^2=2gh$，下降 $v_{下}^2=2gh$，所以两速度大小相同、方向相反；讲义原图只有两根箭头，右侧推导按老师板书重画](https://panda-1.tail2e9885.ts.net/wuli/img/bixiu1-27-sym-speed.png)

〔整理注：第 26 讲把等效思维用在算上升段的时间和高度，第 27 讲把同一个办法用来证明上升与下降的对称性。〕

## 做题套路

1. 先认出运动是不是末速度为 0 的匀减速。刹车问题要先验刹车时间 $t=\frac{v_0}{a}$，只要有这一步就不会掉坑。〔卡 bixiu1-17-c19〕
2. 题目问末速度为 0 的匀减速的最后一段（最后 1 s、最后 2 s、最后 3 s），就把它等效成初速度为 0 的匀加速的第一段，加速度大小不变，直接写 $x=\frac{1}{2}at^2$。〔卡 bixiu1-17-c14、bixiu1-17-c15、bixiu1-17-c16〕
3. 题目问整个匀减速的时间、位移或初速度，把全程等效成初速度为 0 的匀加速。例如已知刹车位移和加速度，直接由 $x=\frac{1}{2}at^2$ 求时间，再用 $v=at$ 求刹车前的速度。〔卡 bixiu1-17-c15、bixiu1-17-c18〕
4. 0v0 模型里一个位移都没给时，把第二段（末速度为 0 的匀减速）等效成初速度为 0 的匀加速，写 $x_2=\frac12a_2t_2^2$，再用 $a$ 与 $t$ 的关系求 $t_2$。〔卡 bixiu1-18-c09、bixiu1-18-c10〕
5. 0v0 模型里求最大速度，第二段已知 $a_2$、$t_2$ 时用 $v_m=a_2t_2$。〔卡 bixiu1-18-c15〕
6. 已知第二段的加速度和时间，先用等效求这一段的位移，再用总位移减出另一段，然后用 $x$ 与 $t$ 的关系求另一段的时间。弹射座椅一题就是这样做的：$x_2=\frac12a_2t_2^2=180$ m，$x_1=225-180=45$ m，$\frac{t_1}{t_2}=\frac{x_1}{x_2}$，得 $t_1=1.5$ s。〔卡 bixiu1-18-c12〕
7. 多段连续匀减速，找到终点这个零点，从终点往起点数：等时划分位移比 $1:3:5:7$，等距划分时间是 $t$、$\sqrt{2}t$、$\sqrt{3}t$。〔卡 bixiu1-22-c08、bixiu1-22-c12〕
8. 竖直上抛先分段：上升段等效成初速度为 0 的匀加速，求时间用 $t_1=\frac{v_0}{g}$，求高度已知时间用 $h_1=\frac12gt_1^2$，不知道时间用 $v_0^2=2gh_1$；下降段是自由落体。〔卡 bixiu1-26-c06〕
9. 竖直上抛两次经过同一点，直接用等效看出上去与下来速度大小相同、时间相同。〔卡 bixiu1-27-c05〕

## 口诀

- 第 17 讲打卡页的小结：特别注意，题目给的时间一般没法用，一定要先验证刹车时间 $t=\frac{v_0}{a}$。匀减速直线运动写法：$v_t=v_0-at$，$t=\frac{v_0-v_t}{a}$；$x=v_0t-\frac{1}{2}at^2$；$v_0^2-v_t^2=2ax$。等效思维：将末速度为 0 的匀减速直线运动的最后一段，等效成初速度为 0 的匀加速的第一段。老师说这种题最重要的一点，就是起手先验一下刹车时间；匀减速的公式一律写成减号，做题会更简单；最后一道题可以看出，不止最后一段可以等效，全程也可以等效。〔卡 bixiu1-17-c19〕
- 第 26 讲小结：竖直上抛分段分析，上升段等效成初速度为零的匀加速，求时间用 $t_1=\frac{v_0}{g}$；求高度，已知时间用 $h_1=\frac12gt_1^2$，不知道时间用 $v_0^2=2gh_1$，这时题目给的 $v_0$ 是等效匀加速的末速度；下降段是自由落体。〔卡 bixiu1-26-c24〕

## 易错

- 等效成的匀加速，加速度大小必须和原来的匀减速一样，因为 $a$ 的大小一样，两条线才能对称，面积才能相等。〔卡 bixiu1-17-c15〕
- 刹车问题里题目给的时间一般没法直接用，要先验刹车时间。等效思维是在确定车已经停下之后才用。〔卡 bixiu1-17-c19〕
- 老师讲这个等效时，条件始终是末速度为 0 的匀减速，用在最后一段或全程。〔卡 bixiu1-17-c14、bixiu1-17-c15〕
- 常规写法不是不能用，只是过程复杂得多。老师特意在例题 5 里把常规方法也写了一遍做对比，没有对比就没有伤害。〔卡 bixiu1-17-c16〕
- 例题 6 里求刹车前的速度，等效成匀加速后算出的是末速度 $v=at$，这个速度就是刹车前行驶的速度，单位还要换算成 km/h 再和限速比较。〔卡 bixiu1-17-c18〕
- 弹射座椅一题中，第二段是喷气结束后仅受重力继续上升，加速度向下，与速度反向，所以是匀减速，$a_2=10\ \mathrm{m/s^2}$。〔卡 bixiu1-18-c12〕
- 子弹穿木块要先把要求的量标准确：$v_1$、$v_2$、$v_3$ 是射入每块时的速度，不是穿出时的速度。〔卡 bixiu1-22-c22〕

## 例题

- **必修 1 第 17 讲 例题 5**：卡车以 10 m/s 刹车，加速度 4 m/s$^2$，求刹车过程最后 2 s 通过的距离。答案 A（8 m）。要点：最后 2 s 是末速度为 0 的匀减速的最后一段，等效成初速度为 0、加速度 4 m/s$^2$ 的匀加速的前 2 s，$x=\frac{1}{2}\times4\times2^2=8$ m。对比常规方法：总时间 2.5 s，最后 2 s 的初速度是跑了 0.5 s 后的速度 8 m/s，再用 $x=v_0t-\frac{1}{2}at^2=16-8=8$ m，结果一样但复杂得多。〔卡 bixiu1-17-c16〕
- **必修 1 第 17 讲 例题 6**（浙江 9+1 联盟 高一上）：刹车痕迹 16.0 m，刹车加速度大小 8.0 m/s$^2$，限速 60 km/h，判断四个选项。答案 A。要点：痕迹就是总位移，全程等效成初速度为 0 的匀加速，$16=\frac12\times8t^2$，$t=2$ s，A 对；刹车前速度 $v=at=16$ m/s，即 57.6 km/h，没超速，B 不对；平均速度不是 30 km/h，C 不对；第一秒位移 $16\times1-\frac12\times8\times1^2=12$ m，D 不对。〔卡 bixiu1-17-c18〕
- **必修 1 第 18 讲 例题 2**：飞机从静止匀加速（4.0 m/s$^2$），中途紧急制动匀减速（6.0 m/s$^2$），从启动到停下共 30 s，求减速运动的距离。答案 B（432 m）。要点：一个位移都没给，第二段等效成初速度为 0 的匀加速，$x_2=\frac12a_2t_2^2$；先由 $\frac{t_1}{t_2}=\frac{a_2}{a_1}=\frac32$ 与 $t_1+t_2=30$ s 得 $t_2=12$ s，$x_2=\frac12\times6\times12^2=432$ m。〔卡 bixiu1-18-c10〕
- **必修 1 第 18 讲 例题 3**：弹射座椅先在喷气发动机驱动下匀加速，喷气完成后仅受重力继续上升 6 s 至最高点，上升总距离 225 m，$g=10\ \mathrm{m/s^2}$，求喷气驱动的时间。答案 B（1.5 s）。要点：先用等效求 $x_2=\frac12\times10\times6^2=180$ m，$x_1=45$ m，再由 $\frac{t_1}{t_2}=\frac{x_1}{x_2}$ 得 $t_1=1.5$ s。〔卡 bixiu1-18-c12〕
- **必修 1 第 22 讲 例题 5**：子弹穿三块相同木块，穿透第三块时速度恰好为零，求射入每块的速度之比和穿过每块的时间之比。答案 B、D。要点：穿透第三块的位置是零点，等距划分；$v_1:v_2:v_3=\sqrt{3}:\sqrt{2}:1$，$t_1:t_2:t_3=(\sqrt{3}-\sqrt{2}):(\sqrt{2}-1):1$。老师说这是巨经典的题，基本上每年都会考，提醒速度之比其实就是时间之比。〔卡 bixiu1-22-c22〕
