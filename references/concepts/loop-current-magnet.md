# 环形电流与条形磁铁（等效磁铁）

一句话：题目给一个条形磁铁，再给一个通电的环形线圈，问线圈怎么动。老师的办法是俯视，把线圈画成一边叉、一边点，用安培定则找最中间那根磁感线，把线圈等效成一块条形磁铁，再对两块磁铁用同斥异吸判断转动方向和靠近还是远离。整个办法里唯一的难点是把圆环在俯视里画对。〔卡 bixiu3-73-c01、bixiu3-73-c07〕

## 老师怎么讲

### 环形电流是什么，为什么它可以当磁铁（必修 3 第 67 讲）

环形电流先是在安培定则一讲里出现的，老师讲安培的分子电流假说时说：万物由分子构成，每个分子都有一个环形电流。有磁性的东西，内部的环形电流排列整齐，像讲义乙图那样磁感线都向右，叠加起来右边是 N 极、左边是 S 极，有磁性。木头这类没有磁性的东西，内部环形电流杂乱，磁感线相互抵消（甲图）。老师接着说，这个假说的核心其实就是环形电流，所以考试出题的话，就会考环形电流。讲义第 24 页左图是一个环形电流，磁感线穿环从 S 指向 N。〔卡 bixiu3-67-c25〕

![讲义第 24 页原图：甲图分子环形电流杂乱无章、磁感线相互抵消，没有磁性；乙图分子环形电流排列整齐、磁感线都向右叠加，右端是 N 极、左端是 S 极，有磁性](https://panda-1.tail2e9885.ts.net/wuli/img/bixiu3-67-molecular-ab.png)

这一讲还有一道用环形电流解释地磁场的例题。老师说它本质就是分子电流假说，把地球看成一个巨大的分子，解法完全是知直求环：先定地磁场（直线）的方向，再用右手确定环形电流方向。地磁场在地球内部向下，这是老师上节课讲过的内容，本节课没有重新推。右手握一下，能产生向下穿环的环形电流，在画面前侧是从右往左流，左是西、右是东，所以电流由东向西。〔卡 bixiu3-67-c26〕

这一讲的小磁针例题 4 里，选项 B 也是环形电流。老师的判断是：电流在环的上面扎进去、下面出来，右手四指跟着上面进下面出的方向，大拇指指向左边；小磁针 N 极跟磁感线一致，所以 N 极应向左，选项 B 不对。老师总结时说，遇到环形或螺线管，一定要看清上下哪个是扎进去、哪个是扎出来，点叉标上之后就确定了这个环的方向，四指跟它保持一致看大拇指。〔卡 bixiu3-67-c22〕

〔整理注：第 67 讲讲的是已知环形电流，用安培定则求磁场方向（或反过来求电流方向），目的是判断磁场。第 73 讲才把环形电流整体当成一块磁铁，去判断它在另一块磁铁旁边怎么动。两讲用的都是点叉加四指握的同一套手法，见 安培定则（右手螺旋定则）（concepts/amperes-rule.md）。〕

### 环形电流加条形磁铁，问线圈怎么动（必修 3 第 73 讲，题型技巧课）

**题型特征。** 老师说，这类题特别典型：题目一定给一个条形磁铁，再给一个环形电流，把它们放在一起，问线圈怎么动。比如讲义第 3 页那道题，会问线圈是平移还是转动，转动的话往哪个方向转。题目里常见的说法是线圈悬挂在条形磁铁附近，线圈与磁铁在同一竖直平面内，通入图示方向的电流。老师把特征概括成一句话：环形电流加磁铁。他强调这类题考法非常固定，是一个小破题，一见到就用本讲的方法，不要直接去分析磁铁和电流之间的力。〔卡 bixiu3-73-c01〕

![讲义第 3、5 页原图（例题 1）：固定的条形磁铁左 N 右 S，S 极附近悬挂一个金属线圈，线圈与磁铁在同一竖直平面内，线圈电流左边向下、右边向上；题干和四个选项在图上方](https://panda-1.tail2e9885.ts.net/wuli/img/bixiu3-73-q1-coil-s-pole.png)

**第一步，俯视，把线圈画成一边叉、一边点。** 老师说，最简单的方法是用俯视的视角把环形电流等效成一块磁铁，所以先把环在俯视里画出来。画法是想象有一个平面，环穿过这个平面，就像之前讲安培定则时用跳跳的项圈做的举例：环只是一个圈，穿过平面，从俯视看你只能看到一条线。看环的哪边扎进去、哪边钻出来，扎进去的一边画叉，钻出来的一边画点。以讲义第 4 页的悬挂线圈为例，俯视时线圈左边扎进去画叉，右边钻出来画点，所以环形电流表示成左叉右点。〔卡 bixiu3-73-c02〕

〔整理注：卡片的整理注说明，图中线圈电流左边向下、右边向上，向下穿过想象的水平面是扎进去，向上穿过是钻出来，所以是左叉右点。〕

![例题 1、2 的线圈（左边电流向下、右边向上）怎样画成俯视图：想象一个水平面（红色虚线）把线圈切开，左边电流向下扎进去画叉，右边电流向上钻出来画点；老师在讲义外现场板书讲了这一步](https://panda-1.tail2e9885.ts.net/wuli/img/bixiu3-73-ring-topview-symbols.png)

**第二步，用安培定则画磁感线，看最中间那根。** 画成左叉右点之后，用安培定则抓一下，磁场是一圈一圈的，叉的周围一圈，点的周围一圈。看最中间那根磁感线：它的箭头如果朝下，就等效成条形磁铁，下面是 N 极，上面是 S 极。老师强调等效时就用这根中心磁感线，一边俯视，一边去找中心的那根磁感线，用它来等效就行。〔卡 bixiu3-73-c03〕

〔整理注：卡片的整理注推出，左边叉的磁感线绕向是顺时针，右边点的磁感线绕向是逆时针，两边在中间都朝下。电流方向反过来时中间磁感线朝上，上端是 N 极。这一点是顺着老师的规则推出来的，老师没有单独讲这个情形。〕

![按安培定则画出俯视图（左叉右点）的磁感线：叉周围顺时针、点周围逆时针，两边的磁感线在中间都朝下，最中间那根磁感线（红色箭头）朝下；形状按老师板书的一圈一圈重画](https://panda-1.tail2e9885.ts.net/wuli/img/bixiu3-73-ring-topview-field.png)

**为什么可以这样等效。** 老师说，环形电流产生的磁场跟条形磁铁的磁场一模一样。条形磁铁的磁感线也是一圈一圈的，外面从 N 回到 S，内部再从 S 回到 N，所以可以根据环形电流中间那条磁感线，把它等价成一个条形磁铁。因为等效之后磁场分布一样，所以可以这么等效。等效之后，问题就变成给你两个条形磁铁，让你分析它们怎么动，直接看 N 极和 S 极的位置去分析，比直接分析一个磁铁和一个电流简单得多。〔卡 bixiu3-73-c04〕

![等效的条形磁铁：外部磁感线从下端 N 出来、绕回上端 S，内部从 S 到 N，中间那根磁感线箭头朝下，所以下端是 N 极、上端是 S 极；这与上一张环形电流的磁感线分布一样](https://panda-1.tail2e9885.ts.net/wuli/img/bixiu3-73-ring-equiv-magnet.png)

**第三步，两块磁铁用同斥异吸，转动和靠近一起判断。** 老师说，等效成条形磁铁之后，就根据同斥异吸，也就是同名磁极相斥、异名磁极相吸，看 N 极和 S 极的位置去分析。他特别强调，以后只要见到一个环形电流加一个条形磁铁让你分析，一律把环形电流等效成条形磁铁，办法是在俯视图里找它中心的那根磁感线。题目里转动和靠近两件事要分别判断：磁极被异名磁极吸引的那一端会向对方转过去，同时两块磁铁会靠近，最后可能吸在一起。〔卡 bixiu3-73-c05〕

〔整理注：卡片的整理注给了判断顺序：先看被吸引的那一端要往哪边转，再从上往下看它是顺时针还是逆时针；判断靠近或远离时，看相互吸引的两个异名磁极是否在靠近。〕

![例题 1 的俯视分析图：固定磁铁左 N 右 S，线圈等效成上 S 下 N 的磁铁；它的 N 极被固定磁铁的 S 极吸引，从上往下看顺时针转动并靠近磁铁；位置按老师板书，固定磁铁在左，线圈在右](https://panda-1.tail2e9885.ts.net/wuli/img/bixiu3-73-q1-analysis.png)

**唯一的难点。** 老师说，这个题如果有难点，唯一的难点就是怎么把圆环在俯视视角里画出来，要看清电流从哪边进、哪边出。不熟练就想象有一个平面，看电流穿过平面的方向。电流方向反过来的话，老师举的例子是左边钻出来画点、右边扎进去画 X，所以右边是 X、左边是点。老师说多练练就没问题。〔卡 bixiu3-73-c06〕

〔整理注：卡片的整理注指出，电流方向一旦画反，叉和点就换了位置，中间磁感线方向跟着反过来，等效磁铁的 N、S 也反过来，转动和靠近的结论就全错。〕

![老师打卡时刻举的反例：电流方向相反时（左边向上、右边向下），左边钻出来是点，右边扎进去是叉；〔整理注：老师口述这个方向，板书只随手画了圆环和叉点，这里的箭头方向按老师话重画〕](https://panda-1.tail2e9885.ts.net/wuli/img/bixiu3-73-ring-reverse-symbols.png)

**本讲小结。** 老师在结尾把整套办法收成三条：题型特征是环形电流加磁铁；等效磁铁是俯视，把环形电流等效成磁铁，用同斥异吸分析；具体思路是俯视画出圆环，看电流从哪边进、哪边出，进的画叉，出的画点，用安培定则找最中间那根磁感线，箭头朝下则下端为 N 极，再把两块磁铁用同斥异吸分析，判断转动方向和靠近还是远离。老师说这一课讲了一个小破题，大家通过前面讲的题好好练习怎么以俯视的视角把圆环画出来。〔卡 bixiu3-73-c07〕

〔整理注：第 67 讲把环形电流当作一个要用安培定则去求磁场方向的对象，第 73 讲把它当成一块磁铁。两讲之间没有说法对不上的地方，只是用法不同：前者问磁场方向，后者问线圈的运动。〕

### 环形电流的磁场分布，以及带电圆环旋转当作环形电流（电磁感应第 6 讲，双圈问题题型技巧课）

**先复习环形电流的磁场。** 老师说，环形电流有磁效应，环内环外都有磁场，但磁感线方向不同。例如环内每一条磁感线都是从下往上穿过环，因为磁感线是闭合曲线，穿过环之后在环外要从上往下转回来，所以圈内圈外 B 的方向相反。判断方向用「叉顺点逆」：电流是顺时针，环中间产生叉形磁场，环外面是点形磁场；电流是逆时针，环内部是点形磁场，环外面是叉形磁场。老师还说，每条磁感线都是闭合的，内部的磁感线都要从外部绕回来，所以环内与环外的磁感线条数一样多。有人会问正中间那条是直的，老师的回答是把它理解为在无限远的地方绕回来，总之内外磁感线总条数一样多。老师说这个口诀在必修三系统课讲过，上一节课也专门复习了。〔卡 dianci-06-c02〕

![讲义第 4 页原图：环形电流的磁感线，圈内向上穿过，圈外从上往下转回来，圈内圈外方向相反](https://panda-1.tail2e9885.ts.net/wuli/img/dianci-06-ring-field-lines.png)

![老师板书：顺时针的环形电流，圈内产生叉形磁场，圈外产生点形磁场（叉表示垂直纸面向里，点表示垂直纸面向外）](https://panda-1.tail2e9885.ts.net/wuli/img/dianci-06-ring-field-cw.png)

**再讲带电圆环旋转是什么意思。** 老师说，题目里说圆环旋转，其实就是环上有电流的意思。环上均匀分布着正电荷，圆环一转，正电荷也跟着转起来，电流就是电荷的定向移动，所以产生了电流。圆环顺时针旋转，相当于环上通了顺时针方向的电流；逆时针旋转就是逆时针的电流。加速旋转，翻译过来就是电流越来越大；减速旋转就是电流越来越小。老师说大家要先知道题目说的旋转到底是什么含义。〔卡 dianci-06-c14〕

![老师讲的等效：圆环均匀带正电，正电荷顺时针转相当于环里通了顺时针电流，转得越快相当于电流越大；图为按讲解重画](https://panda-1.tail2e9885.ts.net/wuli/img/dianci-06-q3-charge-ring-current.png)

〔整理注：卡片的整理注说明，老师例子里的电荷是正电荷，旋转方向与电流方向一致。〕

〔整理注：这一讲和前面两讲的关系是这样的。必修 3 第 67 讲的安培定则、第 73 讲的等效磁铁，用的都是环形电流的磁场；电磁感应第 6 讲沿用的是同一个磁场分布，只是换了一种说法，用叉顺点逆直接给出圈内圈外的方向，并多强调了圈内圈外 B 反向、内外磁感线条数一样多。条件上的不同在于，环上的电流可以来自带电圆环的旋转，要先把旋转翻译成电流的方向和大小变化。这两张卡里没有出现等效磁铁的做法，只讲了磁场方向和电流的来源。这些对比是我自己归纳的。〕

## 做题套路

1. 认题型：条形磁铁加环形电流，问线圈平移还是转动、往哪转、靠近还是远离，就用等效磁铁。注意题里的条形磁铁如果是固定的，不会动，只有线圈会动。〔卡 bixiu3-73-c01、bixiu3-73-c08〕
2. 俯视画圆环：想象一个平面把环切开，扎进去的一边画叉，钻出来的一边画点。这一步看准电流方向，是整道题唯一的难点。〔卡 bixiu3-73-c02、bixiu3-73-c06〕
3. 找中间那根磁感线：用安培定则抓一下，最中间那根磁感线箭头朝下，下端是 N 极、上端是 S 极。〔卡 bixiu3-73-c03、bixiu3-73-c08〕
4. 同斥异吸：把线圈等效成的磁铁和原来的条形磁铁放在一起，被异名磁极吸引的那一端转向对方，同时两块磁铁靠近。〔卡 bixiu3-73-c05〕
5. 报结论：从上往下看是顺时针还是逆时针，靠近还是远离，对着选项选。〔卡 bixiu3-73-c08、bixiu3-73-c09〕
6. 如果题目只是问环形电流周围某一点的小磁针或磁场方向，不需要等效，直接用安培定则：右手四指跟着电流在环上的进出方向握，大拇指所指就是磁场方向，小磁针 N 极跟磁感线一致。〔卡 bixiu3-67-c22〕〔整理注：这一条是把第 67 讲例题 4 的做法与第 73 讲的等效做法放在一起比较得出的，老师没有在一处同时讲这两种用法。〕
7. 题目里说带电圆环旋转时，先把旋转翻译成环形电流：顺时针旋转是顺时针电流，逆时针旋转是逆时针电流，加速旋转是电流增大，减速旋转是电流减小（老师例子里电荷为正）。再用叉顺点逆判断圈内圈外的磁场方向。〔卡 dianci-06-c14、dianci-06-c02〕

## 口诀

- 环形电流加磁铁，俯视等效成磁铁，同斥异吸。〔卡 bixiu3-73-c07〕

## 易错

- 把圆环在俯视里画错：电流从哪边进、哪边出看反，叉和点就换位置，等效磁铁的 N、S 反过来，结论全错。〔卡 bixiu3-73-c06〕
- 一看到环形电流加磁铁，就去直接分析磁铁和电流之间的力：老师说不要这样做，要等效成两块磁铁来看。〔卡 bixiu3-73-c01、bixiu3-73-c04〕
- 只判断转动、忘了判断靠近或远离，或者反过来：转动和靠近是两件事，要分别判断。〔卡 bixiu3-73-c05〕
- 题目里的条形磁铁是固定的，会动的是线圈。〔卡 bixiu3-73-c08〕

## 例题

- **必修 3 第 73 讲 例题 1**：固定条形磁铁（左 N 右 S）的 S 极附近悬挂一个金属线圈，线圈与磁铁在同一竖直平面内，通入图示电流，问看到什么。答案 C，从上往下看线圈顺时针转动，同时靠近磁铁。要点：俯视是左叉右点，中间磁感线朝下，线圈等效成下 N 上 S；固定磁铁右边是 S 极，吸引等效磁铁的 N 极转过去，同时靠近。〔卡 bixiu3-73-c08〕

- **必修 3 第 73 讲 例题 2**：轻质导线圈用细线挂在磁铁 N 极附近，磁铁轴线穿过线圈中心且在线圈平面内，通图示电流，从上往下看线圈将怎样。答案 A，顺时针转动，同时靠近磁铁。要点：老师说与例题 1 模式很像，不读题直接分析；左叉右点，中间磁感线朝下，线圈等效成下 N 上 S；线圈等效磁铁的 S 极（上端）被右边磁铁的 N 极吸引，一边转过去一边靠近。〔卡 bixiu3-73-c09〕
- **必修 3 第 67 讲 例题 6**（百强高中湖北武汉六校联考 2018-2019 高二上）：安培假设地球磁场是绕地球的环形电流引起的，问该电流的方向。答案 A，由东向西垂直磁子午线。要点：把地球看成一个巨大的分子，地磁场在地球内部向下，右手握一下，环上电流在画面前侧从右往左流，即从东往西。〔卡 bixiu3-67-c26〕

- **必修 3 第 67 讲 例题 4**（环形电流只是其中一个选项）：判断小磁针静止时指向，答案 C。要点：选项 B 的环形电流，环上电流上面进下面出，四指跟着握，大拇指指向左，小磁针 N 极应向左，所以 B 错。〔卡 bixiu3-67-c22〕
