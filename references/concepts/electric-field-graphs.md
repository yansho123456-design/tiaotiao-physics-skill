# 电场图像（φ-x 图与 E-x 图）

一句话：电场图像题只给 x 轴这一条直线上的信息，要你分析 x 轴上各点的物理量。φ-x 图和 E-x 图都是先把 x 轴上的电场线画出来，再用第二个核心：φ-x 图看斜率比场强大小，E-x 图看面积求电势差。〔卡 bixiu3-39-c01、bixiu3-39-c16、bixiu3-40-c01、bixiu3-40-c12〕

〔整理注：这个概念只在必修 3 的两讲里讲，第 39 讲讲 φ-x 图，第 40 讲讲 E-x 图，老师说两讲要连着听。〕

## 老师怎么讲

### φ-x 图像：图像含义与画电场线（必修 3 第 39 讲）

老师说，电场图像问题里最常考的有两种，一种是 φ-x 图，另一种是 E-x 图，其中 φ-x 图考得更多一些。这类题的特征是：告诉你电场中的一条线，通常叫 x 轴，以及 x 轴上电势随 x 的分布图，让你分析 x 轴上各个位置的各个物理量，例如比较 M 点和 N 点哪个点场强高，或者把一个负电荷从 M 点移到 N 点，问电场力做正功还是负功、电势能增加还是减小。一句话概括：已知 x 轴上电势随 x 的分布图，分析 x 轴上各种物理量。〔卡 bixiu3-39-c01〕

老师提醒，想真正会做，先要把图像的含义理解到位，很多同学对它有误解。这条曲线不是电场线，也不是等势面，它只能表示 x 轴这一条线。x 轴是一维空间，图像只告诉我们这个一维空间上每一点的电势高低，纵坐标就是 x 轴上某一点的电势，看电势高低只看纵坐标大小。老师随手举例，取 a、b、c、d、e 五点，纵坐标分别是 $-3$、$0$、$5$、$8$、$0$（这几个数是老师为了讲解随便写的），图像表示的就是这五个点在 x 轴上的电势。〔卡 bixiu3-39-c02〕〔整理注：纵坐标为 $0$ 的点电势为零，曲线最高处的点电势最大，这一句是卡片里的整理注。〕

老师还特别讲了一条易错点：这条线以外的所有信息都不知道，x 轴以外任何一个点的电势、场强都不知道。所以给了 φ-x 图，问的一定是 x 轴上各点的物理量，不会问 x 轴以外。讲义红字写的是：电场中 x 轴以外的地方信息全部未知。〔卡 bixiu3-39-c03〕

**核心 1：先把 x 轴上的电场线画出来。** 老师说，分析 φ-x 图有两个核心，第一个核心是画 x 轴上的电场线，电场线从高电势指向低电势，看电势高低就看纵坐标。例子：曲线左半部分 A 点在左边零点附近，B 点在最高处，从 A 到 B 电势一直升高，所以这段电场线从 B 指向 A；从 B 再往右，曲线往下落，电势降低，这段电场线从 B 往右指。之所以要以 B 分开，是因为 B 左边是升高，B 右边是降低。每一段增和减，都应该画出一段箭头，只画 x 轴上的，x 轴以外不画。老师说，只要是 φ-x 图，第一步都先把 x 轴上的电场线画出来，养成习惯。〔卡 bixiu3-39-c04〕〔整理注：电场线方向就是场强方向，后面例题里判断场强的方向直接看这一步画出的箭头，不看斜率的正负，这一句是卡片里的整理注。〕

复杂的图就按单调区间分段：第一步先分段，弄清哪一段在增、哪一段在减；第二步每一段按从高指向低画箭头。讲义第 5 页右边的图，曲线左边一直在降低，右边先增加再降低，一共三个单调区间。第一段起点高、末端低，箭头向右；第二段一直在增，起点低、末端高，箭头向左；第三段又在降低，箭头向右。所以 x 轴电场线是先向右、再向左、再向右。有几个单调区间就分几段。〔卡 bixiu3-39-c05〕

### φ-x 图像：斜率表示场强，以及电势能和电性的判断（必修 3 第 39 讲）

**核心 2：某点斜率的大小表示该点场强的大小。** 老师说，φ-x 图题总是问 x 轴上两个点哪个点场强大，办法很简单，直接看斜率。老师把推导也讲了：在曲线上某点左边取 $x_1$，右边取 $x_2$，两点距离是 $\Delta x$，让 $\Delta x\to 0$，斜率 $k=\frac{\varphi_2-\varphi_1}{\Delta x}$。其中 $\varphi_2-\varphi_1$ 是这一段的电势差 $U$，$\Delta x$ 是距离，记作 $d$，所以 $k=\frac{U}{d}$。前面讲过 $\frac{U}{d}$ 在匀强电场里等于场强；如果是非匀强电场，用这一段的电势差除以这一段的距离，算出来是这一段的平均场强。当 $d$ 趋近于 $0$，根据微元法的思想，这一小段的平均场强就等于这一点的场强，所以斜率 $k$ 的大小就等于这个点的场强大小。老师类比了必修 1 的瞬时速度：位移除以时间是平均速度，时间趋近于 $0$ 时就是瞬时速度，道理一样。老师希望不要只记结论，要把为什么看斜率这个推导过程也听明白。〔卡 bixiu3-39-c06〕

![老师板书的推导：在曲线上取 $x_1$、$x_2$，$\Delta x=d$，斜率 $k=(\varphi_2-\varphi_1)/\Delta x=U/d$ 是这一段的平均场强，$\Delta x\to 0$ 时就是该点的场强（曲线形状为示意，数据未标）](https://panda-1.tail2e9885.ts.net/wuli/img/bixiu3-39-slope-def.png)

比较场强大小的做法：画出各点的切线，看切线的陡峭程度，切线越陡，斜率的大小越大，场强越大。老师举例，曲线上取 A、B、C 三点，A 的切线一般陡，B 在最高处切线基本水平，C 的切线比 A 更陡，所以 $E_C>E_A>E_B$。老师特别提醒，不要纠结斜率是正还是负，因为核心 1 已经把场强的方向画出来了，核心 2 只为了分析场强的大小，所以只看 $k$ 的大小。〔卡 bixiu3-39-c07〕〔整理注：曲线最高点或最低点切线水平，斜率为零，该点场强为零；直线的斜率处处相等，所以直线段上场强大小处处相等，老师在例题 2、例题 3 中用到。这一句是卡片里的整理注。〕

![老师板书的比较：曲线上 $A$、$B$、$C$ 三点的切线，$C$ 最陡、$A$ 次之、$B$ 基本水平，所以 $E_C>E_A>E_B$（曲线形状与各点位置是示意，只表示切线陡缓关系）](https://panda-1.tail2e9885.ts.net/wuli/img/bixiu3-39-slope-compare.png)

比较电势能时，老师说 φ-x 图最容易看的物理量就是电势，所以可以用 $E_p=q\varphi$：先从图上看两点电势谁高谁低，再乘上电荷量。电势相同的两点，同一个电荷的电势能相同。带负电的粒子，不等式两边同乘负数，不等号要变号，即电势高的点电势能反而低。老师在例题 6 里还给了另一种做法：负电荷受力与电场相反，电场力与位移同向就做正功，电场力做正功电势能减小；也可以直接用电势分析。老师说各种方法都可以。〔卡 bixiu3-39-c10〕

判断两个点电荷是同种还是异种，老师说默认无穷远处电势为零。两个正电荷时，除了无穷远，所有地方电势都是正的，老师用前面讲过的电势物理意义来比喻，正电荷是地面鼓起来的小山；两个负电荷时，地势凹下去，所有位置电势都是负的。所以 φ-x 图上电势有一段为负、有一段为正，就一定是一正一负的异种电荷。电势全正是正电荷，电势全负是负电荷，这在例题 4 的带电圆环里也用到。〔卡 bixiu3-39-c15〕〔整理注：这条结论的前提是取无穷远处电势为零，老师在这一讲里没有讲没有取无穷远的情况，这一句是卡片里的整理注。〕

### E-x 图像：题型特征与画电场线（必修 3 第 40 讲）

老师说，E-x 图的特征跟上一节的 φ-x 图很像，都只研究电场里一条线上的各个点，区别是上一节的图体现各个位置的电势，这一节换成各个位置的场强。老师把题型特征写作：已知 x 轴上场强随 x 的分布图，分析 x 轴上各种物理量。分析思路跟上一节一样，也是两个核心，老师强烈建议两节放在一起听，一口气把电场图像问题听完。〔卡 bixiu3-40-c01〕

**核心一：画出 x 轴上的电场线，只是这次基于场强来画。** 老师说这反倒更简单。用讲义第 4 页左图举例，这个图就是把上一节那个图的纵坐标电势换成场强，图像与 x 轴有两个交点。第一个交点左边每个点的纵坐标都是负的，场强指向负方向，向左；两个交点中间纵坐标都是正的，向右；第二个交点右边又都是负的，向左。所以 x 轴上的电场线是第一段向左、第二段向右、第三段向左。提炼成三条：第一，要分段，但不像上一节按单调区间分，而是直接按图像与 x 轴的交点分段，也就是按图像的正负分段；第二，这一段场强都是负的，就画指向 x 轴负方向（向左）的箭头；第三，这一段场强都是正的，就画指向 x 轴正方向（向右）的箭头。老师说这是这一讲最重要的一个点，每次做这类题，第一件事就是先把 x 轴上的电场线画出来。〔卡 bixiu3-40-c02〕

![讲义第 4 页左图：E-x 图像与 x 轴有两个交点，交点左边 E 为负，中间为正，右边为负](https://panda-1.tail2e9885.ts.net/wuli/img/bixiu3-40-core1-left.png)

E-x 图同样只表示 x 轴这个一维空间上的分布，一维空间只有两个方向，x 轴箭头向右，向右就是正方向。某段 E 为负，场强指向负方向，也就是向左；E 为正，指向正方向，也就是向右。老师在例题 3 里补充了一条：图像没给出 E 的地方就不要画电场线。〔卡 bixiu3-40-c03〕〔整理注：E 的正负是相对 x 轴正方向而言，不是相对电荷正负而言，读题时要看题目有没有写明以 x 轴正方向为场强正方向，例题 2、例题 3 的题干都写了这句。这一句是卡片里的整理注。〕

老师又用讲义第 4 页右图练习分段：把上一节同样的图的纵坐标电势换成场强，先找图像与 x 轴的交点，这个图有两个交点，三段依次场强为正、负、正，电场线向右、向左、向右。〔卡 bixiu3-40-c04〕〔整理注：右图只用曲线形状判断每一段的正负，不用来算数，这一句是卡片里的整理注。〕

### E-x 图像：面积表示电势差（必修 3 第 40 讲）

**核心二：图像与 x 轴围成的面积表示两点间的电势差。** 老师说，选两个点 $x_1$、$x_2$，它们与图像围成的面积就是对应的电势差 $U_{x_1x_2}$。〔卡 bixiu3-40-c05〕

证明用微元法：选两个离得很近的点 $x_1$、$x_2$，围成一块不规则的面积，因为很近，可以把底抹平成一个小矩形，也可以把这一小段看成匀强电场，场强可能不是处处相同，但差别不大。小矩形的面积是底（两点间距离 $d$）乘高（场强 $E$），$S=Ed$，而 $Ed$ 就是电势差 $U$。如果 $x_1$、$x_2$ 距离远了，一个矩形误差大，就分割成很多小矩形，每个小矩形的面积表示这一小段的电势差，从左往右把面积加起来，$S_{总}=U_{x_1x_2}$。老师把它类比到 v-t 图：取一个小矩形，近似认为这一小段时间内匀速运动，面积就是这段时间的位移，整段面积就表示位移。老师说用微元法的思想就能证明，这里不需要背。〔卡 bixiu3-40-c06〕

![老师在讲义第 5 页上的推导：x1、x2 靠得很近时，把小块面积抹平成小矩形，高是 E、宽是 d，面积 $S=Ed=U_{x_1x_2}$；曲线形状是示意](https://panda-1.tail2e9885.ts.net/wuli/img/bixiu3-40-area-small.png)

电势差的下标怎么写：哪个点电势高，要根据第一步画的电场线箭头来确定。例如 $x_1$、$x_2$ 在中间这一段，电场线向右，$x_1$ 电势高，写成 $U_{x_1x_2}$；如果在右边那一段，电场向左，沿电场线方向电势降低，越往右电势越高，$x_2$ 电势高，就写成 $U_{x_2x_1}$。这时候面积都写成正的就行，因为从高电势到低电势写，电势差一定是正的。老师说，要养成好习惯，尽量都写成从高电势到低电势的电势差。〔卡 bixiu3-40-c07〕

![电势差的下标怎么写：中段电场向右，左边电势高，写 $U_{x_1x_2}$；右段电场向左，右边电势高，写 $U_{x_2x_1}$。曲线形状是示意，沿用讲义左图的交点与正负](https://panda-1.tail2e9885.ts.net/wuli/img/bixiu3-40-area-direction.png)

### E-x 图像：场源电性、电荷量比与电势比较（必修 3 第 40 讲）

由 x 轴上的电场线方向可以推场源电性。老师说，电场线从场源指向外，说明这个场源是正电荷，因为正电荷的电场是发散的；电场线指向场源，说明是负电荷。例题 2 里左边一段电场线向左，离 a 近，是 a 发出的，a 带正电；b 点右边的电场线向左，指向 b，b 带负电，所以是等量异种电荷，再把连线上的电场线从正指向负补出来。例题 3 里电场线都是从场源往外发出，所以两个场源都是正电荷。用法是先按核心一画出电场线，再看场源两侧的箭头是背离场源还是指向场源。〔卡 bixiu3-40-c08〕

老师提醒一个易错点：E-x 图像与 x 轴的交点说明这个点场强为 0，但场强为 0，电势不一定为 0，这是两件事。例题 3 的 A 项就是这个坑。老师还推了一下：两个场源都是正电荷，除了无穷远处，整个空间电势都是正的，所以它们连线上的电势不为 0。〔卡 bixiu3-40-c09〕

要求两个电荷量的关系，就基于场强为 0 的点分析。例题 3 里 $2a$ 处合场强为 0，$Q_1$ 到它的距离是 $2a$，$Q_2$ 在 $3a$ 处，到它的距离是 $a$，所以 $\frac{kQ_1}{(2a)^2}=\frac{kQ_2}{a^2}$，得 $Q_1=4Q_2$，是 4 倍，不是 2 倍。〔卡 bixiu3-40-c10〕〔整理注：讲义 C 项写成 $Q_1$ 是 $Q_2$ 的 2 倍，是一个错误选项，这一句是卡片里的整理注。〕

比较不在同一电场线两侧的两点电势，老师说是这一节稍微难一些的一类。做法是利用面积，找这两个点到同一点的电势差，再把电势差转换成电势去分析。例题 3 的 D 项比较 $1.5a$ 和 $2.5a$ 处的电势：设 $1.5a$ 到 $2a$ 之间的面积为 $S_1$，$2a$ 到 $2.5a$ 之间的面积为 $S_2$。左边那段电场线向右，$1.5a$ 电势高于 $2a$，$S_1=\varphi_{1.5a}-\varphi_{2a}$；右边那段电场线向左，$2.5a$ 电势高于 $2a$，$S_2=\varphi_{2.5a}-\varphi_{2a}$。肉眼看 $S_2$ 大，因为下面这段曲线更陡峭，所以 $S_2>S_1$，两边约掉 $-\varphi_{2a}$ 得 $\varphi_{2.5a}>\varphi_{1.5a}$。老师说这个题好好总结一下，以后类似的题都会做了。〔卡 bixiu3-40-c11〕

![例题 3 的 D 项：在 1.5a 到 2a 之间曲线平缓，2a 到 2.5a 之间曲线陡峭，面积 $S_2>S_1$，即 $\varphi_{2.5a}-\varphi_{2a}>\varphi_{1.5a}-\varphi_{2a}$，所以 $\varphi_{2.5a}>\varphi_{1.5a}$；曲线形状是示意（按 $Q_1=4Q_2$ 的场强公式画出），纵轴刻度不对应原题](https://panda-1.tail2e9885.ts.net/wuli/img/bixiu3-40-q3-areas.png)

## 做题套路

1. 第一步，不管题目问什么，先把 x 轴上的电场线画出来，x 轴以外不画。φ-x 图按单调区间分段，每段从高电势画向低电势；E-x 图按与 x 轴的交点分段，E 为正画向右，E 为负画向左，图像没给 E 的地方不画。〔卡 bixiu3-39-c04、bixiu3-39-c05、bixiu3-39-c16、bixiu3-40-c02、bixiu3-40-c03、bixiu3-40-c12〕
2. φ-x 图第二步比较场强大小：画切线看陡缓，只看斜率大小。曲线上每点斜率不同，场强大小也不同，直线上斜率相同，场强大小相同，电场力是恒力。〔卡 bixiu3-39-c07、bixiu3-39-c09、bixiu3-39-c11〕
3. E-x 图第二步用面积表示电势差，下标按电场线方向从高电势写到低电势，面积写成正值。对称两点的电势比较，可以用对称的面积相等，拆开后约掉共同的电势。〔卡 bixiu3-40-c05、bixiu3-40-c07、bixiu3-40-c13〕
4. 电场力的方向由电场方向和电荷正负决定，电场力的大小由场强大小决定，做功的正负由力与位移的方向关系判断，电势能的增减随做功的正负而定。〔卡 bixiu3-39-c08〕
5. 比较电势能时用 $E_p=q\varphi$，负电荷不等号变号。〔卡 bixiu3-39-c09、bixiu3-39-c10〕
6. 判电性：粒子从静止出发，运动方向就是电场力方向，再与电场方向对比，相同带正电，相反带负电。〔卡 bixiu3-39-c11〕
7. 判场源电性：φ-x 图看电势全正、全负还是有正有负；E-x 图看电场线是背离场源还是指向场源。〔卡 bixiu3-39-c12、bixiu3-39-c15、bixiu3-40-c08〕
8. 求两个场源的电荷量之比，用场强为 0 的那一点，两个点电荷场强大小相等，列 $\frac{kQ_1}{r_1^2}=\frac{kQ_2}{r_2^2}$。〔卡 bixiu3-40-c10、bixiu3-40-c15〕
9. 比较不在同一电场线两侧的两点电势：各自找到与同一点的电势差，比较面积大小，再把电势差拆成电势去比。〔卡 bixiu3-40-c11、bixiu3-40-c15〕

## 口诀

老师自己给的是两讲的小结卡，两个核心的说法分别是：

- φ-x 图：核心 1，先把 x 轴上的电场线画出来，电场线从高电势指向低电势，按单调区间分段，每段都从高指向低，有几个单调区间就分几段。核心 2，判断场强大小找斜率，斜率的大小就表示这一点场强大小。〔卡 bixiu3-39-c16〕
- E-x 图：核心一，画 x 轴电场线，根据图像和 x 轴的交点分段，E 为负指向 x 轴负方向，E 为正指向 x 轴正方向。核心二，面积表示电势差。〔卡 bixiu3-40-c12〕

## 易错

- φ-x 图只表示 x 轴这一条线，不是电场线也不是等势面，x 轴以外的信息全部未知，不会问 x 轴以外的量。〔卡 bixiu3-39-c02、bixiu3-39-c03〕
- 比较场强大小只看斜率的大小，不看正负，方向看第一步画出的电场线。〔卡 bixiu3-39-c07、bixiu3-39-c08〕
- 例题 1 里问电场力最大的点，电场力本质上还是问场强，O 点切线水平，斜率最小，场强最小，电场力也最小。〔卡 bixiu3-39-c08〕
- 例题 3 里直线上斜率不变，场强不变，电场力是恒力，不是均匀增大。〔卡 bixiu3-39-c11〕
- 带负电的粒子比较电势能，不等号要变号。〔卡 bixiu3-39-c09、bixiu3-39-c10〕
- 例题 4 要选不正确的，读题时注意，电势能的变化要看电场力做功的正负。〔卡 bixiu3-39-c12〕
- 电场力的增减与电荷正负无关，直接看斜率绝对值的变化。〔卡 bixiu3-39-c14〕
- E-x 图的 E 的正负只表示沿 x 轴向右还是向左，不是电荷正负。〔卡 bixiu3-40-c03〕
- 场强为 0 的点电势不一定为 0，两个同种正电荷连线上电势不可能为 0。〔卡 bixiu3-40-c09〕
- 两个点电荷的电荷量之比要从场强叠加为零列式，$Q_1=4Q_2$，不是 2 倍。〔卡 bixiu3-40-c10〕
- 两点场强相等不等于电势相等，要看它们在电场线上的位置。〔整理注：这句来自例题 1 卡片里的整理注。〕〔卡 bixiu3-40-c13〕

## 例题

- **必修 3 第 39 讲 例题 1**：空间某静电场的电势在 x 轴上分布如图，判断 B、C 两点场强大小与方向、O 点电场力、负电荷从 B 移到 C 的做功。答案 AD。要点：先画电场线，O 点电势最高，从 O 指向两边；A 看斜率，B 点比 C 点陡，对；B 项 B 点电场向左，错；C 项 O 点斜率最小，电场力最小，错；D 项负电荷受力与电场相反，B 到 O 做正功，O 到 C 做负功，对。〔卡 bixiu3-39-c08〕
- **必修 3 第 39 讲 例题 2**：曲线加直线、关于纵轴对称的 φ-x 图，判断场强与电势能。答案 BD。要点：O 点电势最低，曲线上斜率各不同，直线上斜率相同；$-x_1$ 到 $x_1$ 斜率先小后大，场强先减小后增大；对称两点电势相同则电势能相同；负电荷比较电势能时不等号变号。〔卡 bixiu3-39-c09〕
- **必修 3 第 39 讲 例题 3**：粒子由静止从 M 向右运动，判电性、能否通过 N 点、场强与电场力。答案 AB。要点：M 在 O 左边，电场向左，粒子向右运动，电场力向右，所以带负电；$OA<OB$，OA 段斜率更大，$E_1>E_2$，$F_1>F_2$，从 M 到 O 正功多，O 到 N 负功少，总的做正功，动能增加，一定能到 N；AO 间场强大于 OB 间；M 到 O 是直线，斜率不变，电场力是恒力。老师说这道题稍微有点难，B 项还综合了动能定理。〔卡 bixiu3-39-c11〕
- **必修 3 第 39 讲 例题 4**：均匀带电圆环轴线上的 φ-x 图，选不正确的。答案 D。要点：整条线电势全为正，无穷远处电势为零，圆环带正电；O 点切线水平，场强为零，也可以用对称相消说明；I 点比 H 点陡，I 点场强大；正试探电荷从 H 到 I，电场力先做负功后做正功，电势能先增加后减小，所以 D 不正确。〔卡 bixiu3-39-c12〕
- **必修 3 第 39 讲 例题 5**：等量异种电荷连线上的电势，选 φ-x 图。答案 C。要点：等量异种电荷连线上电场线从正电荷指向负电荷，沿 x 轴电势一直降低，四个选项里只有 C 一路降低。〔卡 bixiu3-39-c13〕
- **必修 3 第 39 讲 例题 6**（2017 江苏高考）：两个点电荷的 φ-x 图，判电荷种类、场强、电势能、电场力。答案 AC。要点：电势有正有负，所以是一正一负的异种电荷；$x_1$ 处电势为零但斜率不为零，场强不为零；负电荷从 $x_1$ 到 $x_2$，电场力做正功，电势能减小；从 $x_1$ 到 $x_2$ 曲线越来越平缓，场强减小，电场力减小。〔卡 bixiu3-39-c14〕
- **必修 3 第 40 讲 例题 1**：关于 O 点对称的 E-x 折线图，判断各点电势。答案 C。要点：O 往两边电场线都向外，O 点电势最高；$x_1$、$x_3$ 在同一条电场线上，$x_1$ 电势高；$-x_2$ 与 $x_2$ 用两个三角形面积相等，$U_{O,-x_2}=U_{O,x_2}$，拆开约掉 $\varphi_O$，两点电势相等。老师说讲 C 项主要是想让大家再练习一下面积的含义。〔卡 bixiu3-40-c13〕

- **必修 3 第 40 讲 例题 2**：等量电荷的 E-x 图，判断 c、d 两点的场强与电势。答案 A。要点：先画能画的电场线，由场强方向推出 a 带正电、b 带负电，是等量异种电荷；连线上电场线从正指向负，所以 c 点电势高于 d 点；根据对称性，c、d 两点场强大小方向都相同。老师说这个题综合得蛮不错。〔卡 bixiu3-40-c14〕
- **必修 3 第 40 讲 例题 3**（福建师大附中期中）：两个点电荷连线上的 E-x 图，判断零电势、电性、电荷量比、电势高低。答案 D。要点：电场线都从场源往外，两个都是正电荷；$2a$ 处场强为零，但电势不一定为零，两个正电荷连线上电势不为零；场强叠加得 $Q_1=4Q_2$；$1.5a$ 与 $2.5a$ 比较，用面积 $S_2>S_1$，得 $\varphi_{2.5a}>\varphi_{1.5a}$。〔卡 bixiu3-40-c15〕〔整理注：老师口述的 $S_2$ 比 $S_1$ 大是看图作的判断，不是算出来的，没有给出 E 随 x 的函数式，这一句是卡片里的整理注。〕
