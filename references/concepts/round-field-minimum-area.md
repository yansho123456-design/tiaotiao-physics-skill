# 圆形磁场最小面积

一句话：题目只说有一个圆形匀强磁场，位置和大小都不知道，只给出粒子进磁场前和出磁场后的速度方向，要求满足条件的最小磁场面积。老师的办法是：最小磁场圆以轨迹圆弧的弦为直径，所以先由速度偏转角 $\alpha$ 得到弦切角 $\theta=\frac{\alpha}{2}$，再用弦长公式 $L=\frac{2mv\sin\theta}{qB}$ 求弦长，最后算 $S=\pi\left(\frac{L}{2}\right)^2$。〔卡 bixiu3-81-c01、bixiu3-81-c03、bixiu3-81-c09〕

〔整理注：这个概念目前只有必修 3 第 81 讲一讲专门讲，下面的内容全部来自这一讲，按老师在这一讲里的讲课顺序排列。〕

## 老师怎么讲

### 这类题长什么样（必修 3 第 81 讲）

老师说，之前做的题磁场都是确定的，会给你画出来。这类题只告诉你磁场是一个圆形的匀强磁场，但它在哪里、有多大都不知道。题目给出粒子进磁场前的速度方向和离开磁场后的速度方向，让你反过来求满足条件的最小磁场面积，所以叫圆形磁场最小面积问题。讲义上的典型题是：质量为 $m$、电荷量为 $q$ 的粒子，以速度 $v_0$ 从 $O$ 点沿 $y$ 轴正方向射入磁感应强度大小为 $B$ 的圆形匀强磁场，飞出后从 $b$ 处穿过 $x$ 轴，速度方向与 $x$ 轴正方向夹角为 $30^\circ$，不计重力，求圆形磁场的最小面积。讲义橙色小结是：已知进出速度方向，求圆形磁场最小面积。〔卡 bixiu3-81-c01〕

老师还说，这类题考得不多，没有那么重要。但如果不讲，这个方法你没听过，自己做时可能会麻烦、会卡住，所以这堂课重点讲分析思路。〔卡 bixiu3-81-c01〕

### 第一步想法：轨迹是唯一的，磁场只要恰好盖住圆弧（必修 3 第 81 讲）

老师说，根据半径公式 $r=\frac{mv}{qB}$，这类题里粒子的质量、速度、$q$、$B$ 都不变，所以轨迹圆的半径是固定的，可以先把完整轨迹画出来。例如粒子从 $A$ 点水平向右走，要从 $C$ 点垂直 $x$ 轴向下穿出，完整轨迹是先走一段直线，到某个点开始偏转，偏转一段圆弧后再走直线。因为圆弧半径固定，整个轨迹是唯一的。〔卡 bixiu3-81-c02〕

磁场只要把这段圆弧包住就行，直线部分不用管，因为本来就是走直线，磁场是用来让粒子偏转的。老师强调要恰好覆盖，多了不行也少了不行。磁场少了，粒子从那里飞出来，出来的速度方向就不是要求的方向。磁场多了，粒子到了该出去的位置还在磁场里，还要继续偏转，出来的方向也不对。讲义红字：直线轨迹不用管，磁场恰好覆盖住圆轨迹即可。〔卡 bixiu3-81-c02〕

![讲义第 4 页原图：粒子从 $A$ 点水平向右射入，要从 $C$ 点垂直 $x$ 轴向下穿出，完整轨迹是先走直线、再走一段圆弧（蓝色）、再走直线，圆弧半径固定，轨迹唯一；磁场只要恰好覆盖蓝色圆弧](https://panda-1.tail2e9885.ts.net/wuli/img/bixiu3-81-trajectory-ac.png)

### 为什么以弦长为直径的圆最小（必修 3 第 81 讲）

老师说，目标是恰好把蓝色圆弧包住。讲义画了三个圆，橙色虚线圆、绿色虚线圆、蓝色实线圆，都能恰好把这段圆弧包进去。要找面积最小的那个，做出这段圆轨迹的弦，以弦长为直径画一个圆形磁场，它一定面积最小。理由是：如果磁场圆的直径比弦长还小，就包不住这条弦，包不住弦，圆弧必定也包不住。〔卡 bixiu3-81-c03〕

于是问题转化为求弦长。弦长求出来，就知道了圆形磁场的直径，有了直径求面积，老师说小学生都会。讲义红字：以弦长为直径的磁场面积最小，核心：求弦长。〔卡 bixiu3-81-c03〕

![讲义第 5 页三个圆的示意重画：橙色虚线圆、绿色虚线圆、蓝色实线圆都能恰好把蓝色圆弧包住，其中以弦为直径的蓝色圆面积最小；圆的大小位置按讲义示意，不对应具体数据](https://panda-1.tail2e9885.ts.net/wuli/img/bixiu3-81-three-circles.png)

### 求弦长：用弦长公式，核心变成求弦切角（必修 3 第 81 讲）

老师说，一说弦长就该想到「弦长公式」，这是磁场中唯一配称为技巧的东西，非常重要、做题非常好用。没听过的同学要先回去看前面讲弦长公式的那一节，再来听这一讲。公式写成 $L=\frac{2mv\sin\theta}{qB}$，其中 $\theta$ 是弦切角。这类题里 $m$、$v$、$q$、$B$ 一定会告诉你，所以要先知道弦切角 $\theta$，才能求出弦长。老师总结：目标又变了，从求弦长转化为求弦切角。讲义红字：求出弦切角，利用弦长公式求弦长，核心：求弦切角。〔卡 bixiu3-81-c04〕

〔整理注：卡片记录转录里把公式听写成「L 等于 RMVsinθ 比上 QB」，板书是 $L=\frac{2mv\sin\theta}{qB}$，这里按板书写。弦长公式本身的推导和用法，见 弦长公式（concepts/chord-length-formula.md）。〕

### 弦切角画在哪里：画在轨迹圆上，别被磁场圆误导（必修 3 第 81 讲）

老师说，画弦切角千万不要被图里的磁场圆误导。弦切角要在轨迹圆上画，磁场圆跟弦切角没有半毛钱关系。粒子从某个点进磁场，你要做的是轨迹圆在这个点的切线。进磁场时速度方向就是进磁场前的速度方向，所以这条切线就是进速度所在的直线，它和弦的夹角就是弦切角，设为 $\theta$。也可以用离开磁场时来画，因为离开磁场之后速度方向不再变化，出速度所在的直线也是轨迹圆的切线。〔卡 bixiu3-81-c05〕

老师特别强调，看图时可能觉得进、出速度这两条线不是灰色磁场圆的切线，但弦切角看的是轨迹圆的切线，把轨迹圆弧补全，这两条线就是它的切线。同一条弦两端的两个弦切角是一样的，都是 $\theta$。〔卡 bixiu3-81-c05〕

![弦切角要画在轨迹圆上：弦（红线）与轨迹圆（灰色虚线）在进、出磁场处的切线（绿线）之间的角，同一条弦两端的弦切角相等，都是 $\theta$；图中圆弧所转角度是示意取的，不对应原题数据](https://panda-1.tail2e9885.ts.net/wuli/img/bixiu3-81-chord-tangent-angle.png)

### 速度偏转角怎么求：平移速度，箭头屁股相接（必修 3 第 81 讲）

老师说，这类题已知的是进出速度方向，已知的角度关系都和进出速度的角度有关，所以要先由进出速度方向把速度偏转角求出来。速度偏转角就是末速度相比初速度改变的那个角度。求法是：速度是矢量，可以平移，把初速度和末速度平移到箭头屁股和屁股重叠，平移哪个都行，然后看这两个箭头之间的夹角。〔卡 bixiu3-81-c06〕

例如初速度水平向右，末速度大致向右下，平移后两箭头夹角是锐角，速度偏转角就是锐角。如果末速度指向左下角，平移后夹角是钝角，速度偏转角就是钝角。讲义里的例子是 $v_0$ 水平向右、$v_t$ 指向右下角，把 $v_t$ 平移过来，这个夹角设为 $\alpha$，就是速度偏转角。〔卡 bixiu3-81-c06〕

![求速度偏转角的方法：把末速度平移到与初速度箭头屁股挨在一起，看两个箭头之间的夹角，可能是锐角（$v_t$ 偏向右下），也可能是钝角（$v_t$ 偏向左下）；两幅图的具体角度是示意取的](https://panda-1.tail2e9885.ts.net/wuli/img/bixiu3-81-deflection-acute-obtuse.png)

### 速度偏转角和弦切角的关系：$\theta=\frac{\alpha}{2}$（必修 3 第 81 讲）

老师说，设速度偏转角为 $\alpha$，弦切角为 $\theta$。推导是：把轨迹圆弧画出来，进、出速度所在的两条线都是切线，两条切线和弦围成一个三角形，两个底角是同一条弦的两个弦切角，都是 $\theta$。这个三角形的另一个角是速度偏转角 $\alpha$ 的补角，即 $180^\circ-\alpha$。三角形内角和是 $180^\circ$，所以 $2\theta+(180^\circ-\alpha)=180^\circ$，两边的 $180^\circ$ 消掉，得 $2\theta=\alpha$，即 $\theta=\frac{\alpha}{2}$。〔卡 bixiu3-81-c07〕

老师说，这个关系找一次就行，结论直接知道就行。他最后总结：核心其实是速度偏转角。讲义红字：弦切角 = 速度偏转角 / 2。〔卡 bixiu3-81-c07〕

![老师推导弦切角等于速度偏转角的一半：两条切线与弦围成三角形，两个底角都是弦切角 $\theta$，顶角是 $180^\circ-\alpha$，内角和 $2\theta+(180^\circ-\alpha)=180^\circ$，得 $\theta=\alpha/2$；图中 $\alpha$ 取 120° 只是示意](https://panda-1.tail2e9885.ts.net/wuli/img/bixiu3-81-angle-derive.png)

### 把几步连起来：解题四步（必修 3 第 81 讲）

老师说，这类题的解题步骤是：第一步，平移速度，求出速度偏转角；第二步，由弦切角等于速度偏转角除以 2，求出弦切角；第三步，代入弦长公式求出弦长；第四步，计算面积，弦长是最小磁场圆的直径，所以面积是 $\pi\left(\frac{L}{2}\right)^2$。这套思路是这类题最简单的做法，不管选择题还是计算题，只要找到速度偏转角，后面的过程都一模一样。〔卡 bixiu3-81-c09〕

〔整理注：卡片已标明面积公式 $\pi\left(\frac{L}{2}\right)^2$ 是按直径等于弦长补写的，不是老师逐字说出来的。〕

### 选择题与计算题的写法不同（必修 3 第 81 讲）

选择题可以直接走四步，老师说这类题在磁场里算难题，但听过前面的思路之后，连图都不用画。〔卡 bixiu3-81-c10〕

计算题里弦长公式用不了，要换一种写法。老师说，无论什么题，上手第一步无脑先写 $qvB=\frac{mv^2}{r}$，这个公式有分。本题给的是 $v_0$，就写 $qv_0B=\frac{mv_0^2}{r}$，得 $r=\frac{mv_0}{qB}$。接着要找轨迹圆弧的弦长和轨迹半径 $r$ 的关系。先画轨迹：过 $b$ 点沿速度做反向延长线交 $y$ 轴于 $D$ 点，大致画出轨迹，设粒子从 $A$ 点进磁场、从 $C$ 点出磁场，连接 $AC$，设 $AC$ 长为 $L$。〔卡 bixiu3-81-c12〕

这段圆弧的弦长等于最小磁场的直径，老师说这一点不需要额外证明，可以直接用，直接写：由几何关系，磁场区域最小时，半径 $R=\frac{L}{2}$。轨迹圆用小 $r$，磁场圆用大 $R$，这样说明一下就行。〔卡 bixiu3-81-c12〕

然后用传统的定圆心转半径方法找 $L$ 与 $r$ 的关系。$AD$、$CD$ 是这段圆弧的切线，过 $A$ 做 $AD$ 的垂线、过 $C$ 做 $CD$ 的垂线，交点 $O'$ 就是轨迹圆心。再做弦 $AC$ 的中垂线，交 $AC$ 于 $E$，它一定过圆心 $O'$。角度上，$\angle b$ 是 $30^\circ$，直角三角形 $ODb$ 里 $\angle ODb=60^\circ$。四边形 $DAO'C$ 内角和 $360^\circ$，$\angle DAO'$ 和 $\angle DCO'$ 都是 $90^\circ$，再减掉 $60^\circ$，得 $\angle AO'C=120^\circ$。$O'E$ 平分它，所以 $\angle AO'E=60^\circ$。在直角三角形 $EAO'$ 里，斜边是轨迹半径 $r$，$AE=r\sin60^\circ=\frac{\sqrt3}{2}r=\frac{\sqrt3}{2}\cdot\frac{mv_0}{qB}$，所以 $R=AE$，面积 $S=\pi R^2=\frac{3\pi m^2v_0^2}{4q^2B^2}$。〔卡 bixiu3-81-c12〕

老师说，物理计算题不要求写详细的几何证明，直接写出几何关系，比如 $\angle AO'C=120^\circ$，加一个简单说明就行。大思路是：最小磁场圆的直径等于轨迹弦长，再找弦长与轨迹圆半径的关系。〔卡 bixiu3-81-c12〕

〔整理注：这条计算题写法里用到的画轨迹、定圆心、找半径，是另一个概念的内容，见 磁场轨迹问题（画轨迹、定圆心、找半径）（concepts/magnetic-trajectory-center-radius.md）。卡片记录转录里 $O'$ 被写成「OP」，$\angle AO'E=60^\circ$ 是按老师板书整理的。〕

![例题 2 老师板书重画：过 $b$ 点反向延长速度得到交点 $D$，$\angle ODb=60^\circ$，由四边形得 $\angle AO'C=120^\circ$，作弦 $AC$ 的中垂线交于 $E$，$\angle AO'E=60^\circ$，$AE=\frac{\sqrt3}{2}r$；$O$ 到 $A$ 的距离和 $r$ 的大小是示意取的，原题没给](https://panda-1.tail2e9885.ts.net/wuli/img/bixiu3-81-q2-geometry.png)

## 做题套路

1. 认出题型：磁场位置和大小未知，只知道进、出速度方向，求圆形磁场最小面积。〔卡 bixiu3-81-c01〕
2. 记住核心结论：最小磁场圆以轨迹圆弧的弦为直径，所以只需求弦长。〔卡 bixiu3-81-c03〕
3. 第一步，平移速度，求出速度偏转角 $\alpha$。把初、末速度平移到箭头屁股相接，看两箭头之间的夹角，分清锐角和钝角。〔卡 bixiu3-81-c06、bixiu3-81-c08、bixiu3-81-c09〕
4. 第二步，弦切角 $\theta=\frac{\alpha}{2}$。〔卡 bixiu3-81-c07、bixiu3-81-c09〕
5. 第三步，代入弦长公式 $L=\frac{2mv\sin\theta}{qB}$ 求弦长。〔卡 bixiu3-81-c04、bixiu3-81-c09〕
6. 第四步，弦长是最小磁场圆的直径，面积 $S=\pi\left(\frac{L}{2}\right)^2$。〔卡 bixiu3-81-c09〕
7. 写计算题过程时，先写 $qvB=\frac{mv^2}{r}$ 得 $r=\frac{mv}{qB}$，再说明磁场区域最小时 $R=\frac{L}{2}$，然后用定圆心转半径的几何关系找 $L$ 与 $r$ 的关系，直接写出角度关系，不必写很详细的几何证明。〔卡 bixiu3-81-c12〕
8. 老师说，选择题基本上一分钟可以搞定，计算题好好看讲过程的那一部分，问题就不大了。〔卡 bixiu3-81-c13〕

## 易错

- 弦切角要画在轨迹圆上，不要被图里的磁场圆误导。磁场圆和弦切角没有关系，要看进、出速度所在直线这两条轨迹圆的切线与弦的夹角。〔卡 bixiu3-81-c05〕

![讲义第 7 页原图：已知进磁场的速度 $v_0$（水平向右）和出磁场的速度 $v_t$（指向右下），灰色虚线圆是磁场圆，红线是弦；老师特意把磁场圆画在这里，提醒别被它误导，弦切角要看轨迹圆的切线](https://panda-1.tail2e9885.ts.net/wuli/img/bixiu3-81-angle-slide.png)

- 速度偏转角有时是锐角，有时是钝角。为避免搞错，一定先平移速度，初速度、末速度平移哪个都行，让两个箭头的屁股挨在一起，再看夹角是锐角还是钝角。讲义红字：注意，速度偏转角要平移速度到箭头屁股在一起，分清锐角钝角。〔卡 bixiu3-81-c08〕
- 磁场必须恰好覆盖轨迹圆弧，不能多也不能少。多了粒子还在磁场里继续偏转，少了出来的方向不对。〔卡 bixiu3-81-c02〕
- 没听过弦长公式的同学，要先回头学弦长公式，再做这类题。〔卡 bixiu3-81-c04〕

## 例题

- **必修 3 第 81 讲 例题 1**（竖直面内直角三角形 $MNQ$，$\angle M$ 为直角，$\alpha=\frac{\pi}{3}$）：粒子以速度 $v$ 由 $M$ 点沿 $MQ$ 方向射出，加垂直于平面的圆形有界匀强磁场（磁感应强度 $B$），使粒子偏转后沿 $QN$ 方向到达 $N$ 点，求磁场的最小面积。答案 C，$S=\frac{3\pi m^2v^2}{4q^2B^2}$。要点：把末速度平移到与初速度箭头屁股相接，得速度偏转角 $120^\circ$，弦切角 $60^\circ$，弦长 $L=\frac{2mv\sin60^\circ}{qB}=\frac{\sqrt3\,mv}{qB}$，半径 $R=\frac{\sqrt3\,mv}{2qB}$，面积 $S=\pi R^2$。老师说，听过前面思路后，这种题连图都不用画。〔卡 bixiu3-81-c10〕
- **必修 3 第 81 讲 例题 2**（粒子沿 $y$ 轴射入圆形磁场，从 $b$ 处以 $30^\circ$ 穿过 $x$ 轴）：求圆形磁场区域的最小面积。答案 $S=\frac{3\pi m^2v_0^2}{4q^2B^2}$。要点：出速度平移后速度偏转角 $120^\circ$，弦切角 $60^\circ$，结果与例题 1 相同。老师说这道题的重点是计算题怎么写过程，不是结果。〔卡 bixiu3-81-c11、bixiu3-81-c12〕
